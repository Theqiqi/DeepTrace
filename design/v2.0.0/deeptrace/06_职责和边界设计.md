# deeptrace - 职责和边界设计(修改模式)

> 引用:v1.2.0/deeptrace/09_职责和边界设计.md。职责边界不变,补充:

- Infrastructure(debug):只封装 Windows 调试事件机制(等待事件、继续事件、
  断点消费的恢复/单步/重武装),不感知断点记录文件;不包含 service/store.h。
- Service(debug):debug_continue 组装——校验调试模式、加载断点记录判定命中、
  调用 Infrastructure 原语、填充 ContinueInfo;唯一引入 store 与 windows.h 语义
  的层。
- Domain:仅数据结构。
- 禁止:Infrastructure 调用 Service;公共 API 返回 Windows 类型。
