# CLI - 参数列表(修改模式)

> 引用:v1.0.0/cli/14_参数列表.md。本版本更新 debug run 参数;其余参数不变。

## 1. debug run 参数(新增)

| # | 参数 | 位置 | 必填 | 类型 | 取值/校验 |
|---|------|------|------|------|-----------|
| 1 | script | 第 1 个 | 是 | script-path | 非空;文件存在/可读由脚本模块校验 |

## 2. 脚本步骤字段(script.json 内部)

步骤 op 与字段(全部为字符串值):

| op | 必填字段 | 可选字段 | 字段校验 |
|----|----------|----------|----------|
| break / clear | addr | - | address(0x 或十进制) |
| hbreak | addr, type, length | - | address;type 0..2;length 1\|2\|4\|8 |
| hclear | addr | - | address |
| guard / unguard | addr, size | - | address;number(>0) |
| pause / resume | - | - | - |
| step / next | - | tid(可选) | number |
| registers | - | tid(可选) | number |
| register | name | tid(可选) | ascii;number |
| status | - | - | - |
| continue | - | timeout_ms(可选,默认 5000) | number(>0) |
| read | addr, size | format(hex\|text,默认 hex) | address;number;format |
| write | addr, bytes | - | address;hex-bytes(空格分隔/连续均可) |
| disasm | addr | count(默认 8) | address;number |
| watch_add | desc, addr, type | - | ascii;address;value-type |
| watch_remove | index | - | number |
| watch_clear | - | - | - |
| watch_refresh | - | - | - |
| watch_list | - | - | - |

字段值类型规则(address/number/format/value-type/hex-bytes/ascii/tid)与
convert/既有命令的参数校验规则保持一致(见 14_参数列表既有表)。

## 3. 其余命令参数

全部不变,引用既有文档。
