# CLI - 技术选型(修改模式)

> 引用:v1.0.0/cli/17_技术选型.md。本版本沿用既有选型,仅标注新增部分。

## 1. 既有选型(沿用)

- 程序类型:命令行可执行文件(exe)
- 语言:C++20
- 平台:Windows
- 框架:Console
- 构建:CMake(CMakeLists.txt + CMakePresets.json)
- 包管理:vcpkg
- 依赖:静态库 deeptrace(引用公共头 deeptrace.h 与 out/lib/<配置>)
- 参数解析:argc/argv 自实现(parser)

## 2. 本版本新增选型

- **JSON 解析**:自实现小解析器(script.cpp,纯标准库)——脚本格式固定为
  「顶层数组 + 字符串值对象」,字段表有限且显式,自实现 200 行内可完整覆盖
  并保证功能完整;不引入第三方 JSON 库,避免新增依赖面。经功能完整性审查
  (19_代码审查结论)与全量测试验证。
- 其余技术选型全部沿用,无新增依赖。
