# CLI - 领域分析(修改模式)

> 引用:v1.0.0/cli/02_领域分析.md 既有领域模型。本版本聚焦改动点增量更新。

## 1. 领域问题(改动点)

- 既有模型:动态分析(内存/模块/扫描/监视)、静态分析(反汇编/汇编/转换)与
  动态调试(断点/单步/寄存器)都以单命令呈现,调试会话状态依赖跨调用与持久化文件,
  会话语义不清晰。
- 本版本新增领域集合:**调试会话脚本**(一次脚本 = 一次完整调试会话)。

## 2. 新增集合与操作

| 集合 | 元素 | 操作 |
|------|------|------|
| 调试脚本会话 | 脚本文件(JSON 步骤数组) | 运行(attach→debug_attach→步骤序列→清理→detach) |
| 脚本步骤 | break/clear/hbreak/hclear/guard/unguard/pause/resume/step/next/registers/register/status/continue/read/write/disasm/watch_* | 执行(单条) |

- 会话状态(调试模式、断点记录、暂停/命中位置)仅存在于本次 CLI 进程内存中;
  脚本结束(成功或失败)统一清理本次设置并 detach,恢复目标进程原始状态。
- 与既有集合的关系:脚本步骤复用既有调试/内存/反汇编/监视集合的**操作语义**,
  但以"会话内单条执行"方式编排;动态/静态分析单命令集合保持不变。

## 3. 参与者与操作流程

- 参与者:用户/脚本/AI 工具。流程:编写脚本文件 → `-p <pid> debug run <script>`
  → CLI 输出每步结果 → 退出(0/1/2)。
