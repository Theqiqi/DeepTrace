# CLI - 接口设计(修改模式)

> 引用:v1.0.0/cli/12_接口设计.md。标注改动数据结构与接口。

## 1. 数据结构列表(标注改动)

| 数据结构 | 改动 |
|----------|------|
| `CommandRequest{group, action, args, ...}` | 不变。debug run 使用 group="debug"、action="run"、args=[script-path] |
| `CommandSpec{group, action, usage, brief, params}` | debug 组新增 run 条目 |
| `ParamSpec{name, type, required, def}` | 新增类型名:"script-path" |
| `ScriptStep{op, fields(map<string,string>)}`(新) | 脚本单步:op + 全部字符串字段 |
| `Script{steps(vector<ScriptStep>)}`(新) | 步骤数组 |
| `StepResult{ok, kind, text}`(新) | 步骤执行结果:ok、结果类别(hit/exited/timeout/exception/ok)、文本 |

## 2. 接口变更

### 命令解析层

- `parse_args` 支持 `debug run <script-path>`:params=[req("script", "script-path")];
  `valid_param` 新增 `script-path`(非空即合法,路径合法性由脚本模块检查)。
- 帮助文本:debug 组新增 `run <script.json>` 条目。

### 接口调用层

- `int cmd_debug(const CommandRequest&)`:`action=="run"` → `cmd_debug_run(req)`。
- 新增 `int cmd_debug_run(const CommandRequest&)`(cmd_debug_run.cpp):
  - 调用 `script::parse_file(path, steps)`;失败 → `Error: <msg>` + 退出 2。
  - 逐条执行步骤;步骤失败 → `Error: step N (<op>): <msg>` + 退出 1;
    continue 遇进程退出 → 报告 + 退出 1。
  - 成功/失败均执行会话清理(清除本次设置的断点/守护页)→ `debug_detach()`。
- 新增 `script::parse_file / parse_text / validate`(script.cpp,纯标准库):
  - parse:顶层 JSON 数组 → 对象列表;每对象字段字符串值;支持 \" 与 \\\\ 转义。
  - validate:op 表校验 + 必填字段 + 按类型校验字段值;错误带行列号。
- 静态库调用映射(全部为公共 API):
  - break/clear/hbreak/hclear/guard/unguard/pause/resume/step/next/registers/
    register/status/continue + memory read/write + disasm at + watch add/remove/
    clear/refresh/list(映射见 16_接口调用设计)。

### 命令打印层

- 步骤头:`[N] op [args]`;结果按类别打印(见 07 功能点设计)。
- `print_version()` 输出 `deeptrace_cli v2.0.0`。
