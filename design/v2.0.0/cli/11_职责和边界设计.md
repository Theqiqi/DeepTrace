# CLI - 职责和边界设计(修改模式)

> 引用:v1.0.0/cli/11_职责和边界设计.md。标注新增模块职责与禁止项。

## 1. 各层职责

| 层 | 职责 | 禁止项 |
|----|------|--------|
| 命令解析层(command) | 解析 argv → CommandRequest;校验命令/参数 | 不执行任何静态库 API;不读目标进程 |
| 接口调用层(interface) | 调用静态库公共 API;管理会话生命周期 | 禁止包含静态库内部头文件;只允许 deeptrace.h |
| 命令打印层(printing) | 结果格式化输出(纯 ASCII) | 不调用静态库 API |
| script 模块(新) | 脚本文件读取/JSON 解析/步骤校验 | 不调用静态库 API;不触碰进程 |

## 2. 边界规则

- 单向调用:打印层 ← 接口调用层 ← 解析层 ← main(不变)。
- `debug run` 的会话生命周期 = 本次 CLI 进程:attach(-p)→ debug_attach →
  步骤执行 → 清理本次会话设置 → debug_detach → detach。清理与 detach 在
  成功/失败路径都必须执行(RAII 或 finally 语义,见 07/16 文档)。
- 脚本步骤只通过静态库公共 API 操作目标;script 模块与执行器之间仅传递
  纯数据结构(不共享全局状态)。
