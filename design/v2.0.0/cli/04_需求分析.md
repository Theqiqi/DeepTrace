# CLI - 需求分析(修改模式:需求变更文档)

> 引用:v1.0.0/cli/04_需求分析.md 既有需求。本版本输出需求变更,逐条列出改动点。

## 1. 需求变更清单

| # | 改动点 | 新增/修改/删除 | 影响命令组/功能 |
|---|--------|----------------|-----------------|
| 1 | 新增 `debug run <script>`:一次调用 = 一次完整调试会话,会话状态仅在内存 | 新增 | debug/run |
| 2 | 调试脚本 = JSON 步骤数组(步骤覆盖调试+内存+反汇编+监视) | 新增 | 脚本格式 |
| 3 | 会话清理:脚本结束统一清理本次设置的软/硬断点与守护页,恢复目标原始状态 | 新增 | debug/run |
| 4 | 静态库缺失能力 continue → 触发静态库流程新增 `debug_continue` | 新增(库能力) | deeptrace |
| 5 | 既有全部命令保留(向后兼容);版本 2.0.0 | 修改 | 全局 |

## 2. 无交互与纯 ASCII 约束复核

- `debug run` 无任何阻塞输入等待(getchar/scanf/cin 不出现);读取脚本文件为文件 I/O,
  不等待用户输入;执行完立即退出。
- 脚本内容/错误消息/逐步输出均为纯 ASCII(JSON 字段与取值 ASCII;错误消息 `Error:` 前缀)。
- 一次调用一个操作;会话资源(调试模式、断点、守护页)在调用结束前配对释放。
