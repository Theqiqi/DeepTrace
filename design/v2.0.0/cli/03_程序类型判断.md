# CLI - 程序类型判断(修改模式)

> 沿用:程序类型不变,仍为 CLI 无交互形式。不做重复判断。

- `debug run <script>` 符合 CLI 无交互判定标准:
  - 操作可抽象为命令+参数:`debug run <script>`
  - 输入可抽象为参数:脚本文件路径(步骤内容在文件内,不占用命令行交互)
  - 输出可文本化:逐步结果逐行打印
  - 一次执行一个操作:一次调用 = 一个完整调试会话,执行完立即退出
- 调试会话的"有状态"被封装在**单次调用内部**(内存中),不违反无状态 CLI 入口约定:
  CLI 入口依旧无状态,会话生命周期 = 本次 CLI 进程。
- 程序类型判断结论:**沿用既有 CLI 无交互类型**,无变更。
