# CLI - 静态库能力匹配分析

## 1. 静态库存在性匹配

- 结论:无既有静态库,本流程随 CLI 同步构建 deeptrace 静态库
  (进程内存操作类,命名 deeptrace),进入"静态库流程调用",由 cpp_static_flow 执行。

## 2. API 能力覆盖性匹配(静态库完成契约返回后)

deeptrace 公共 API(design/v1.0.0/deeptrace/07 接口列表)与 CLI 能力逐项匹配:

| CLI 能力 | deeptrace API | 覆盖 |
|----------|----------|------|
| C1 进程列举 | enumerate_processes | ✓ |
| C2 附加/分离 | attach / detach | ✓ |
| C3 进程信息 | process_info | ✓ |
| C4 挂起/恢复/终止 | suspend_process / resume_process / terminate_process | ✓ |
| C5 读取内存 | memory_read | ✓ |
| C6 写入内存 | memory_write | ✓ |
| C7 转储 | memory_dump | ✓ |
| C8 区域列举 | memory_regions | ✓ |
| C9 类型化读取 | memory_readval | ✓ |
| C10 模块 | module_list / module_find / module_base | ✓ |
| C11 导出表 | module_exports | ✓ |
| C12 模块转储 | module_dump | ✓ |
| C13 线程 | thread_list / thread_suspend / thread_resume / thread_terminate | ✓ |
| C14 断点 | breakpoint_set / breakpoint_clear / hw_breakpoint_set / hw_breakpoint_clear / guard_set / guard_clear | ✓ |
| C15 单步/步过 | debug_step / debug_step_over | ✓ |
| C16 调试状态 | debug_status | ✓ |
| C17 寄存器 | registers_get / register_get | ✓ |
| C18 反汇编 | disasm_at / disasm_range | ✓ |
| C19 扫描 | pattern_scan | ✓ |
| C20 watch | watch_* | ✓ |
| C21 DLL | dll_* | ✓ |
| C22 汇编 | asm_assemble | ✓ |
| C23 壳码 | shellcode_* | ✓ |
| C24 帮助/版本 | CLI 自实现(标准库) | ✓ |

结论:**全部覆盖**,无缺失能力,无需进入缺失能力分析。
