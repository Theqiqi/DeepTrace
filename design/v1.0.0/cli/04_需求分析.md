# CLI - 需求分析

## 1. CLI 需要完成的功能方向

参考 DeepTrace 全部功能,复刻为 11 个命令组,每组若干子命令:

| 组 | 子命令 |
|----|--------|
| ps | list, attach, detach, info, suspend, resume, kill |
| mem | read, write, dump, regions, readval |
| module | list, find, base, exports, dump |
| thread | list, suspend, resume, kill |
| debug | attach, detach, pause, resume, step, next, break, clear, hbreak, hclear, guard, unguard, status, registers, register |
| disasm | at, range |
| resolve | base, scan |
| watch | list, add, remove, refresh, clear |
| dll | inject, eject, list, status |
| asm | assemble |
| shellcode | inject, injectat, status |

全局选项:-p/--pid(目标进程)、-h/--help、-v/--version。

## 2. 使用场景

- 场景1:附加进程后读取/修改指定地址内存
- 场景2:查找目标模块基址与导出函数地址
- 场景3:跨进程 AOB 特征码扫描
- 场景4:设置/清除断点,单步调试
- 场景5:监视若干地址值变化(watch)
- 场景6:注入 DLL 与壳码

## 3. 非功能需求

- 无交互:一次调用一个操作,执行完立即退出
- 纯 ASCII 输出
- 退出码:成功 0,失败非 0
- 帮助系统:分组列出命令与参数
