# deeptrace 静态库 - 模块设计

## 1. 模块划分

按职责拆分:

| 模块 | 目录 | 职责 | 依赖 |
|------|------|------|------|
| 类型定义 | src/data/types.h | 全部公共数据结构、枚举 | 无 |
| 算法-编码 | src/algorithm/encoding | hex 编解码、字符串格式化 | data |
| 算法-匹配 | src/algorithm/scan | AOB 模式匹配(纯字节流) | data |
| 算法-反汇编 | src/algorithm/disasm | x64 指令解码(纯字节流) | data |
| 算法-汇编 | src/algorithm/asm | x64 指令编码(纯字符串) | data |
| 原子化-进程 | src/atomic/process | OpenProcess/快照/挂起/结束 | data |
| 原子化-内存 | src/atomic/memory | Read/WriteProcessMemory/VirtualQueryEx | data |
| 原子化-模块 | src/atomic/module | 模块快照/PE 导出解析 | data |
| 原子化-线程 | src/atomic/thread | 线程快照/Suspend/Resume/Terminate | data |
| 原子化-调试 | src/atomic/debug | DebugActiveProcess/上下文/断点写入 | data |
| 原子化-注入 | src/atomic/inject | VirtualAllocEx/远端线程 | data |
| 接口-进程 | src/api/process | 进程公共 API + 会话管理 | 全部 |
| 接口-内存 | src/api/memory | 内存公共 API | 算法+原子化 |
| 接口-模块 | src/api/module | 模块公共 API | 原子化 |
| 接口-线程 | src/api/thread | 线程公共 API | 原子化 |
| 接口-调试 | src/api/debug | 调试公共 API + 断点持久化 | 原子化 |
| 接口-解析 | src/api/resolve | 扫描公共 API | 算法+原子化 |
| 接口-监视 | src/api/watch | watch 持久化+刷新 | 原子化 |
| 接口-注入 | src/api/inject | DLL/壳码公共 API | 原子化 |
| 接口-汇编 | src/api/asm | 汇编公共 API | 算法 |

## 2. 命名空间

```
deeptrace          // 全部公共 API
deeptrace::internal// 算法/原子化内部实现(不对外)
```

## 3. 公共头文件组织

```
deeptrace/include/deeptrace.h   // 唯一公共头:类型 + API 声明 + result_message
```
