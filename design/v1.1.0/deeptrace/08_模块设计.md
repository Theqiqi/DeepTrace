# deeptrace 静态库 - 模块设计

## 1. 模块划分

按职责拆分:

| 模块 | 目录 | 职责 | 依赖 |
|------|------|------|------|
| 类型定义 | src/domain/types.h | 全部公共数据结构、枚举 | 无 |
| 算法-编码 | src/algorithm/encoding | hex 编解码、字符串格式化 | domain |
| 算法-匹配 | src/algorithm/scan | AOB 模式匹配(纯字节流) | domain |
| 基础能力-反汇编 | src/infrastructure/disassembly | x64 指令解码/编码(纯字节流/纯字符串) | domain |
| 基础能力-进程 | src/infrastructure/process | OpenProcess/快照/挂起/结束 | domain |
| 基础能力-内存 | src/infrastructure/memory | Read/WriteProcessMemory/VirtualQueryEx | domain |
| 基础能力-模块 | src/infrastructure/module | 模块快照/PE 导出解析 | domain |
| 基础能力-线程 | src/infrastructure/thread | 线程快照/Suspend/Resume/Terminate | domain |
| 基础能力-调试 | src/infrastructure/debug | DebugActiveProcess/上下文/断点写入 | domain |
| 基础能力-注入 | src/infrastructure/inject | VirtualAllocEx/远端线程 | domain |
| 基础能力-日志 | src/infrastructure/logging | Logger/LogSink/ConsoleSink(按需) | domain |
| 便捷工具 | src/utils | log.h 等便捷门面,只转发调用不实现能力(按需) | infrastructure |
| 服务-进程 | src/service/process | 进程公共 API + 会话管理 | 全部 |
| 服务-内存 | src/service/memory | 内存公共 API | 算法+基础能力 |
| 服务-模块 | src/service/module | 模块公共 API | 基础能力 |
| 服务-线程 | src/service/thread | 线程公共 API | 基础能力 |
| 服务-调试 | src/service/debug | 调试公共 API + 断点持久化 | 基础能力 |
| 服务-解析 | src/service/resolve | 扫描公共 API | 算法+基础能力 |
| 服务-监视 | src/service/watch | watch 持久化+刷新 | 基础能力 |
| 服务-注入 | src/service/inject | DLL/壳码公共 API | 基础能力 |
| 服务-汇编 | src/service/asm | 汇编公共 API | 基础能力(disassembly) |

## 2. 目录结构

```
src/
├── domain/            # types.h(纯类型)
├── algorithm/         # hex、scan、format(纯业务计算)
├── infrastructure/    # 基础能力,按能力类型分子目录
│   ├── process/  memory/  module/  thread/  debug/  inject/
│   ├── disassembly/   # x64 解码/编码
│   ├── logging/       # Logger/LogSink/ConsoleSink(按需)
│   └── threadpool/  network/  database/  symbol/   # 未来扩展
├── service/           # 组装 + 会话 + 持久化
└── utils/             # 便捷门面,只转发调用不实现能力(按需)
```

- Infrastructure 内能力子目录按项目需要确定,不限定死具体类型
- 不按平台建目录:同一能力的多平台实现以文件后缀区分文件名(process_win32.cpp / process_linux.cpp)

## 3. 命名空间

```
deeptrace          // 全部公共 API
deeptrace::internal// 算法/基础设施内部实现(不对外)
```

## 4. 公共头文件组织

```
deeptrace/include/deeptrace.h   // 唯一公共头:类型 + API 声明 + result_message
```
