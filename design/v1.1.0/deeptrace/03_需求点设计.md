# deeptrace 静态库 - 需求点设计

## 1. 需求点拆分

### P1 进程管理
- P1.1 进程列举(快照法 CreateToolhelp32Snapshot)
- P1.2 进程附加(OpenProcess PROCESS_ALL_ACCESS,会话记录)
- P1.3 进程分离(关闭句柄)
- P1.4 进程信息(PID 校验 + 线程数查询)
- P1.5 进程挂起(枚举线程逐个 SuspendThread,首线程挂起数保护)
- P1.6 进程恢复(枚举线程逐个 ResumeThread)
- P1.7 进程结束(TerminateProcess,可带退出码)

### P2 内存操作
- P2.1 内存读取(ReadProcessMemory,完整读取校验)
- P2.2 内存写入(WriteProcessMemory)
- P2.3 内存转储(读取整段返回 vector)
- P2.4 区域列举(VirtualQueryEx 循环)
- P2.5 类型化读取(按类型解释 1/2/4/8 字节与 float/double)

### P3 模块操作
- P3.1 模块列举(Module32First/Next)
- P3.2 模块查找/基址(名称不区分大小写,支持全名或 basename)
- P3.3 导出表解析(远端读取 PE DOS/NT/导出目录)
- P3.4 模块转储(按模块大小读取写入文件/返回十六进制)

### P4 线程操作
- P4.1 线程列举(Thread32First/Next)
- P4.2 线程挂起/恢复(OpenThread + SuspendThread/ResumeThread)
- P4.3 线程结束(TerminateThread)

### P5 调试
- P5.1 软件断点(写 0xCC 保存原字节;状态持久化文件)
- P5.2 硬件断点(SetThreadContext 写 DR0-DR3/DR7;持久化)
- P5.3 页保护(VirtualProtectEx PAGE_GUARD)
- P5.4 调试附加(DebugActiveProcess + 等待初始事件 + Stop)
- P5.5 单步/步过(DebugActiveProcess + TF 置位 + WaitForDebugEvent 单步事件 + Stop)
- P5.6 寄存器(GetThreadContext 全量/单寄存器)

### P6 反汇编/汇编
- P6.1 x64 解码器(REX/ModRM/SIB/位移,常用指令集)
- P6.2 x64 编码器(助记符+操作数 → 机器码,与解码器同指令集)

### P7 解析
- P7.1 模块基址(同 P3.2)
- P7.2 AOB 模式扫描(可读区域遍历 + 通配匹配)

### P8 监视
- P8.1 watch 持久化(状态文件 %TEMP%/deeptrace_watch_<pid>.dat)
- P8.2 watch 刷新(重新读取各条目内存值)

### P9 DLL 注入
- P9.1 注入(VirtualAllocEx + WriteProcessMemory + CreateRemoteThread(LoadLibraryW))
- P9.2 弹出(远端线程 FreeLibrary;按路径或地址)
- P9.3 列表/状态(持久化 + 校验模块仍加载)

### P10 壳码
- P10.1 注入(自动分配 + 写入 + CreateRemoteThread)
- P10.2 指定地址注入(写入 + 线程执行)
- P10.3 状态(GetExitCodeThread 判断运行)

## 2. 需求点验收标准(示例)

- P2.1:对 target 进程已知 volatile 全局变量地址读取,值必须与声明一致
- P7.2:对 target 已知特征字节扫描,必须命中且地址正确
- P5.1:写入 0xCC 后 mem read 可见 0xCC,clear 后恢复原字节
