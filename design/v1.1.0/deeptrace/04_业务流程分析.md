# deeptrace 静态库 - 业务流程分析

## BF1 内存查看流程
```
CLI 调用 → process_attach(pid) → memory_read(addr,size) → 返回字节 → detach
```
前置:进程存在且有权限;地址可读。

## BF2 内存修改流程
```
process_attach(pid) → memory_write(addr,data) → 校验写入字节 → detach
```
前置:地址可写;写入长度正确。

## BF3 调试断点流程
```
process_attach(pid) → breakpoint_set(addr)(读原字节→写0xCC→持久化) → detach
breakpoint_clear(addr):读状态→写回原字节→删除状态
```
前置:地址可执行;状态文件可读写。

## BF4 单步流程
```
debug_attach(pid) → 选择目标线程 → 置 TF → ContinueDebugEvent → WaitForDebugEvent(单步)
→ 读取新 RIP → DebugActiveProcessStop
```

## BF5 扫描流程
```
process_attach(pid) → memory_regions → 对每个可读区域 pattern_scan → 汇总命中地址
```

## BF6 DLL 注入流程
```
process_attach(pid) → VirtualAllocEx(路径长度) → WriteProcessMemory(路径)
→ CreateRemoteThread(LoadLibraryW) → 等待线程结束 → GetModuleHandleEx 验证 → 持久化
```

## BF7 watch 流程
```
watch_add:attach → 读地址值 → 持久化条目
watch_refresh:attach → 逐条读取当前值 → 更新
watch_remove/clear:操作状态文件
```

## BF8 壳码注入流程
```
process_attach(pid) → VirtualAllocEx(size) → WriteProcessMemory(bytes) → CreateRemoteThread(起始地址) → 持久化(tid/地址)
```
