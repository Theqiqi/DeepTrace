# CLI - 异常设计(修改模式)

> 引用:v1.0.0/cli/15_异常设计.md。错误消息统一 `Error: <消息>` 前缀,纯 ASCII;
> 退出码语义:0 成功 / 1 业务错误 / 2 用法错误。本版本只涉及新增 convert 的错误路径。

## 1. convert 错误路径(全部用法错误,退出码 2)

| 场景 | 消息(示例) | 退出码 |
|------|-------------|--------|
| 缺 type | `Error: missing argument: type` | 2 |
| 缺 value | `Error: missing argument: value` | 2 |
| 类型非法 | `Error: invalid type: 'bogus'` | 2 |
| 值非法/越界/不支持形式 | `Error: invalid value for type 'dword': 'xyz'` | 2 |
| 多余参数 | `Error: too many arguments: 'extra'` | 2 |
| typed_bytes 防御性失败 | `Error: invalid value for type '<type>': '<value>'` | 2 |

- 所有消息纯 ASCII;不产生任何进程副作用,无资源配对问题。
- `resolve scan` 回滚后恢复 v1.3.0 既有错误行为(如 `resolve scan 100 dword`
  → `Error: too many arguments: 'dword'`,退出码 2)。
