# CLI - 需求点设计(修改模式)

> 引用:v1.0.0/cli/05_需求点设计.md。本版本只对受影响需求点做增量更新。

## 1. 受影响需求点

### 1.1 回滚:resolve scan(恢复 v1.3.0)

- `resolve scan <pattern>` 只接受 AOB 模式(空格分隔 hex 字节 + `??` 通配),
  行为与 v1.3.0 完全一致;删除 v1.4.0 新增的 `[type]` 参数与转换路径。

### 1.2 新增:数据值转换 convert

- 命令形式:`convert <type> <value>`(类型在前、数据在后,无子动作)
- type 取值:`byte|word|dword|qword|float|double|string|hex`(必填)
- 转换规则:
  - 整数:十进制或 0x 前缀十六进制,无符号;范围 byte 0..255、word 0..65535、
    dword 0..4294967295、qword 0..18446744073709551615;多字节小端序
  - float/double:仅十进制字面量(拒绝十六进制浮点),IEEE754 小端序,须为有限值
  - string:纯 ASCII 可打印字符(0x20..0x7E),逐字节输出
  - hex:连续 hex 字节串(可选 0x 前缀、偶数长度),逐字节透传
- 输出:单行、空格分隔、大写十六进制字节(如 `64 00 00 00`),与 scan pattern 格式兼容
- 无参/缺参/类型非法/值非法/越界 → `Error:` 纯 ASCII 消息 + 退出码 2
- 不需要 `-p`,不需要进程会话

### 1.3 解析器支持无子动作命令

- 命令表允许 action 为空(独立命令);`convert <type> <value>` 中 type/value 从
  第 1 个位置参数开始解析;既有"组 + 子动作"命令解析行为不变。

## 2. 约束满足确认

- 无等待:convert 无任何输入等待,执行完立即退出 ✓
- 纯 ASCII:帮助/错误/输出全 ASCII ✓
- 一次调用一个操作:convert 单命令单任务 ✓
- 资源配对:convert 无成对资源,不涉及 attach/detach ✓
