# CLI - 功能点设计(修改模式)

> 引用:v1.0.0/cli/07_功能点设计.md。本版本只对改动点新增/更新功能点。

## 1. 功能点:convert(新增)

**功能**:按类型把数据值转换为十六进制字节并输出。

### 1.1 功能分析(正常/错误路径)

正常路径:
1. 解析 `convert <type> <value>`(无子动作命令,args[0]=type,args[1]=value)
2. 校验 type ∈ 枚举;校验 value 符合该类型(整数范围/浮点有限/ASCII/hex 偶数长度)
3. `internal::typed_bytes` 转换:整数小端(1/2/4/8 字节)、float 4 字节 IEEE754 小端、
   double 8 字节 IEEE754 小端、string ASCII 逐字节、hex 连续字节
4. `printer::print_bytes` 输出单行大写 hex(空格分隔)→ 退出码 0

错误路径(全部用法错误,退出码 2,`Error:` 前缀纯 ASCII):
- 缺参:`convert` → missing argument: type;`convert dword` → missing argument: value
- 类型非法:`convert bogus 1` → invalid type: 'bogus'
- 值非法/越界:`convert dword xyz` / `convert byte 256` →
  invalid value for type '<type>': '<value>'
- 多余参数:`convert dword 1 extra` → too many arguments

能力边界(支持清单 / 不支持错误):
- 支持:byte/word/dword/qword(无符号十进制或 0x 十六进制)、float/double(十进制有限值)、
  string(ASCII 0x20..0x7E)、hex(0x 可选、偶数长度)
- 不支持(明确错误):负数整数、非 ASCII 字符串、十六进制浮点(如 0x1p3)、
  大小端切换、AOB 通配符(??)。帮助文本不得暗示这些形式。

### 1.2 功能流程图(内部)

```
parse_args
  ├─ 选项解析(-h/-v/-p) → help/version/pid
  ├─ 无子动作命令判定:convert(独立命令,args 从位置 1 起)
  ├─ 参数校验:convert-type → convert-value → 跨字段 valid_convert_value
  └─ 失败 → Error + 退出码 2
execute
  └─ convert 分派 → cmd_convert(不 attach)
       ├─ typed_bytes 失败(防御性)→ Error + 退出码 2
       └─ print_bytes → 退出码 0
```
