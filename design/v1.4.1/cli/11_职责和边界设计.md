# CLI - 职责和边界设计(修改模式)

> 引用:v1.0.0/cli/11_职责和边界设计.md。职责边界不变,仅新增/回滚涉及项的说明。

## 1. 各层职责与禁止项(引用)

- 命令解析层:构造请求对象,禁止直接执行/打印。
- 接口调用层:执行命令流程,经公共 API 调静态库;本版本新增的 `typed_bytes`
  为纯标准库数据变换辅助(与既有 `hex_bytes` 同级),禁止使用平台 API。
- 命令打印层:只做格式化输出,禁止直接调库。
- 单向调用:命令打印层 ← 接口调用层 ← 命令解析层 ← main。

## 2. 改动边界

- `convert` 不调用任何静态库 API(纯数据变换);`resolve scan` 恢复为唯一扫描入口,
  仅调用 `deeptrace::pattern_scan` 公共 API。
- CLI 不包含静态库内部头文件;生产代码仅使用标准库与 `deeptrace.h` 公共 API。
