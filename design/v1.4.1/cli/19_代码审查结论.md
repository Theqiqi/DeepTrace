# CLI - 代码审查结论(v1.4.1)

## 1. 审查范围

- 回滚:v1.4.0 的 `resolve scan` 类型值改动(commands.cpp/parser.cpp/cmd.h/cmd_resolve.cpp/executor.cpp 及测试)
- 新增:独立命令 `convert <type> <value>`(命令表/解析/typed_bytes/cmd_convert/分派/测试)

## 2. 审查方式

- 代码审查 agent 逐项核对:解析边界、转换正确性、退出码、兼容性、ASCII/无交互约束、版本残留
- 结合 Debug/Release 双编译与单测/集成/e2e 全量执行验证

## 3. 审查发现与修复

| # | 发现 | 严重度 | 修复 |
|---|------|--------|------|
| 1 | `resolve scan 100 dword` 的错误消息是 `invalid pattern: '100'`(pattern 校验先于多余参数检查),单测与 e2e 误断言 `too many arguments` | 中(测试断言错误) | 单测改用合法 pattern + 多余参数触发 `too many arguments`;同时保留 `invalid pattern` 断言;e2e 同步改为 `resolve scan "48 8B" dword` |
| 2 | `convert dword -1` 中 `-1` 被选项扫描器拦截,错误为 `unknown option: -1` 而非 `invalid value for type` | 低(测试断言错误) | 拆分为独立用例断言 `unknown option`(负数本就不支持,行为正确) |
| 3 | `Parser.ConvertAllTypes` 用值 `1` 测 hex 类型,奇数长度非法导致误判 | 低(测试数据错误) | hex 改用 `11` |
| 4 | commands.h 参数类型注释未包含新增的 convert-type/convert-value | 低(注释) | 同步注释 |
| 5 | agent 技能文档(agents/)未记录 convert | 提示 | 不影响流程正确性,技能文档仅描述既有 v1.3.0 行为(与恢复后的 scan 一致),可选后续补充 |
