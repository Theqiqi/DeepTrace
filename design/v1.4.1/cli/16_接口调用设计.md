# CLI - 接口调用设计(修改模式)

> 引用:v1.0.0/cli/16_接口调用设计.md。接口调用层的每个静态库调用对应真实公共 API。

## 1. 静态库调用映射(本版本)

| 命令 | 调用 | 公共 API | 说明 |
|------|------|----------|------|
| resolve scan(回滚) | `pattern_scan(pattern, hits)` | `deeptrace::pattern_scan(const std::string&, std::vector<uintptr_t>&)` | 恢复 v1.3.0 直接调用,无转换层 |
| convert(新增) | 无静态库调用 | - | 纯标准库数据变换 |

- 删除 v1.4.0 在 scan 分支的 `value_to_pattern` 转换调用。

## 2. -p / attach-detach 路径检查

- `convert` 不需要目标进程:不传 `-p` 时 `needs_session_attach` 返回 false,不 attach;
  传了 `-p` 时与 asm 等命令一致走既有 attach/detach 自动路径(成对,无泄漏)。
- 无新增成对资源,资源生命周期配对完整性不受影响。

## 3. 能力-调用追溯

- convert 的全部输入形式(8 种类型)由标准库实现,不映射静态库 API;
- scan 的 pattern 输入格式与 convert 输出格式的兼容性由测试阶段 e2e 用例
  「convert 输出喂给 resolve scan 命中真实内存」验证。
