# CLI - 业务流程分析(修改模式)

> 引用:v1.0.0/cli/06_业务流程分析.md。本版本只重画受影响命令的业务流程。

## 1. convert 业务流程(新增)

```
用户输入: convert <type> <value>
   │
   ▼
参数校验(类型枚举 + 按类型的值校验) ──失败──► Error: <消息>(退出码 2)
   │ 通过
   ▼
按类型转换(标准库:整数/浮点小端、ASCII、hex 透传)
   │
   ▼
打印单行 hex 字节(print_bytes)→ 退出码 0
```

- 单条命令边界:`convert` 一次调用只转换一个值,执行完立即退出。
- 转换结果可被用户作为 `resolve scan <pattern>` 的输入(两条独立命令,
  无跨调用状态、无进程会话)。

## 2. resolve scan 业务流程(恢复 v1.3.0,引用既有文档)

```
resolve scan <pattern> ──► pattern_scan ──► 命中地址 / No match found
```

- 无类型转换路径;`resolve scan 100 dword` 报 too many arguments(退出码 2)。
