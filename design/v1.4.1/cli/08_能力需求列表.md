# CLI - 能力需求列表(修改模式)

> 只回答"CLI 需要做什么",不回答"用什么做"。聚焦改动点新增的能力需求。

## 1. 改动点能力需求

| # | 能力需求 | 说明 |
|---|----------|------|
| 1 | 按类型解析数据值 | byte/word/dword/qword 无符号整数(十进制/0x 十六进制)、float/double 十进制浮点、string ASCII、hex 连续字节 |
| 2 | 类型值 → 字节序列 | 整数按宽度小端展开、浮点 IEEE754 小端、字符串逐字符 ASCII、hex 逐字节 |
| 3 | 字节 → 单行大写 hex 文本 | 空格分隔、每字节 2 位大写 hex,与 scan pattern 格式一致 |
| 4 | 类型/值合法性校验 | 类型枚举;整数值域;浮点有限性;ASCII 范围;hex 偶数长度 |
| 5 | 无子动作命令解析 | 独立命令(无 sub-action)的位置参数解析 |

## 2. 能力覆盖判断

- 能力 1/2/4:纯数据变换,由 CLI 接口调用层用 **C/C++ 标准库**实现
  (与既有 `hex_bytes`/`to_addr` 等辅助函数同级,不涉及 OS API)。
- 能力 3:复用既有打印层 `print_bytes`(单行 hex 输出)。
- 能力 5:命令层解析器扩展。
- **静态库能力需求:无新增**。扫描能力(能力清单之外)完全复用既有
  `deeptrace::pattern_scan`;本版本对静态库零需求。
