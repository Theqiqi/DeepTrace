# CLI - 模块设计(修改模式)

> 引用:v1.0.0/cli/10_模块设计.md 三层架构。本版本标注改动涉及的层与文件。

## 1. 三层架构改动映射

| 层 | 改动文件 | 改动内容 |
|----|----------|----------|
| 命令解析层 command | `commands.cpp` | 回滚 resolve scan 命令表;新增 convert 命令表项;帮助文本版本号 v1.4.1 |
| | `commands.h` | 注释同步 |
| | `parser.cpp` | 删除 scan-type/scan-value 校验;新增 convert-type/convert-value 校验;无子动作命令解析 |
| 接口调用层 interface | `cmd.h` | 回滚 value_to_pattern 声明;新增 cmd_convert 与 internal::typed_bytes 声明 |
| | `executor.cpp` | 回滚 value_to_pattern 实现;实现 typed_bytes;新增 convert 分派 |
| | `cmd_convert.cpp`(新增) | convert 命令处理器 |
| | `cmd_resolve.cpp` | 回滚 scan 分支,恢复直接调用 pattern_scan |
| 命令打印层 printing | `printer.cpp` | 仅版本号字符串 v1.4.1(输出格式复用 print_bytes) |
| 构建 | `CMakeLists.txt`(工程版本)、`src/CMakeLists.txt`(core 库加 cmd_convert.cpp) | 版本号 / 源文件清单 |

## 2. 各层职责不变

- 命令层:命令表 + 参数校验 + 请求对象构造
- 接口层:命令分派 + 标准库转换辅助 + 调用静态库公共 API
- 打印层:格式化输出
