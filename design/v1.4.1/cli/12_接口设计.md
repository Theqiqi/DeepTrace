# CLI - 接口设计(修改模式)

> 引用:v1.0.0/cli/12_接口设计.md。标注改动数据结构与接口。

## 1. 数据结构列表(标注改动)

| 数据结构 | 改动 |
|----------|------|
| `CommandRequest{group, action, args, ...}` | 不变。convert 使用 group="convert"、action=""(空)、args=[type, value] |
| `CommandSpec{group, action, usage, brief, params}` | 不变。允许 action 为空表示独立命令 |
| `ParamSpec{name, type, required, def}` | 新增类型名:"convert-type"、"convert-value" |

## 2. 接口变更

### 命令解析层

- `parse_args(int argc, char* argv[])` → `ParseResult`:支持无子动作独立命令
  (pos[0]=group,pos[1..]=参数);`valid_param` 新增 `convert-type`/`convert-value`
  分支;`parse_args` 末尾新增 convert 跨字段校验。

### 接口调用层

- 新增 `int cmd_convert(const CommandRequest& req)`(cmd_convert.cpp):
  `typed_bytes(args[1], args[0], bytes)` → 成功 `print_bytes(bytes)` 返回 0,
  失败(防御性)`Error:` 返回 2。
- 新增 `bool internal::typed_bytes(const std::string& value, const std::string& type,
  std::vector<uint8_t>& out)`(executor.cpp):类型值 → 字节序列,纯标准库。
- `executor.cpp` 分派新增 `else if (req.group == "convert") rc = cmd_convert(req);`。
- 删除 `internal::value_to_pattern`(v1.4.0 引入,回滚)。

### 命令打印层

- 复用既有 `print_bytes(const std::vector<uint8_t>&)`(单行大写 hex)。
- `print_version()` 输出 `deeptrace_cli v1.4.1`。
