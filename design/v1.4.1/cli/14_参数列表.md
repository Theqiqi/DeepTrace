# CLI - 参数列表(修改模式)

> 引用:v1.0.0/cli/14_参数列表.md。本版本更新 convert 参数;回滚 resolve scan 参数。

## 1. convert 参数(新增)

| # | 参数 | 位置 | 必填 | 类型 | 取值/校验 |
|---|------|------|------|------|-----------|
| 1 | type | 第 1 个 | 是 | convert-type | byte\|word\|dword\|qword\|float\|double\|string\|hex |
| 2 | value | 第 2 个 | 是 | convert-value | 按 type 跨字段校验(见下表) |

### value 按类型校验规则

| type | 规则 |
|------|------|
| byte | 无符号整数(十进制或 0x 前缀),0..255 |
| word | 无符号整数,0..65535 |
| dword | 无符号整数,0..4294967295 |
| qword | 无符号整数,0..18446744073709551615 |
| float | 十进制浮点(拒绝 x/X/p/P),有限值 |
| double | 十进制浮点(拒绝 x/X/p/P),有限值 |
| string | 非空,全部字符 0x20..0x7E(可打印 ASCII) |
| hex | 可选 0x 前缀、偶数长度 hex 字节串 |

## 2. resolve scan 参数(回滚)

```
resolve scan <pattern>    pattern(必填):AOB 模式(空格分隔 hex 字节 + ?? 通配)
```

- 删除 v1.4.0 新增的 `[type]` 可选参数。
- 同步:commands.cpp 的 ParamSpec 与 parser.cpp 校验逻辑已回滚,
  `resolve scan 100 dword` → too many arguments(退出码 2)。
