# CLI - 技术选型(修改模式)

> 沿用:v1.0.0/cli/17_技术选型.md 既有选型,本版本无新技术选型。

- 程序类型:命令行可执行文件(exe)
- 语言:C++20
- 平台:Windows(经 WSL + cmd.exe 构建/测试)
- 框架:Console
- 构建:CMake(CMakeLists.txt + CMakePresets.json)
- 包管理:vcpkg
- 依赖:静态库 deeptrace(公共头 + out/lib/<配置>)
- 参数解析:argc/argv 自实现
- 新增说明:convert 的类型值解析/转换使用 C/C++ 标准库
  (`<cstdlib>` strtoull/strtof/strtod、`<cstring>` memcpy),不引入第三方库。
