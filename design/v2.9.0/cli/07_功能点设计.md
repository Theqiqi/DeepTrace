## 1. 新增功能点:批量定位器 JSON(mem batch read/write)

### 1.1 JSON 格式(定稿)

```json
{ "version": 1, "process": "Game.exe",
  "values": {
    "player_health": { "module": "Game.exe", "base": "0x123456",
                       "offsets": ["0x10", "0x20", "0x30"], "type": "float" },
    "sun_ptr":       { "symbol": "sunObjPtr", "offsets": ["0x8"], "type": "qword" },
    "abs":           { "base": "0x140001000", "type": "dword" },
    "name":          { "base": "0x100", "offsets": ["0x40"], "type": "string" },
    "buf":           { "base": "0x200", "type": "bytes", "count": 16 }
  } }
```

- `version`:必须为 1(数字)。
- `process`:可选;存在时 attach 后比对目标进程名(大小写不敏感)。
- `values`:name → 定位器定义。
- 寻址源三态互斥:
  - `module`+`base`:base 为模块内偏移,地址 = module_base(module) + base;
  - `symbol`(可配 offsets):脚本符号根,script_symbol 解析;
  - `base`(无 module):绝对地址(hex 或十进制)。
  - 缺失或冲突(module+symbol 同现)→ 校验错误。
- `offsets`:多级偏移数组,每级先读 qword 指针再偏移(指针链);
  空/缺省 = 单级。
- `type`:byte/word/dword/qword/float/double/string/bytes。
- `count`:仅 bytes 必填(>0),读 count 字节。
- 写模式每项追加 `"value"`(必填)。

### 1.2 解析语义

```
addr = module ? resolve_base(module) + base
     : symbol ? script_symbol(symbol)
     : parse(base)
for off in offsets: addr = *(qword)addr + off    // memory_read 8 字节
最终地址 = addr
read : 按 type 读值(整型/浮点 memory_readval;string 读 NUL 停;bytes 读 count)
write: 按 type 解析 value → memory_write
```

### 1.3 正常路径

```
mem batch read paths.json
  → attach(pid) → process 校验(可选)
  → 逐项: resolve_base/script_symbol → 链遍历 → 读值
  → 表格: name | 最终地址 | 值 → detach → 退出 0
```

### 1.4 错误路径

| 场景 | 层 | 退出码 |
|------|----|--------|
| JSON 语法/结构错误、version≠1、寻址源冲突、type/count/value 非法 | batch 解析器 | 2 |
| 文件不可读 | batch 解析器 | 2 |
| process 不匹配 | 执行层 | 1 |
| 模块未加载 / 符号未注册 | 执行层(resolve) | 1(该条目) |
| 链中间读失败(野指针) | 执行层(memory_read) | 1(该条目) |
| 写失败 | 执行层(memory_write) | 1(该条目) |

- 逐条失败继续其余条目;存在失败条目 → 最终退出 1,全成 → 0。

### 1.5 输出格式(表格式)

```
name            address              value
player_health   0x00007FF62A1B2100   3.14
sun_ptr         0x00000000001F0000   0x1122334455667788
abs             0x0000000140001000   0x64
name            0x0000000140001040   hello
buf             0x0000000140001200   DE AD BE EF 00 00 ...
```

### 1.6 能力边界声明

- 支持:批量定位器读/写、三态寻址源、多级链、8 类型、process 校验。
- 不支持:指针链搜索(后续独立版本);保存/管理命令(文件即存储)。
- 帮助文本:mem 组新增 batch read / batch write 条目。
