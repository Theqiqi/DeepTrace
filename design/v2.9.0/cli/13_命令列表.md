# CLI - 命令列表(新建模式,功能,v2.9.0)

> 引用:v2.8.0/cli/13_命令列表.md。v2.9.0 mem 组新增 batch read / batch write。

## 1. mem 组新增命令

```text
mem batch read <file.json>
    批量执行 JSON 定位器:逐项解析最终地址并按 type 读值,表格打印
    (name + 最终地址 + 值)

mem batch write <file.json>
    批量执行 JSON 定位器:逐项解析最终地址并按 type 写 value
```

- JSON 格式(顶层):
  ```json
  { "version": 1, "process": "Game.exe",
    "values": { "<name>": { <locator>, "type": "...", [count/value] } } }
  ```
- `<locator>` 三选一(互斥):
  - `"module": "game.dll", "base": "0x123456"` —— 模块内偏移;
  - `"symbol": "sunObjPtr"` —— 脚本符号(可配 offsets);
  - `"base": "0x140001000"` —— 绝对地址。
- `"offsets": ["0x10","0x20"]` —— 多级偏移(指针链,每级读 qword 指针)。
- `"type"`: byte|word|dword|qword|float|double|string|bytes。
  - bytes 需 `"count": N`。
- `mem batch write` 每项需 `"value"`。
- 帮助文本:mem 组新增 batch read / batch write 两行。
