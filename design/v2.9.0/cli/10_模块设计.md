> 解析)+ 接口层 cmd_memory(batch 执行)+ 命令表 + 测试。

## 2. 职责边界(与既有约定一致)

- batch 模块:纯文本解析与校验(无 session、无 deeptrace 调用),仿 script
  模块(interface/script.cpp 的 JsonReader 风格,极简标准库)。
- 接口调用层(cmd_memory):attach 后调用公共 API(resolve_base /
  script_symbol / memory_read / memory_write / memory_readval)执行定位;
  所有 deeptrace 调用必须对应公共 API(deeptrace.h)。
- 打印层:表格输出可内联于 cmd_memory(仿 print_watches 对齐),或新增
  printer 函数;保持纯格式化。
- 静态库:零改动(全部组合现有公共 API)。
