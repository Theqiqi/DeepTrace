# CLI - 接口设计(修改模式,v2.1.0)

> 引用:v2.0.0/cli/12_接口设计.md。v2.1.0 改动:cmd_debug 删除单命令分派,
> 脚本步骤表 = 调试能力全量入口;其余接口不变。

## 1. 数据结构列表(标注改动)

| 数据结构 | 改动 |
|----------|------|
| `CommandRequest{group, action, args, ...}` | 不变。debug 组 action 仅 `run` |
| `CommandSpec{group, action, usage, brief, params}` | debug 组仅保留 run 条目 |
| `ParamSpec{name, type, required, def}` | 不变(script-path) |
| `ScriptStep{op, fields(map<string,string>)}` | 不变;op 表全量覆盖调试能力 |
| `Script{steps(vector<ScriptStep>)}` | 不变 |
| `StepResult{ok, kind, text}` | 不变 |

## 2. 接口变更

### 命令解析层

- debug 组命令表删除 15 个单命令条目,仅保留 `debug run <script-path>`。
- 调用 `deeptrace_cli -p <pid> debug step/break/registers/...` →
  `unknown command: '<action>'`(exit 2),提示用户改用 `debug run`。
- 帮助文本:debug 组仅一行 `debug run <script.json>`。

### 接口调用层

- `int cmd_debug(const CommandRequest&)`:`action=="run"` → `cmd_debug_run(req)`;
  其余 action 走 parser 拦截,不会到达此处(防御性返回 InvalidArg)。
- `cmd_debug_run`(不变):parse_file → debug_attach → 逐条执行 → cleanup → debug_detach。
- `script::parse_file / parse_text / validate`(不变):op 表即调试能力清单,
  见 14_参数列表 §2 全量表。

### 命令打印层

- 版本号 `deeptrace_cli v2.1.0`;其余输出格式不变。

## 3. 能力覆盖对照(脚本步骤 ↔ 静态库调试 API)

| 脚本 op | 静态库 API | 原单命令 |
|---------|-----------|----------|
| break / clear | `breakpoint_set` / `breakpoint_clear` | debug break / clear |
| hbreak / hclear | `hw_breakpoint_set` / `hw_breakpoint_clear` | debug hbreak / hclear |
| guard / unguard | `guard_set` / `guard_clear` | debug guard / unguard |
| pause / resume | `debug_pause` / `debug_resume` | debug pause / resume |
| step / next | `debug_step` / `debug_step_over` | debug step / next |
| continue | `debug_continue` | (v2.0.0 新增) |
| status | `debug_status` | debug status |
| registers / register | `registers_get` / `register_get` | debug registers / register |
| attach / detach | 会话生命周期自动管理(debug run 内部) | debug attach / detach(删除) |

> 全部调试能力均有脚本步骤入口,无一遗漏;原单命令调用路径全部删除。
