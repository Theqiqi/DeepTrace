# CLI - 命令列表(修改模式,v2.1.0)

> 引用:v2.0.0/cli/13_命令列表.md。v2.1.0 实测修正——debug 组**只保留 `run` 一个入口**,
> 其余 15 个 debug 单命令全部删除(语义错误,见 00_CHANGELOG §1 实测结论),
> 对应能力全部由脚本步骤覆盖。既有非 debug 命令表不变。

## 1. debug 组(仅 run)

```text
debug run <script.json>        Run a scripted debug session (one invocation = one session)
```

- 用法:`deeptrace_cli -p <pid> debug run <script.json>`
- 脚本 = JSON 步骤数组;步骤**全量覆盖静态库调试能力**:
  - 断点:`break`/`clear`(软件)、`hbreak`/`hclear`(硬件)、`guard`/`unguard`(页守护);
  - 执行控制:`pause`/`resume`/`step`/`next`/`continue`;
  - 状态查询:`status`/`registers`/`register`;
  - 配套:`read`/`write`/`disasm`/`watch_list`/`watch_add`/`watch_remove`/
    `watch_refresh`/`watch_clear`。
- 一次调用 = 一次完整调试会话:attach → debug_attach → 逐条执行 → 清理 → detach,
  会话状态全程在内存中,调用结束即结束。
- 需要 `-p <pid>`(executor 的 -p 自动 attach 路径覆盖本命令)。

### 删除的 debug 单命令(调用报 unknown command)

attach、detach、pause、resume、step、next、break、clear、hbreak、hclear、guard、
unguard、status、registers、register —— 一律改用脚本步骤(见 14_参数列表 步骤表)。

### 使用示例

```jsonc
// demo.json
[
  {"op": "break", "addr": "0x140001000"},
  {"op": "continue", "timeout_ms": "5000"},
  {"op": "registers"},
  {"op": "step"},
  {"op": "read", "addr": "0x140001000", "size": "16", "format": "hex"},
  {"op": "watch_add", "desc": "g_int", "addr": "0x140001000", "type": "dword"},
  {"op": "watch_list"},
  {"op": "clear", "addr": "0x140001000"}
]
```

```text
deeptrace_cli -p 1234 debug run demo.json
```
