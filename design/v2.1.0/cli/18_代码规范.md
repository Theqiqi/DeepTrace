# CLI - 代码规范(修改模式,v2.1.0)

> 引用:v2.0.0/cli/18_代码规范.md。v2.1.0 补充:debug 单命令禁止条款。

## 1. 既有规范(沿用)

- 命名:snake_case 函数/变量、PascalCase 类型、kCamel 常量;公有头注释 /* */。
- 纯 ASCII 输出;错误 `Error: <消息>`。
- 三层单向调用;接口调用层只引用公共头。

## 2. 脚本模块约定(沿用,script.cpp)

- 解析器无状态:输入文本 → 输出 steps 或错误(含行列号);不做任何进程操作。
- 步骤字段全部为 std::string;类型校验集中在一个校验函数表。
- 错误信息带步骤序号与字段名,便于 AI/脚本定位。
- 文件大小上限 1 MiB。

## 3. 会话执行器约定(沿用,cmd_debug_run.cpp)

- 清理逻辑集中一个函数(clear_session_state),成功/失败路径唯一调用点。
- 每步骤打印头 `[N] op [args]` 与结果;不吞异常。
- 不引入全局可变状态;本次会话状态局部于调用。

## 4. v2.1.0 新增:debug 入口约束(强制)

- **CLI 禁止新增任何 debug 单命令**(step/break/registers/attach 等)。
  调试操作只能以脚本步骤形式存在(`debug run <script>` 内)。
- 新增调试能力时:库层 API + 对应脚本 op(必填/可选字段、校验)同步新增,
  并在 14_参数列表 §2 与 12_接口设计 §3 登记,缺一即视为改动不完整。
- 删除能力时:命令表、脚本 op 表、帮助文本、用例同步删除,不留死路径。
