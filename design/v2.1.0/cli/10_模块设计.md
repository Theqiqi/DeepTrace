# CLI - 模块设计(修改模式,v2.1.0)

> 引用:v2.0.0/cli/10_模块设计.md。v2.1.0 改动:debug 单命令处理删除,
> cmd_debug 仅转发 run;脚本模块不变。

## 1. 三层架构(沿用)

```
命令打印层(printing) ← 接口调用层(interface) ← 命令解析层(command) ← main
```

## 2. 本版本改动涉及

| 层 | 文件 | 改动 |
|----|------|------|
| 命令解析层 | `command/commands.cpp` | debug 组仅保留 run 命令表项(删除 15 个单命令) |
| 命令解析层 | `command/parser.cpp` | 不变(unknown command 路径已覆盖删除动作) |
| 接口调用层 | `interface/cmd_debug.cpp` | 删除全部单命令分派,仅转发 run → cmd_debug_run |
| 接口调用层 | `interface/cmd_debug_run.cpp` | 不变(会话执行器) |
| 接口调用层 | `interface/script.cpp/h` | 不变(op 表 = 调试能力全量入口) |
| 命令打印层 | `printing/printer.cpp` | 版本号 v2.1.0 |
| 构建 | `cli/CMakeLists.txt` | 工程版本 2.1.0 |

## 3. 模块职责摘要

- **script 模块**:脚本解析+校验,步骤表全量覆盖调试能力;不接触静态库。
- **cmd_debug_run 模块**:会话执行器,按步骤调用静态库公共 API,管理会话清理;
  唯一持有「本次调用=一次调试会话」的生命周期。
- **cmd_debug 模块**:仅剩 run 转发(防御性),无任何单命令处理逻辑。
- 其余模块(ps/mem/module/thread/disasm/watch/dll/asm/shellcode/convert)
  全部不变,引用既有文档。
