# CLI - 模块设计(修改模式)

> 引用:v1.0.0/cli/10_模块设计.md。标注新增/修改涉及的层与文件。

## 1. 三层架构(沿用)

```
命令打印层(printing) ← 接口调用层(interface) ← 命令解析层(command) ← main
```

## 3. 模块职责摘要

- **script 模块**:把脚本文本解析为结构化步骤数组,并完成逐步骤校验;不接触静态库。
- **cmd_debug_run 模块**:会话执行器,按步骤调用静态库公共 API,管理会话清理;
  唯一持有「本次调用=一次调试会话」的生命周期。
- 其余模块(ps/mem/module/thread/debug 既有动作/disasm/watch/dll/asm/shellcode/convert)
  全部不变,引用既有文档。
