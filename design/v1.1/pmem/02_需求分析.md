# pmem 静态库 - 需求分析

## 1. 领域模型

业务对象:
- 进程(Process):PID、名称、线程数、父进程
- 内存区域(MemoryRegion):基址、大小、保护属性、状态、类型
- 模块(Module):基址、大小、名称、路径
- 导出符号(Export):名称、RVA、地址
- 线程(Thread):TID、优先级、起始地址
- 寄存器(Register):名称、值
- 断点(Breakpoint):地址、类型(软件/硬件/页保护)、原字节
- 监视条目(Watch):描述、地址、类型、当前值
- 注入 DLL:路径、远端基址、状态
- 壳码(Shellcode):字节、远端地址、线程 ID、状态
- 指令(Instruction):地址、机器码、文本

数据集合操作:列举、读取、写入、添加、删除、刷新。

## 2. 需求(能力)列表

| 编号 | 需求 | 说明 |
|------|------|------|
| R1 | 进程列举 | 枚举系统全部进程(PID/名称/线程数) |
| R2 | 进程附加/分离 | 打开进程句柄建立会话 / 关闭句柄 |
| R3 | 进程信息 | 查询指定进程详细信息 |
| R4 | 进程挂起/恢复 | 挂起/恢复进程全部线程 |
| R5 | 进程结束 | 以指定退出码终止进程 |
| R6 | 内存读取 | 跨进程读取任意地址指定大小 |
| R7 | 内存写入 | 跨进程写入任意地址 |
| R8 | 内存转储 | 读取一段内存返回字节序列 |
| R9 | 内存区域列举 | VirtualQueryEx 遍历内存区域 |
| R10 | 类型化读取 | byte/word/dword/qword/float/double |
| R11 | 模块列举 | 枚举进程已加载模块 |
| R12 | 模块查找/基址 | 按名称查模块与基址 |
| R13 | 导出表解析 | 解析 PE 导出表为符号列表 |
| R14 | 模块转储 | 模块内存导出为文件或十六进制 |
| R15 | 线程列举 | 枚举进程全部线程 |
| R16 | 线程挂起/恢复/结束 | 单线程操作 |
| R17 | 软件断点 | 0xCC 写入 + 原字节保存/恢复 |
| R18 | 硬件断点 | DR0-DR3/DR7 设置与清除 |
| R19 | 页保护断点 | VirtualProtectEx PAGE_GUARD |
| R20 | 调试附加/分离 | DebugActiveProcess/Stop |
| R21 | 单步/步过 | 陷阱标志单步与步过 CALL |
| R22 | 寄存器读写 | 获取/读取指定寄存器 |
| R23 | 反汇编 | x64 指令解码(指定地址/范围) |
| R24 | 特征码扫描 | AOB 模式(含 ??)跨区域扫描 |
| R25 | 监视列表 | watch 增删查刷新(状态持久化) |
| R26 | DLL 注入/弹出 | 远端 LoadLibrary/FreeLibrary |
| R27 | 汇编 | x64 助记符编码为机器码 |
| R28 | 壳码注入 | 远端分配+写入+线程执行 |

## 3. 约束

- 全部能力必须真实调用 Windows 底层 API 实现,禁止模拟
- 公共 API 不得暴露 Windows 类型(windows.h 类型),只允许标准 C++ 类型,保证 CLI 不依赖平台头文件
- 线程安全:可被多个调用方顺序调用(CLI 单线程调用,库内不引入全局可变状态跨调用竞争)
- 错误必须通过 Result 枚举 + 错误消息返回,不抛异常跨边界
