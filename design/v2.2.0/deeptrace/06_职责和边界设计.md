# deeptrace - 职责和边界设计(修改模式,增量,v2.2.0)

> 引用:v2.0.0/deeptrace/06_职责和边界设计.md 既有职责边界。本版本遵循不变:

## 1. 各层职责(沿用)

- **Service 层 inject 模块**:组装业务——校验参数 → 查/改注入记录(load/save_injects)
  → 调用 Infrastructure 原语(RemoteAlloc/WriteRemoteMemory/RemoteFree/
  CreateRemoteThreadEx)→ 填充 InjectInfo。
- **Infrastructure 层**:内存分配/写入/释放、远程线程创建等平台原语,不感知业务记录。
- **Domain 层**:仅类型(InjectInfo/Result/InjectRecord)。
- 算法/日志等与本改动无关,沿用。

## 2. 禁止项(沿用)

- Service 不直接调用 WinAPI(一律经 Infrastructure);不引入平台类型到公共头。
- Infrastructure 不操作注入记录、不做业务判定。
- 公共头仅标准 C++ 类型;头文件包含风格 名字/名字/名字,无相对路径。
