# deeptrace - 静态库需求变更文档(v2.2.0)

> 来源:CLI 流程 v2.2.0 跨流程需求(见 cli/09_能力匹配分析.md、cli/09_静态库流程交接记录.md)。
> 本文档为 cpp_static_flow.md「跨流程需求接收」步骤的输入;接收后进入静态库需求分析。

## 1. 变更概要

- 静态库:deeptrace(v2.1.0 基线,Windows 进程内存操作静态库)。
- 变更:shellcode 注入能力从「写入+立即执行」一体,扩展为可分阶段操作
  (写入不执行 / 触发一次 / 释放清理),支撑 CLI「汇编代码注入并执行」功能。
- 全部复用既有基础设施能力,不新增基础设施。

## 2. 需求变更清单

| # | 能力 | 期望公共 API | 输入 → 输出 |
|---|------|--------------|-------------|
| 1 | 只分配+写入,不执行 | `Result shellcode_alloc(const std::vector<uint8_t>& bytes, InjectInfo& out)` | 机器码字节 → InjectInfo(地址, tid=0, running=false),记录持久化 |
| 2 | 触发已记录地址一次 | `Result shellcode_run(uintptr_t addr, InjectInfo& out)` | 记录内地址 → InjectInfo(地址, 新 TID, running=true),记录更新 |
| 3 | 释放已记录地址 | `Result shellcode_free(uintptr_t addr)` | 记录内地址 → Ok,记录删除 |

## 3. 每项详细要求

### 3.1 shellcode_alloc

- **功能**:在目标进程分配 PAGE_EXECUTE_READWRITE 内存、写入字节、保存注入记录,
  **不创建远程线程**。
- **异常**:
  - 未 attach(无会话句柄)→ `NotAttached`;
  - bytes 为空 → `InvalidArg`;
  - 分配失败 → 返回分配错误;
  - 写入失败/写不全 → 释放已分配内存后返回错误(无残留)。
- **记录**:与既有 shellcode_inject 相同格式(kind=shellcode, hex 字节, addr, tid=0),
  写入 `%TEMP%/deeptrace_<pid>/injects.dat`。
- **验收**:
  1. 无线程产生(running=false);
  2. 内存内容 = 写入字节(memory_read 可验证);
  3. shellcode_status 可见该记录;
  4. 失败路径无内存残留。

### 3.2 shellcode_run

- **功能**:按地址查找 shellcode 注入记录(NotFound 若不存在),CreateRemoteThreadEx(addr, 0)
  创建一条新远程线程执行,更新记录 thread_id。
- **异常**:
  - 未 attach → `NotAttached`;
  - 地址不在记录 → `NotFound`;
  - 创建线程失败 → 错误(记录不变)。
- **验收**:
  1. 每次调用创建一条新远程线程;
  2. 可重复调用(多次 run 均成功);
  3. 记录 TID 反映最近一次触发;
  4. 未记录地址 → NotFound。

### 3.3 shellcode_free

- **功能**:按地址查找 shellcode 注入记录(NotFound 若不存在),RemoteFree 释放内存,
  删除记录。
- **异常**:
  - 未 attach → `NotAttached`;
  - 地址不在记录 → `NotFound`;
  - 释放失败 → 错误(记录保留)。
- **验收**:
  1. 远程内存释放;
  2. 记录删除(再次 run/free 该地址 → NotFound);
  3. 可释放任一 shellcode 记录(alloc/inject/injectat/injectfile/exec 产生的)。

## 4. 约束

- 必须使用真实底层能力(内存分配/释放、远程线程创建),禁止模拟/硬编码/伪造。
- 复用既有基础设施:RemoteAlloc/RemoteFree/WriteRemoteMemory/
  CreateRemoteThreadEx/IsRemoteThreadRunning(见 infrastructure/memory、inject)。
- 对外公共头 include/deeptrace.h 增加 3 个 API 声明;公共类型仅用标准 C++ 类型。
- 完成契约须包含:公共头、API 列表、Debug/Release 产物、能力覆盖结果、测试结果。
