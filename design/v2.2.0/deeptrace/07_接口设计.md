# deeptrace - 接口设计(修改模式,增量,v2.2.0)

> 引用:v2.0.0/deeptrace/07_接口设计.md 既有接口。本版本新增接口细节:

## 1. shellcode_alloc

- 前置:`attach(pid)` 完成(会话句柄有效);bytes 非空。
- 流程:
  1. `RemoteAlloc(handle, bytes.size(), PAGE_EXECUTE_READWRITE, &remote)`;
  2. `WriteRemoteMemory(handle, remote, bytes.data(), bytes.size(), &err)`;
     失败/写不全 → `RemoteFree(remote)` 后返回错误;
  3. 记录 `InjectRecord{"shellcode", hex, remote, 0}` 追加并 save_injects;
  4. out 填充(kind=shellcode, remote_base=remote, thread_id=0, running=false, size)。
- 异常:NotAttached / InvalidArg(空字节)/ 分配错误 / 写入错误(已释放)。

## 2. shellcode_run

- 前置:已 attach;addr 在注入记录中(kind=shellcode)。
- 流程:
  1. load_injects 按 addr 查找 kind=shellcode 记录;无 → NotFound;
  2. `CreateRemoteThreadEx(handle, addr, 0, &tid)`;失败 → 错误(记录不变);
  3. 更新记录 thread_id=tid,save_injects;
  4. out 填充(remote_base=addr, thread_id=tid, running=true)。
- 异常:NotAttached / NotFound / 建线程错误。

## 3. shellcode_free

- 前置:已 attach;addr 在注入记录中(kind=shellcode)。
- 流程:
  1. load_injects 按 addr 查找;无 → NotFound;
  2. `RemoteFree(handle, addr)`;失败 → 错误(记录保留);
  3. 从记录中删除该条,save_injects。
- 异常:NotAttached / NotFound / 释放错误。

## 4. 与既有 API 的关系

- 记录格式/存储与 shellcode_inject 完全一致;alloc/run/free 产生的记录可与
  inject/injectat/status 互操作(inject 记录亦可 run/free;status 显示 alloc 记录
  running=no)。
- 向后兼容:既有全部公共 API 签名与行为不变。
