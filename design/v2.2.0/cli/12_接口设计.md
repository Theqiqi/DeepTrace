# CLI - 接口设计(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/12_接口设计.md 既有接口。本版本新增命令与数据结构:

## 1. 数据结构(沿用,无新增)

- `CommandRequest{group, action, args, pid, pid_set, help, version}` 不变:
  新命令均可用既有结构表达(group/action/args 定长)。
- 新增参数类型 `shellcode-source`(命令层校验:非空字符串;hex/文件判定在接口层)。

## 2. 新增命令的接口层行为

### 2.1 asm file

- 输入:`<path.asm>` + 可选 `--hex`/`--c-array`/`--out <path.bin>`。
- 处理:读文本(不存在/读失败 → 错误)→ `asm_assemble(code, bytes, &text)`
  → `--out` 写 .bin → 输出字节文本(hex 或 C 数组,默认与 assemble 一致)。

### 2.2 hex2bin

- 输入:`<hex> <output.bin>`。
- 处理:hex_bytes 校验(命令层)→ 写 .bin(标准库)→ 输出 `wrote <path> (<n> bytes)`。

### 2.3 shellcode alloc

- 输入:`<source>`(hex 或 .bin 路径,接口层解析)。
- 处理:resolve → `shellcode_alloc(bytes, info)` → print_inject。

### 2.4 shellcode run

- 输入:`<addr>`。
- 处理:`shellcode_run(addr, info)` → print_inject。

### 2.5 shellcode free

- 输入:`<addr>`。
- 处理:`shellcode_free(addr)` → `OK`。

### 2.6 shellcode exec

- 输入:`<source>`(hex / .bin / .asm)。
- 处理:resolve(含 .asm 汇编)→ `shellcode_alloc` → `shellcode_run`(两段,内部
  失败时若已分配则 `shellcode_free` 回滚)→ print_inject。

### 2.7 shellcode injectfile

- 输入:`<path.bin>`。
- 处理:读文件 → `shellcode_inject(bytes, info)` → print_inject。

## 3. source 解析规则(接口层辅助,cmd.h 内新增)

```
resolve_source(s):
  valid_hex_bytes(s)                        -> hex 字节
  否则:file_exists(s)?
    后缀 .asm/.s(仅 exec 支持)              -> 读文本 + asm_assemble
    其余                                    -> 读二进制
  否则                                    -> InvalidArg
```

## 4. 与既有命令的关系

- `shellcode inject`/`injectat`(hex 输入)保持兼容,不接收文件。
- `shellcode status` 显示全部记录(含 alloc 记录, running=no)。
- 所有新命令均经 executor 既有 `-p <pid>` 自动 attach/detach 路径,无新会话逻辑。
