# CLI - 模块设计(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/10_模块设计.md 既有模块结构。本版本改动落在三层既有模块:

## 1. 改动点 → 层/文件

| 改动点 | 层 | 文件 |
|--------|-----|------|
| 新命令登记(asm file / hex2bin / shellcode alloc/run/free/exec/injectfile)与帮助文本 | 命令层 | src/command/commands.cpp |
| 新参数校验(shellcode-source 类型、--out 标志) | 命令层 | src/command/parser.cpp |
| 请求数据结构:不变(CommandRequest 通用) | 命令层 | src/command/request.h |
| asm file 动作(文件汇编 + --out 写 .bin) | 接口层 | src/interface/cmd_asm.cpp |
| hex2bin 命令(hex → .bin 文件) | 接口层 | src/interface/cmd_hex2bin.cpp(新) |
| shellcode alloc/run/free/exec/injectfile 动作 + 文件读取辅助 | 接口层 | src/interface/cmd_shellcode.cpp、cmd.h(辅助) |
| 分派(executor)与自动 attach/detach 路径:新命令复用既有 -p 路径,无新分派 | 接口层 | src/interface/executor.cpp(不变) |
| 输出:复用 print_inject/print_message;hex2bin 新输出格式 | 打印层 | src/printing/printer.cpp(hex2bin 行) |

## 2. 模块职责(沿用)

- 命令层:构造请求对象(参数校验);接口层:经公共 API 调库并执行命令流程;
  打印层:格式化输出。新增文件/函数遵循既有风格。

## 3. 未改动模块

ps/mem/module/thread/debug/disasm/resolve/watch/dll/convert 命令与
script/executor 主路径均不变。
