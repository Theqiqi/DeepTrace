# CLI - 功能点设计(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/07_功能点设计.md 既有功能点。本版本新增/更新受影响功能点。

## 1. 功能点:字节来源解析(source → bytes)

### 1.1 功能分析

- 输入:`shellcode alloc`/`exec` 的 source 参数(非空字符串)。
- 解析规则(界面层,确定性判定):
  1. 合法 hex 字节串(0x 前缀或偶数位 hex 数字,非空)→ 按 hex 解析为字节;
  2. 否则按文件路径处理:`.asm`/`.s`(仅 exec)→ 读文本 → `asm_assemble` → 字节;
     `.bin`/其他 → 按二进制读文件 → 字节;
  3. 文件不存在或读失败 → 错误。
- 错误路径:非法 hex 且非现存文件 → `Error: invalid shellcode source: '<v>'` + 退出 2;
  文件存在但读失败 → `Error: cannot read file: <path>` + 退出 2。
- 能力边界:只支持 hex 字符串 / .bin / .asm(.s);不支持其他格式(PE/obj 等 → 明确报错)。

### 1.2 功能流程

```
resolve(source):
  if valid_hex(source): bytes = hex_bytes(source); return ok
  if !file_exists(source): return InvalidArg
  if ext in {.asm,.s}: text = read_text(source); asm_assemble(text, bytes); return ok
  bytes = read_binary(source); return ok
```

## 2. 功能点:shellcode alloc(写入原语)

### 2.1 功能分析

- 输入:source(hex 或 .bin 路径)。
- 执行:source → bytes → `deeptrace::shellcode_alloc(bytes, info)`。
- 输出:`print_inject(info)`(kind=shellcode, 地址, tid=0, running=no)。
- 错误路径:未 attach → NotAttached + 退出 1;字节为空/分配/写入失败 → 对应错误 + 退出 1
  (分配成功后写入失败须释放已分配内存,无残留)。
- 退出码:0 成功 / 1 业务错误 / 2 用法错误(source 非法或文件不存在)。

### 2.2 功能流程

```
cmd_shellcode alloc:
  bytes = resolve(source)              --fail--> Error + 2
  r = shellcode_alloc(bytes, info)     --fail--> Error + 1
  print_inject(info)
  return 0
```

## 3. 功能点:shellcode run(触发原语)

### 3.1 功能分析

- 输入:已记录地址 addr。
- 执行:`deeptrace::shellcode_run(addr, info)`(静态库查记录 → 创建远程线程 → 更新记录)。
- 输出:`print_inject(info)`(地址, 新 TID, running=yes)。
- 错误路径:未 attach → 退出 1;地址不在记录 → NotFound + 退出 1;创建线程失败 → 退出 1。
- 可重复:对同一地址每次调用创建一条新远程线程(「复用触发」语义)。

### 3.2 功能流程

```
cmd_shellcode run:
  r = shellcode_run(addr, info)        --fail--> Error + 1
  print_inject(info)
  return 0
```

## 4. 功能点:shellcode free(清理原语)

### 4.1 功能分析

- 输入:已记录地址 addr。
- 执行:`deeptrace::shellcode_free(addr)`(释放远程内存 + 删除记录)。
- 输出:`OK`。
- 错误路径:未 attach → 退出 1;地址不在记录 → NotFound + 退出 1;释放失败 → 退出 1。
- 资源配对:alloc/inject/injectat/injectfile/exec 产生的记录均可 free;free 后记录删除,
  再次 run/free 该地址 → NotFound。

### 4.2 功能流程

```
cmd_shellcode free:
  r = shellcode_free(addr)             --fail--> Error + 1
  print OK
  return 0
```

## 5. 功能点:shellcode exec(流水线单入口)

### 5.1 功能分析

- 输入:source(hex / .bin / .asm)。
- 执行:source → bytes(按需汇编)→ `shellcode_alloc` 语义分配写入 → 创建远程线程执行。
- 输出:`print_inject(info)`(地址, TID, running=yes)。
- 错误路径:source 非法/文件不存在 → 退出 2;分配/写入/建线程失败 → 退出 1
  (分配成功后失败须释放,无残留)。
- 一次调用 = 一次完整流程:转换→写入→触发;之后可 run 复用 / free 清理。

### 5.2 功能流程

```
cmd_shellcode exec:
  bytes = resolve(source)              --fail--> Error + 2
  alloc bytes                          --fail--> Error + 1 (cleanup on partial)
  create remote thread at addr         --fail--> free addr; Error + 1
  print_inject(info)
  return 0
```

## 6. 功能点:asm file(汇编文件)

### 6.1 功能分析

- 输入:.asm/.s 文件路径,可选 `--hex`/`--c-array`/`--out <bin>`。
- 执行:读文本(文件不存在/读失败 → 退出 2)→ `asm_assemble(code, bytes, text)`(失败 → 退出 1)
  → 输出 hex 文本或 C 数组;`--out` 时写 .bin(写失败 → 退出 1)。
- 输出语义:无 --out 时仅输出字节文本(与 assemble 一致);有 --out 时输出字节文本 + 文件写出确认。
- 能力边界:与 asm assemble 相同(keystone x64 支持子集由静态库决定)。

### 6.2 功能流程

```
cmd_asm file:
  text = read_text(path)               --fail--> Error + 2
  asm_assemble(text, bytes, &t)        --fail--> Error + 1
  if --out: write_binary(out, bytes)   --fail--> Error + 1
  print bytes (hex | c-array)
  return 0
```

## 7. 功能点:hex2bin(hex → .bin 文件)

### 7.1 功能分析

- 输入:hex 字节字符串 + 输出文件路径。
- 执行:校验 hex(非法 → 退出 2)→ 转字节 → 写 .bin 文件(失败 → 退出 1)。
- 输出:成功打印 `wrote <path> (<n> bytes)`。
- 纯 CLI 标准库文件 I/O,不依赖静态库、不依赖目标进程。

### 7.2 功能流程

```
cmd_hex2bin:
  bytes = hex_bytes(hex)               --fail--> Error + 2
  write_binary(out, bytes)             --fail--> Error + 1
  print wrote <out> (<n> bytes)
  return 0
```

## 8. 功能点:shellcode injectfile(文件注入)

### 8.1 功能分析

- 输入:.bin 文件路径。
- 执行:读文件(不存在/读失败 → 退出 2)→ `shellcode_inject(bytes, info)`(失败 → 退出 1)。
- 输出:与 inject 相同 `print_inject(info)`(立即执行语义)。
- 能力边界:仅 .bin 文件;hex 输入走既有 inject。

### 8.2 功能流程

```
cmd_shellcode injectfile:
  bytes = read_binary(path)            --fail--> Error + 2
  shellcode_inject(bytes, info)        --fail--> Error + 1
  print_inject(info)
  return 0
```
