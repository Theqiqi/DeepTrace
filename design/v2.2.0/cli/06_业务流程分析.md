# CLI - 业务流程分析(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/06_业务流程分析.md 既有业务流程。本版本只重画受影响命令流程。

## 1. shellcode 分阶段流程(新增:alloc → run → free)

```text
准备 shellcode 字节
   │
   ▼
shellcode alloc <hex|bin路径>          ← 写入原语(一次调用一个操作)
   │  分配 PAGE_EXECUTE_READWRITE + 写入 + 记录持久化,不执行
   ▼
输出分配首地址 0x...                    ← 记录供后续操作
   │
   ▼
shellcode run <addr>                   ← 触发原语(可重复:每调用一条新远程线程)
   │  创建远程线程执行一次
   ▼
输出 InjectInfo(地址/TID/running)
   │
   ├─ 需要再次执行 ──► 再次 shellcode run <addr>(复用触发)
   │
   ▼
shellcode free <addr>                  ← 清理原语(痕迹清除)
   │  释放远程内存 + 删除记录
   ▼
输出 OK
```

- 分阶段语义:写入与执行解耦;记录按 PID 持久化(injects.dat),跨 CLI 调用衔接。
- 单条命令边界:每次调用一个操作,执行完立即退出;记录为唯一跨调用状态。

## 2. shellcode 流水线流程(新增:exec)

```text
shellcode exec <source>                ← 一次调用 = 一次完整流程
   │  source 判定:hex 字符串 / .bin 文件 / .asm 文件(自动)
   ├─ hex ──► 字节
   ├─ .bin ─► 读取文件字节
   └─ .asm ─► 读取文本 → 汇编(asm_assemble)→ 字节
   ▼
分配 + 写入(不执行路径复用 alloc 语义)
   ▼
创建远程线程触发一次
   ▼
输出 InjectInfo(地址/TID/running)
   │
   ▼
(后续用户可 shellcode run <addr> 复用 / shellcode free <addr> 清理)
```

- 单条命令边界:一次调用完成「转换→写入→触发」完整流程,立即退出;无跨调用状态依赖。

## 3. asm file / hex2bin 流程(新增,无目标进程依赖)

```text
asm file <path.asm> [--hex] [--c-array] [--out <bin>]
   │  读取汇编源文件文本(不存在/不可读 → Error + 退出 2)
   ▼
asm_assemble(代码)                     ← 静态库公共 API(既有)
   ├─ 失败 ──► Error + 退出 1
   ▼
输出字节(hex 文本 / C 数组);--out 时写出 .bin 文件(写失败 → Error + 退出 1)

hex2bin <hex> <output.bin>
   │  校验 hex(非法 → 用法错误 + 退出 2)
   ▼
写出 .bin 文件(失败 → Error + 退出 1) → 打印路径与字节数
```

## 4. shellcode injectfile 流程(新增)

```text
shellcode injectfile <path.bin>
   │  读取 .bin 文件(不存在/读失败 → Error + 退出 2)
   ▼
分配 + 写入 + 立即执行(与既有 inject 完全一致)   ← 复用既有 shellcode_inject 语义
   ▼
输出 InjectInfo
```
