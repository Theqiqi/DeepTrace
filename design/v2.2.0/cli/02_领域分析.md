# deeptrace_cli - 领域分析(修改模式,增量更新,v2.2.0)

> 引用:v1.4.1/cli/02_领域分析.md 既有领域模型。本版本对受影响集合做增量更新,
> 未受影响集合与操作沿用既有文档。

## 1. 受影响集合:注入集合(增量)

既有注入集合:`dll`(加载/卸载/列举)、`shellcode`(注入/列举)。

v2.2.0 将 shellcode 集合的**操作**按「写入 / 触发 / 清理」拆分,并新增「字节来源」维度:

| 集合 | 元素 | 操作(新增加粗) | 说明 |
|------|------|----------------|------|
| shellcode | 注入记录(kind=shellcode, hex/地址/tid,按 PID 持久化) | 查看(status,既有)、写入(**alloc 新增**)、触发(**run 新增**)、清理(**free 新增**)、写入+触发(inject/injectat/injectfile) | 一次调用一个操作;记录持久化衔接跨调用 |
| 字节来源(新概念,非独立集合) | hex 字符串 / .bin 文件 / .asm 文件 | 解析(**hex/bin/asm → 字节,新增**) | 供写入与流水线命令消费 |

### 关键语义

- **写入(alloc)**:分配 PAGE_EXECUTE_READWRITE + 写入字节 + 记录持久化,**不创建线程**;
  输出分配首地址。
- **触发(run)**:对已记录地址创建远程线程触发一次;已结束的线程不可复用,
  「复用触发」= 对同一地址再次 run(可重复);地址必须在注入记录中(NotFound 否则)。
- **清理(free)**:释放已分配内存 + 删除对应记录(痕迹清除)。
- **流水线(exec)**:字节来源 → 字节 → 分配 → 写入 → 触发,一次调用完成完整流程,
  输出地址与 TID(之后可 run 复用 / free 清理)。

## 2. 受影响集合:汇编集合(增量)

既有汇编集合:操作「汇编(assemble)」输入为内联代码字符串。

v2.2.0 增量:**输入形式扩展为文件(.asm/.s)**,操作可输出 .bin 文件:

| 集合 | 元素 | 操作(新增加粗) | 说明 |
|------|------|----------------|------|
| 汇编 | 代码文本(内联/文件) → 机器码字节 | 汇编字符串(既有 assemble)、汇编文件(**file 新增**) | file 支持 --out 写 .bin |

## 3. 受影响集合:转换集合(增量)

既有 convert(类型化数据 → hex 字节文本)。v2.2.0 增量:**hex → .bin 文件写出**
(独立命令 hex2bin,标准库文件 I/O)。

## 4. 未受影响集合

进程/内存/模块/线程/调试/反汇编/解析/监视等集合与操作沿用既有模型,不重复分析。
