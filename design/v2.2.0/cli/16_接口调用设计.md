# CLI - 接口调用设计(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/16_接口调用设计.md。v2.2.0 新增命令 ↔ 静态库公共 API 映射如下,
> 其余命令映射不变。

## 1. 新增命令 → 静态库公共 API 映射

| 命令 | 静态库 API | 说明 |
|------|-----------|------|
| `asm file <path> [--out]` | `asm_assemble(code, bytes, &text)` | 文件文本 → 字节;--out 写 .bin 为 CLI 标准库 I/O |
| `shellcode injectfile <path>` | `shellcode_inject(bytes, info)` | 读文件 → 既有注入(立即执行) |
| `shellcode alloc <source>` | `shellcode_alloc(bytes, info)` | 分配+写入,不执行 |
| `shellcode run <addr>` | `shellcode_run(addr, info)` | 触发一次(可重复) |
| `shellcode free <addr>` | `shellcode_free(addr)` | 释放+清记录 |
| `shellcode exec <source>` | `asm_assemble`(仅 .asm 输入)→ `shellcode_alloc` → `shellcode_run` | 流水线;失败回滚见 15 §3 |

- `hex2bin <hex> <out>`:无静态库调用(纯 CLI 标准库文件 I/O)。
- source 解析(hex/.bin/.asm 判定):CLI 标准库自实现(cmd.h 辅助),非静态库能力。

## 2. -p 自动 attach/detach 路径覆盖

- 新命令均经 executor 既有 `-p <pid>` 自动 attach → 执行 → detach 路径
  (executor 分派按 group/action 表,新动作登记命令表后自动覆盖,无新会话逻辑)。
- 资源配对:attach/detach 由 executor 统一保证;alloc/exec 的内存与记录由
  静态库 + 15 §3 回滚保证;free 为配对释放入口。

## 3. 检查项

- 每个静态库调用对应真实公共 API:是(上表逐条映射,均为 v2.2.0 契约内 API)。
- 无重复实现:文件 I/O/hex 解析为 CLI 标准库职责;汇编/注入/触发/释放均经静态库。
- 能力完整性:声明支持的输入形式(hex/.bin/.asm)均有实现与正例测试,
  不支持形式(其他扩展名/不存在文件/非法 hex)有负例(明确报错)。
