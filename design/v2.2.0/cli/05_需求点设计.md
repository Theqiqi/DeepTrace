# CLI - 需求点设计(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/05_需求点设计.md 既有需求点。本版本只对受影响需求点做增量更新。

## 1. 新增需求点

### R-ASM-FILE:汇编文件输入

- 命令:`asm file <path.asm> [--hex] [--c-array] [--out <path.bin>]`
- 输入:汇编源文件路径(.asm/.s),可选输出格式标志与 .bin 写出路径
- 输出:机器码字节文本(hex 或 C 数组);指定 `--out` 时同时写出 .bin 文件
- 边界:文件不存在/不可读 → 错误退出 2;汇编失败 → 错误退出 1(经静态库 API)

### R-HEX2BIN:16 进制 → .bin 文件

- 命令:`hex2bin <hex> <output.bin>`
- 输入:合法 hex 字节字符串(0x 前缀或偶数位 hex 数字)+ 输出文件路径
- 输出:写出 .bin 文件;成功打印文件路径与字节数
- 边界:非法 hex → 用法错误退出 2;写出失败 → 错误退出 1

### R-SC-ALLOC:写入 shellcode(不执行)

- 命令:`shellcode alloc <source>`
- 输入:source = hex 字符串或 .bin 文件路径(自动判定)
- 输出:分配首地址(InjectInfo: kind=shellcode, address, tid=0, running=no)
- 语义:分配 PAGE_EXECUTE_READWRITE + 写入 + 记录持久化,**不创建线程**
- 边界:hex 非法 / .bin 不存在 / 目标未 attach → 错误退出 1

### R-SC-RUN:触发 shellcode 一次

- 命令:`shellcode run <addr>`
- 输入:已记录地址
- 输出:InjectInfo(地址, 新 TID, running=yes)
- 语义:对已记录地址创建远程线程触发一次;可重复调用(每调用一条新线程)
- 边界:地址不在注入记录 → NotFound 错误退出 1;未 attach → 错误退出 1

### R-SC-FREE:释放 shellcode

- 命令:`shellcode free <addr>`
- 输入:已记录地址
- 输出:`OK`
- 语义:释放远程内存 + 删除注入记录(痕迹清除)
- 边界:地址不在注入记录 → NotFound 错误退出 1;未 attach → 错误退出 1

### R-SC-EXEC:流水线单入口

- 命令:`shellcode exec <source>`
- 输入:source = hex / .bin 路径 / .asm 路径(自动判定)
- 输出:InjectInfo(地址, TID, running=yes)
- 语义:一次调用完成 转换(.asm 才汇编)→ 分配 → 写入 → 触发;输出地址/TID 供后续 run/free
- 边界:source 非法/文件不存在 → 错误退出 2;执行阶段失败 → 错误退出 1(分配失败时无残留)

### R-SC-INJECTFILE:文件注入(立即执行)

- 命令:`shellcode injectfile <path.bin>`
- 输入:.bin 文件路径
- 输出:InjectInfo(与 inject 相同)
- 语义:读 .bin → 分配 + 写入 + 立即执行(与既有 inject 完全一致)
- 边界:文件不存在/读失败 → 错误退出 1(或 2,见 15_异常设计);未 attach → 错误退出 1

## 2. 受影响既有需求点

- `asm assemble`(不变):内联字符串汇编保持既有行为。
- `shellcode inject/injectat/status`(不变):保留兼容,状态语义不变(记录含 alloc 记录时 running=no)。
- 无交互/纯 ASCII/一次调用一个操作/资源配对约束:全部新需求点满足(复核见 04_需求分析 §3)。
