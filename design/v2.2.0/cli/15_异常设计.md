# CLI - 异常设计(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/15_异常设计.md。v2.2.0 新增命令错误路径与退出码如下,其余不变。

## 1. 错误消息格式(沿用)

统一 `Error: <消息>` 前缀,纯 ASCII,输出到 stderr。

## 2. 新增错误路径与退出码

| 命令 | 场景 | 退出码 | 消息示例 |
|------|------|--------|----------|
| asm file | 文件不存在/不可读 | 2 | `Error: cannot read file: x.asm` |
| asm file | 汇编失败 | 1 | `Error: BadFormat: <code>` |
| asm file | --out 写出失败 | 1 | `Error: cannot write file: out.bin` |
| hex2bin | hex 非法 | 2 | `Error: invalid hex-bytes: 'xyz'` |
| hex2bin | 写出失败 | 1 | `Error: cannot write file: out.bin` |
| shellcode alloc/exec | source 非 hex 且文件不存在 | 2 | `Error: invalid shellcode source: '<v>'` |
| shellcode alloc/exec | 文件存在但读取失败 | 2 | `Error: cannot read file: <path>` |
| shellcode injectfile | 文件不存在/读取失败 | 2 | `Error: cannot read file: <path>` |
| shellcode alloc/run/free/exec/injectfile | 未 attach(-p 缺失/失败) | 1 | `Error: NotAttached`(attach 失败: `Error: attach: NoSuchProcess`) |
| shellcode alloc | 空字节/分配/写入失败 | 1 | `Error: InvalidArg` / `Error: <result>` |
| shellcode run | 地址不在记录 | 1 | `Error: NotFound` |
| shellcode run | 建线程失败 | 1 | `Error: Error` |
| shellcode free | 地址不在记录 | 1 | `Error: NotFound` |
| shellcode free | 线程仍在运行(超时) | 1 | `Error: Timeout` |
| shellcode exec | alloc 后 run 失败 | 1 | `Error: <result>`(已回滚释放,无残留) |

## 3. 资源配对与回滚

- `shellcode alloc`:静态库保证失败路径无残留(分配后写入失败 → 释放)。
- `shellcode exec`:**alloc 成功后 run 失败 → 接口层调用 `shellcode_free` 回滚**,
  再返回错误;保证一次调用无残留。
- `shellcode free`:静态库先等线程(Timeout 不释放)再删记录再释放;无悬垂记录。
- 注入记录(injects.dat)为跨调用持久状态;free 成功即删除记录(痕迹清除)。

## 4. 异常边界

- 无阻塞等待:free 等待线程有 5s 上限(超时返回 Timeout 不释放),其余命令立即返回。
- 能力边界(声明支持/不支持):alloc/exec 支持 hex 与 .bin;exec 额外支持 .asm/.s;
  其他扩展名/不存在路径/非法 hex → 明确报错(见上表),帮助文本不暗示支持。
- 退出码语义:0 成功 / 1 业务错误(目标/库/资源问题)/ 2 用法错误(参数/文件/输入)。
