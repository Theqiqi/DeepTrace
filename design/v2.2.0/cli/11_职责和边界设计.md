# CLI - 职责和边界设计(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/11_职责和边界设计.md 既有职责边界。本版本遵循不变:

## 1. 各层职责(沿用)

- **命令解析层(command)**:参数校验(含新类型 shellcode-source:非空字符串,
  界面层解析为 hex/文件;--out/--hex/--c-array 标志)。不调库。
- **接口调用层(interface)**:只经 deeptrace.h 公共 API 调库(asm_assemble/
  shellcode_alloc/run/free/inject 等);文件读取/写出为 CLI 标准库 I/O
  (不依赖静态库);source 解析在此层完成。不包含静态库内部头文件。
- **命令打印层(printing)**:格式化输出(print_inject/print_message/
  print_bytes;hex2bin 输出格式新增)。

## 2. 禁止项(沿用)

- 命令打印层不直接调库;命令解析层不直接调接口执行。
- 接口调用层不得包含静态库内部头文件;生产代码仅用静态库公共 API + C/C++ 标准库
  (禁平台 API/第三方库)。
- 输出字符串纯 ASCII。
