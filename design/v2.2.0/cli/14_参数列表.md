# CLI - 参数列表(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/14_参数列表.md。v2.2.0 新增参数如下,其余参数不变。

## 1. asm file 参数

| # | 参数 | 位置 | 必填 | 类型 | 取值/校验 |
|---|------|------|------|------|-----------|
| 1 | path | 第 1 个 | 是 | script-path 风格(非空) | 文件存在/可读由接口层校验 |
| 2 | --hex | 标志 | 否 | flag | 匹配 `--hex` |
| 3 | --c-array | 标志 | 否 | flag | 匹配 `--c-array` |
| 4 | --out | 标志 | 否 | flag(值=下一位置参数) | 非空路径;写失败报错 |

> 注:`--out <path>` 以「标志 + 值」形式实现:parser 视 `--out` 为 flag,
> 其后紧跟路径参数(见 5.2 实现说明)。

## 2. hex2bin 参数

| # | 参数 | 位置 | 必填 | 类型 | 取值/校验 |
|---|------|------|------|------|-----------|
| 1 | hex | 第 1 个 | 是 | hex-bytes | 0x 前缀或偶数位 hex 数字 |
| 2 | output | 第 2 个 | 是 | string | 非空 |

## 3. shellcode 新增动作参数

| 动作 | # | 参数 | 类型 | 取值/校验 |
|------|---|------|------|-----------|
| injectfile | 1 | path | string | 非空;文件存在/可读由接口层校验 |
| alloc | 1 | source | shellcode-source(新类型) | 非空;hex 或文件判定在接口层 |
| run | 1 | address | address | 0x 或十进制(>0) |
| free | 1 | address | address | 0x 或十进制(>0) |
| exec | 1 | source | shellcode-source | 非空;hex/.bin/.asm 判定在接口层 |

## 4. 新参数类型:shellcode-source

- 命令层校验:非空字符串(与 script-path 同级,实际内容由接口层解析)。
- 接口层解析规则见 12_接口设计 §3(合法 hex → hex;存在文件 → 按后缀读;
  其余 → InvalidArg)。

## 5. 既有参数

全部不变,引用既有文档。
