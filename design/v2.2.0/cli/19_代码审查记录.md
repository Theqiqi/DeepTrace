## 7. 审查发现与修复记录

| # | 发现 | 修复 |
|---|------|------|
| 1 | shellcode_free 未等待运行中线程直接释放(目标崩溃风险) | 等待线程(5s,Timeout 不释放);Error(线程已消失)视为已结束 |
| 2 | shellcode_alloc 记录保存失败 → 无法追踪的孤儿内存 | 保存失败回滚 RemoteFree |
| 3 | shellcode_free 先释放后删记录 → 记录指向已释放内存 | 先删记录保存,后释放 |
| 4 | cmd_asm.cpp 重复 include interface/cmd.h | 删除冗余行 |
| 5 | alloc 接受 .asm 文件并按二进制静默注入(边界违反) | asm_ok=false 时 .asm/.s 直接 InvalidArg + 负例测试 |
| 6 | exec .asm 汇编失败被映射为退出 2 | BadFormat → 退出 1 + 负例测试 |
| 7 | parser valid_param 的 out-flag 分支不可达死代码 | 删除 |
| 8 | asm file --out 无写出确认(设计 07 要求) | 补 `wrote <path> (<n> bytes)` 输出 |

## 8. 结论

审查通过;发现项已全部修复并回归(修复后 Debug/Release 编译通过、测试全绿)。
