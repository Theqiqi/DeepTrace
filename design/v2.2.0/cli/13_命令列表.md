# CLI - 命令列表(修改模式,增量,v2.2.0)

> 引用:v2.0.0/cli/13_命令列表.md。v2.2.0 新增命令如下,其余命令不变。

## 1. asm 组(新增 file)

```text
asm assemble <code> [--hex] [--c-array]        (不变)
asm file <path.asm> [--hex] [--c-array] [--out <path.bin>]
    Assemble assembly source file to bytes (--out: write raw .bin)
```

## 2. hex2bin 组(新)

```text
hex2bin <hex> <output.bin>
    Write hex bytes to a raw binary file
```

## 3. shellcode 组(新增 5 个动作)

```text
shellcode inject <hex_bytes>              (不变:alloc+write+execute)
shellcode injectat <address> <hex_bytes>  (不变)
shellcode injectfile <path.bin>           Read .bin and inject (execute immediately)
shellcode alloc <source>                  Allocate + write only, print address (no execute)
shellcode run <address>                   Trigger recorded shellcode once (repeatable)
shellcode free <address>                  Free recorded shellcode memory + clear record
shellcode exec <source>                   Pipeline: convert -> write -> trigger in one call
shellcode status                          (不变)
```

- `source` = hex 字节串 或 .bin 文件路径(alloc/exec);exec 另支持 .asm/.s 文件(内存直转)。
- `run`/`free` 仅作用于注入记录中的地址(NotFound 否则)。

## 4. 其余命令组

ps/mem/module/thread/debug/disasm/resolve/watch/dll/convert 全部不变,引用既有文档。
