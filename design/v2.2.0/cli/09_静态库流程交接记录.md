# CLI - 静态库流程交接记录(v2.2.0)

> 「跨流程需求接收」步骤。静态库完成契约返回前,CLI 不得实现接口调用层的相关代码。

## 1. 交接概要

- 发起方:CLI 流程(v2.2.0,修改/添加功能:汇编代码注入并执行)。
- 静态库:deeptrace(v2.1.0 基线)。
- 交接时机:CLI 能力匹配发现 3 项缺失能力,静态库流程被触发。

## 2. 缺失能力清单(逐项:期望公共 API / 输入输出 / 异常要求 / 验收标准)

### M1:只分配+写入,不执行(shellcode_alloc)

- **期望公共 API**:`deeptrace::Result shellcode_alloc(const std::vector<uint8_t>& bytes, InjectInfo& out);`
- **输入**:待注入的机器码字节(非空)。
- **输出**:`InjectInfo{kind="shellcode", remote_base=分配首地址, thread_id=0, running=false, size=字节数}`;
  注入记录持久化(与 shellcode_inject 同格式,`%TEMP%/deeptrace_<pid>/injects.dat`)。
- **异常要求**:未 attach → `NotAttached`;空字节 → `InvalidArg`;分配失败 → 分配错误;
  写入失败 → 释放已分配内存后返回错误(无残留)。
- **验收标准**:
  1. 不产生任何远程线程(无执行副作用);
  2. 分配内存内容 = 写入字节(可用 memory_read 验证);
  3. 记录可被 shellcode_status 查见(running=no);
  4. 失败路径无内存残留。

### M2:对已记录地址创建远程线程触发一次(shellcode_run)

- **期望公共 API**:`deeptrace::Result shellcode_run(uintptr_t addr, InjectInfo& out);`
- **输入**:注入记录中的地址(kind=shellcode)。
- **输出**:`InjectInfo{kind="shellcode", remote_base=addr, thread_id=新建线程TID, running=true}`;
  记录 thread_id 更新。
- **异常要求**:未 attach → `NotAttached`;地址不在记录 → `NotFound`;创建线程失败 → 错误。
- **验收标准**:
  1. 每次调用在 addr 创建**一条新**远程线程并执行;
  2. 可重复调用(多次 run 均成功,「复用触发」语义);
  3. 记录 TID 反映最近一次触发;
  4. 未记录地址 → NotFound。

### M3:释放已分配地址 + 删除记录(shellcode_free)

- **期望公共 API**:`deeptrace::Result shellcode_free(uintptr_t addr);`
- **输入**:注入记录中的地址(kind=shellcode)。
- **输出**:`Result::Ok`;记录删除。
- **异常要求**:未 attach → `NotAttached`;地址不在记录 → `NotFound`;记录线程仍运行
  (等待 5s 超时)→ `Timeout`(不释放);保存/释放失败 → 错误。
- **验收标准**:
  1. 远程内存被释放(VirtualFreeEx);
  2. 记录删除(再次 run/free 该地址 → NotFound);
  3. 可释放经 alloc/inject/injectat/injectfile/exec 产生的任一 shellcode 记录;
  4. 线程仍在运行时 free → Timeout 且不释放(目标不崩溃);
  5. 失败路径不产生悬垂记录(记录指向已释放内存)。

## 3. 约束与要求

- 静态库实现必须使用真实底层能力(内存分配/释放、远程线程创建),禁止模拟数据、
  硬编码结果或伪造 API。
- 公共 API 签名须与上表一致;对外头文件 include/deeptrace.h 更新并同步文档。
- 复用既有基础设施:RemoteAlloc/RemoteFree/WriteRemoteMemory/CreateRemoteThreadEx/
  IsRemoteThreadRunning(均已有,无需新增基础设施)。
- 静态库流程完成后输出**静态库完成契约**,跳回 CLI 的「API 能力覆盖性匹配」阶段重新匹配。
