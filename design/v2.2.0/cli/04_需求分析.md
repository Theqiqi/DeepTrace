## 1. 已确认的设计决策(想法收集阶段的开放问题)

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 命令形态 | **独立子命令组合**:每条命令一个操作,工具功能分开、使用时组合 |
| 2 | `shellcode inject` 执行语义 | **保留兼容**(分配+写入+立即执行不动);新增 alloc(只写入不执行)/run(触发)/free(清理) |
| 3 | .asm 文件处理 | **`asm file <path> [--out <bin>]`** 汇编文件→字节,可选写 .bin |
| 4 | hex → .bin 写出 | **独立 `hex2bin <hex> <path.bin>` 命令** |
| 5 | 远程线程触发语义 | 新增 `shellcode run <addr>`:对已分配地址创建远程线程**触发一次,可重复**;「复用」= 对同一地址再次 run;「清除痕迹」= `shellcode free <addr>` |
| 6 | 流水线单入口 | 新增 `shellcode exec <source>`:**一次调用 = 转换→写入→触发完整流程**,输出地址/TID,之后可 run 复用 / free 清理 |

## 3. 无交互与纯 ASCII 约束复核

- 新命令无任何阻塞输入等待(getchar/scanf/cin 不出现);文件读取为文件 I/O,不等待用户输入;执行完立即退出。
- 所有输出(帮助/错误/结果)纯 ASCII;错误消息统一 `Error:` 前缀。
- 一次调用一个操作;资源成对(分配/释放、触发/清理)按命令配对,`free` 与 `exec` 完成/失败路径均保证释放语义(见 15_异常设计)。
- 新增/修改需求点均满足无交互与纯 ASCII 约束。

## 4. 能力边界声明(声明支持 / 不支持)

- `alloc`/`exec` 的 source 支持:合法 hex 字符串、存在的 .bin 文件;`exec` 额外支持存在的 .asm/.s 文件(读文本→汇编)。**不支持**:其他扩展名文件、不存在的文件路径、非法 hex → 明确报错。
- `run`/`free` 仅作用于**注入记录中存在**的地址(经 alloc/inject/injectat/injectfile/exec 产生的记录);任意未记录地址 → `NotFound` 报错。
- `inject`/`injectat` 保持 hex 输入不变(不接收文件);文件注入走 `injectfile`。
- shellcode 为裸机字节序列(无 PE 头/重定位);**不支持**含需重定位/导入表的 PE 注入(文档与帮助文本不暗示支持)。
