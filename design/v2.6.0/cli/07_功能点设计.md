# CLI - 功能点设计(修改模式,增量,v2.6.0)

> 引用:v2.5.0/cli/07_功能点设计.md。v2.6.0 仅新增「符号寻址」功能点,其余不变。

## 1. 新增功能点:符号寻址

### 1.1 描述

地址型参数(如 `mem read` 的第一个参数、`watch add` 的第二个参数)除数字地址外,
接受脚本符号名(ASCII 标识符形状)。接口层解析流程:

```
address_token:
  ├─ 数字解析成功(纯数字 / 0x 前缀十六进制) ──→ 作为地址使用(行为不变)
  └─ 否则 ──→ deeptrace::script_symbol(token, &addr)
                ├─ Ok      → 作为地址使用
                ├─ NotFound→ Error: NotFound(token) 退出 1
                └─ 其他    → report_error 退出 1(NotAttached 等)
```

### 1.2 涉及命令与参数

| 命令 | 参数位置 | 现状 | v2.6.0 |
|------|----------|------|--------|
| mem read <addr> [size] [fmt] | 1 | to_addr | resolve_addr |
| mem write <addr> <value> [fmt] | 1 | to_addr | resolve_addr |
| mem dump <addr> <size> | 1 | to_addr | resolve_addr |
| mem readval <addr> <type> | 1 | to_addr | resolve_addr |
| disasm at <addr> [count] | 1 | to_addr | resolve_addr |
| disasm range <start> <end> | 1,2 | to_addr | resolve_addr |
| watch add <desc> <addr> <type> | 2 | to_addr | resolve_addr |
| shellcode injectat <addr> <hex> | 1 | to_addr | resolve_addr |
| shellcode run <addr> | 1 | to_addr | resolve_addr |
| shellcode free <addr> | 1 | to_addr | resolve_addr |

### 1.3 正常路径

```
deeptrace_cli -p <pid> mem read sunObjPtr 8
  → parser: address 参数 "sunObjPtr" 形状合法
  → attach(pid)
  → resolve_addr("sunObjPtr") → script_symbol → Ok(0x7FF6...)
  → memory_read(0x7FF6..., 8) → 打印字节 → detach → 退出 0
```

### 1.4 错误路径

| 场景 | 层 | 输出 | 退出码 |
|------|----|------|--------|
| 符号未注册 | 接口层 script_symbol→NotFound | `Error: NotFound(sunObjPtr)` | 1 |
| 名字含非法字符(`foo bar`) | 解析器 | `Error: invalid address: 'foo bar'` | 2 |
| 无 session | 接口层 script_symbol→NotAttached | `Error: NotAttached` | 1 |
| 目标进程无此符号但数字解析不出 | 同上 | `Error: NotFound(...)` | 1 |

### 1.5 能力边界声明

- 支持:已注册脚本符号按名引用(所有 address 类型参数)。
- 不支持:未注册符号(NotFound)、非标识符形状(用法错误)、无 attach(NotAttached)。
- 帮助文本新增一句说明:地址参数支持数字地址或脚本符号名。

## 2. 其余功能点

mem/disasm/watch/shellcode 的数字地址读写、监视、注入等既有行为全部不变。
