# CLI - 异常设计(修改模式,增量,v2.6.0)

> 引用:v2.5.0/cli/15_异常设计.md。v2.6.0 新增符号寻址错误路径。

## 1. 新增错误路径(符号寻址)

| 场景 | 层 | 退出码 | 输出 |
|------|----|--------|------|
| 符号未注册(未 run / 已 disable) | 接口层(script_symbol→NotFound) | 1 | `Error: NotFound(sunObjPtr)` |
| 无 session(-p 缺失/失败) | 接口层(script_symbol→NotAttached) | 1 | `Error: NotAttached` / `Error: attach: NoSuchProcess` |
| 符号名字形状非法(`foo bar`/`a-b`/`0xZZ`) | 解析器 | 2 | `Error: invalid address: 'foo bar'` |
| 符号名纯数字形状但被当作地址 | 解析器/接口层 | - | 按数字地址处理(不报错;边界记录在案) |

## 2. 错误消息格式

- 统一 `Error: <消息>` 前缀,纯 ASCII(沿用 report_error / parser 既有格式)。
- 符号相关上下文以参数原样回显(`Error: NotFound(<symbol>)`),便于定位。

## 3. 既有错误路径

数字地址读写/监视/注入的既有错误(ReadFault/WriteFault/InvalidArg 等)不变;
无阻塞等待、退出码语义(0 成功 / 1 业务错误 / 2 用法错误)不变。
