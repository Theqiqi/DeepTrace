# CLI - 模块设计(修改模式,增量,v2.6.0)

> 引用:v2.5.0/cli/10_模块设计.md。v2.6.0 改动落点:解析层(parser)参数校验 +
> 接口层(executor/cmd_*)地址解析,打印层无改动。

## 1. 改动点 → 层 / 文件映射

| 改动点 | 层 | 文件 | 说明 |
|--------|----|------|------|
| address 参数接受符号形状 | 命令解析层 | src/command/parser.cpp | `valid_address` 扩展:数字 或 ASCII 标识符 |
| 符号名形状校验(新增) | 命令解析层 | src/command/parser.cpp | `valid_symbol_shape`(本地函数) |
| 地址解析 helper(新增) | 接口调用层 | src/interface/executor.cpp、cmd.h | `resolve_addr(s, &addr)` 先数字后符号 |
| 各命令接入 resolve_addr | 接口调用层 | cmd_memory/cmd_disasm/cmd_watch/cmd_shellcode | 替换 to_addr 调用点 |
| 静态库新 API | 静态库(见 deeptrace 流程) | DeepTrace/... | `script_symbol(name, &addr)` |

## 2. 职责边界(与既有约定一致)

- 命令解析层:只校验形状(数字 或 标识符),不查符号记录(无 session,纯语法)。
- 接口调用层:attach 后调用静态库 `script_symbol` 解析符号;所有 deeptrace 调用
  必须对应公共 API(deeptrace.h)。
- 命令打印层:无改动(错误输出沿用 report_error)。
