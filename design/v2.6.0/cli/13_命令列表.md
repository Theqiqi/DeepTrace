# CLI - 命令列表(修改模式,增量,v2.6.0)

> 引用:v2.5.0/cli/13_命令列表.md。v2.6.0 **不新增命令**;地址型参数支持符号名。

## 1. 命令列表(命令不变,参数语义增强)

```text
mem read <address> [size] [format]
mem write <address> <value> [format]
mem dump <address> <size>
mem readval <address> <type>
disasm at <address> [count]
disasm range <start> <end>
watch add <description> <address> <type>
shellcode injectat <address> <hex_bytes>
shellcode run <address>
shellcode free <address>
```

- `<address>`(及 range 的 start/end)v2.6.0 起接受两种形式:
  1. 数字地址(纯数字或 0x 前缀十六进制)——行为与 v2.5.0 完全一致;
  2. 脚本符号名(ASCII 标识符,由 `script run` 的 alloc 注册)——CLI 自动解析为
     记录地址后执行,如 `mem read sunObjPtr 8`、`watch add ptr sunObjPtr qword`。
- 符号不存在 → `Error: NotFound(...)` 退出 1;名字形状非法 → 用法错误退出 2。
- 帮助文本:build_help_text 中地址参数简介追加说明「address: number or script symbol」。

## 2. script 组及其余命令组

script 组命令(v2.5.0 起:check/run/disable/status)不变;
ps/module/thread/debug/resolve/dll/convert/asm/hex2bin 全部不变。
