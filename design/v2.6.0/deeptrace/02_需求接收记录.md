# deeptrace - 跨流程需求接收记录(v2.6.0)

> 来源:CLI v2.6.0 流程(符号寻址)。跳转目标:静态库流程「跨流程需求接收」步骤。

## 1. 接收的缺失能力

CLI 地址参数需按名引用脚本符号(人造指针槽位)。CLI 现有消费方式仅
`script_status`(全量列表)与 `script_free`(按名释放,但无地址返回)。缺
「按符号名直接查地址」的公共 API,CLI 不得自行解析 scripts.dat(记录格式为静态
库内部实现),故进入静态库流程补充。

## 2. 期望公共 API

```
Result script_symbol(const std::string& name, uintptr_t* out_addr);
```

## 3. 输入输出

| 项 | 说明 |
|----|------|
| 输入 | name:脚本符号名(ASCII 标识符);out_addr:输出地址 |
| 输出 | Ok + 地址;NotFound(未注册)/ NotAttached(无 session)/ InvalidArg(非法名/空指针) |
| 异常要求 | 只读查询,不修改记录;记录缺失文件视为空(NotFound) |
| 验收标准 | 真实 target 上 alloc 后可按名查到同一地址;free 后 NotFound |
