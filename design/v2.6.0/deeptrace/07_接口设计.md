# deeptrace - 接口设计(v2.6.0,增量)

## 1. 公共 API 声明

```cpp
// include/deeptrace.h, script 段(在 script_status 之后)
Result script_symbol(const std::string& name, uintptr_t* out_addr);
```

## 2. 实现要点(service/script.cpp)

```cpp
Result script_symbol(const std::string& name, uintptr_t* out_addr) {
    auto& s = internal::session();
    if (!s.handle) return Result::NotAttached;
    if (!valid_symbol_name(name) || !out_addr) return Result::InvalidArg;

    auto recs = internal::load_script_symbols(s.pid);
    for (const auto& r : recs) {
        if (r.name == name) {
            *out_addr = r.address;
            return Result::Ok;
        }
    }
    return Result::NotFound;
}
```

- 只读查询,无写路径,无资源获取/释放,配对约束不涉及。
- 错误语义与 script_free 一致(NotFound/NotAttached/InvalidArg)。

## 3. 消费方

CLI 接口层 `resolve_addr`:数字解析失败后调用本 API;Ok → 用地址继续,
NotFound/NotAttached → report_error(退出 1)。
