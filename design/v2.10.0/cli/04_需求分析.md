> 模块+偏移/符号+偏移/绝对地址),解决指针链读取与批量读写的入口缺口。

## 2. 需求说明

### 2.1 批量定位器 JSON 配置(新增功能点)

**动机**:指针链(多级偏移)读取、批量读写关键值(游戏 HP/MP/等级等)是高频
需求;现有命令逐条手抄中间指针,繁琐易错。CLI 保持基本显性能力不变,复杂
交互由 JSON 配置承载(用户定稿模型)。

**输入**:`mem batch read <file.json>` / `mem batch write <file.json>`;
JSON 为顶层 version/process/values 对象,每项 = 定位器定义
(base/offsets/type[+module|symbol|count|value])。

**处理**:
- 解析 JSON → OffsetPath 列表(校验 version/寻址源三态/type/count/value)。
- process 存在时 attach 后比对目标进程名(不匹配 → 退出 1)。
- 逐项解析定位器:根地址 = module?resolve_base+base : symbol?script_symbol :
  base(绝对);链遍历:每级 memory_read(qword 指针)+ 偏移;得最终地址。
- read:按 type 读值;write:按 type 解析 value 写入最终地址。

**输出**:表格式(name + 最终地址 + 值),一次打印全部条目。

**无交互约束**:一次调用一操作、执行完立即退出;attach 由 executor 统一
处理(-p 或默认会话)。

### 2.2 受影响既有功能点(无修改)

- mem read/write/readval 等既有命令与符号寻址(v2.6.0)、near 就近分配
  (v2.7.0)完全不变;batch 为 mem 组新增动作。

## 3. 能力边界(声明支持 / 不支持)

- 支持:批量定位器读/写;寻址源三态(module+base / symbol / 绝对地址);
  多级偏移链;8 种类型;process 校验;字符串链末端(string 遇 NUL 停,
  上限 256);字节数组(bytes + count)。
- 不支持/错误:
  - version ≠ 1 / 寻址源冲突或缺 / type 非法 / count 缺失或非法(仅 bytes)
    / 写模式 value 缺失 → 用法错误退出 2。
  - 模块未加载 → NotFound 退出 1;符号未注册 → NotFound 退出 1;
    链中间读失败 → ReadFault 退出 1;process 不匹配 → 退出 1。
  - 指针链搜索(反查)不做(独立后续版本)。
- 逐条失败策略:单条目失败报错并继续其余条目,最终退出码反映是否全成
  (实现期定稿)。

## 4. 需求点设计

| 需求点 | 说明 |
|--------|------|
| R1 定位器 JSON | version/process/values,每项 base+offsets+type(+module/symbol/count/value) |
| R2 批量读 | 逐项定位 → 最终地址 → 按 type 读值 → 表格打印 |
| R3 批量写 | 逐项定位 → 最终地址 → 写 value |
| R4 寻址源三态 | module+base(模块内偏移)/ symbol(脚本符号)/ base(绝对地址),互斥 |
| R5 链遍历 | offsets 每级 memory_read(qword) + 偏移 |
| R6 类型系统 | byte/word/dword/qword/float/double/string/bytes(+count) |
| R7 process 校验 | 可选;attach 后比对进程名,不匹配退出 1 |
| R8 错误语义 | 配置非法(2)/ 业务失败(1)区分;逐条失败继续 |
