# CLI - 异常设计(修改模式,功能,v2.10.0)

> 引用:v2.9.0/cli/15_异常设计.md。v2.10.0 新增导出参数错误路径,
> 既有 batch 错误路径全部不变。

## 1. 新增错误路径(--format / --out)

| 场景 | 层 | 退出码 | 输出 |
|------|----|--------|------|
| --format 取值非法(非 table/csv/json) | 命令解析层 | 2 | `invalid --format: '<值>'` |
| --format 缺值(后无 token) | 命令解析层 | 2 | `missing argument for option: --format` |
| --out 缺值 | 命令解析层 | 2 | `missing argument for option: --out` |
| --out 写文件失败(路径不可写等) | 执行层 | 1 | `Error: cannot write file: <path>` |

## 2. 错误语义关键点

- 导出参数属用法错误 → 退出 2;落盘失败属业务错误 → 退出 1。
- 逐条失败继续策略不变:导出文件内失败项 status=error + error 消息,
  信息不丢失;最终退出码 0/1 语义不变。
- 表格(缺省)失败行仍显示 `error` 字符串,与 v2.9.0 完全一致。

全部不变,引用既有文档。
