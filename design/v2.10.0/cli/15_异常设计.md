# CLI - 异常设计(新建模式,功能,v2.9.0)

> 引用:v2.8.0/cli/15_异常设计.md。v2.9.0 新增批量定位器错误路径。

## 1. 新增错误路径(mem batch read/write)

| 场景 | 层 | 退出码 | 输出 |
|------|----|--------|------|
| JSON 语法错误(行/列定位) | batch 解析器 | 2 | `batch parse error at line N col M: ...` |
| version ≠ 1 | batch 解析器 | 2 | `invalid version 'N' (expected 1)` |
| 寻址源缺失/冲突(module+symbol 同现) | batch 解析器 | 2 | `item '<name>': ...` |
| type 非法 / count 缺失或非法(仅 bytes) | batch 解析器 | 2 | 同上 |
| write 模式 value 缺失/非法 | batch 解析器 | 2 | 同上 |
| 文件不可读 | batch 解析器 | 2 | `cannot read file: <path>` |
| process 不匹配 | 执行层 | 1 | `Error: NotFound(process mismatch: <name>)` |
| 模块未加载 | 执行层(resolve_base) | 1(条目) | `Error: NotFound(<module>)` |
| 符号未注册 | 执行层(script_symbol) | 1(条目) | `Error: NotFound(<symbol>)` |
| 链中间读失败 | 执行层(memory_read) | 1(条目) | `Error: ReadFault(<addr>)` |
| 写失败 | 执行层(memory_write) | 1(条目) | `Error: WriteFault(<addr>)` |

## 2. 错误语义关键点

- **配置错误(2)vs 业务失败(1)**:JSON 结构/取值问题属用法错误退出 2;
  运行期失败(模块/符号/读写)属业务错误退出 1。
- **逐条失败继续**:单条目失败打印该条错误并继续其余条目;存在失败条目
  → 最终退出 1,全成 → 0。失败条目在表格中以 `error` 占位。
- 退出码与既有语义一致(0 成功 / 1 业务错误 / 2 用法错误)。

## 3. 既有错误路径

符号寻址(v2.6.0)、near 就近分配(v2.7.0)、mem write 符号(v2.8.0)
等既有错误路径全部不变。
