# CLI - 功能点设计(修改模式,功能,v2.10.0)

> 引用:v2.9.0/cli/07_功能点设计.md。v2.10.0 新增「批量结果导出」改动点,
> 定位器 JSON/链遍历/类型系统不变。

## 1. 新增功能点:批量结果导出(mem batch --format/--out)

### 1.1 命令形态

```text
mem batch read  <file.json> [--format table|csv|json] [--out <file>]
mem batch write <file.json> [--format table|csv|json] [--out <file>]
```

- `--format` 缺省 `table`:输出与 v2.9.0 完全一致(向后兼容)。
- `--format csv`:CSV 输出,固定列 `name,address,value,status,error`,
  首行 header;字段含逗号/引号/换行时按 RFC4180 双引号包裹、内部引号加倍。
- `--format json`:JSON 对象数组;字符串按 JSON 转义;address 保持
  `0x` 十六进制字符串(避免大数精度问题)。
- `--out <file>`:结果写文件(纯 ASCII 文本);缺省 stdout。
- read 导出列:`name,address,value,status,error`。
- write 导出列:`name,address,status,error`(value 恒空)。

### 1.2 行语义

| status | 含义 | value | error |
|--------|------|-------|-------|
| ok | 该条目成功 | read:读到的值;write:空 | 空 |
| error | 该条目失败(定位/读写) | 空 | 错误消息(result_message + 上下文) |

### 1.3 正常路径

```text
mem batch read paths.json --format json --out out.json
  → attach(pid) → process 校验(可选)
  → 逐项: 定位 → 链遍历 → 读值(收集 name/address/value/status)
  → printer 格式化 JSON → stdout 或写 out.json → detach → 退出 0
```

### 1.4 错误路径

| 场景 | 层 | 退出码 |
|------|----|--------|
| --format 取值非法 / 缺值 | 命令解析层 | 2 |
| --out 缺值 | 命令解析层 | 2 |
| --out 写文件失败 | 执行层 | 1 |
| batch 既有错误(JSON 配置 2 / 业务失败 1) | 不变 | 不变 |

- 逐条失败仍继续其余条目;存在失败条目 → 最终退出 1,全成 → 0。
- 导出文件内的失败项以 status=error + error 消息体现(不丢失信息)。

### 1.5 输出示例

```text
# table(缺省,同 v2.9.0)
name            address              value
player_hp       0x00007FF62A1B2100   0x3E8
bad_item        0x0000000000000000   error

# csv
name,address,value,status,error
player_hp,0x00007FF62A1B2100,0x3E8,ok,
bad_item,0x0000000000000000,,error,NotFound(bad_item)

# json
[{"name":"player_hp","address":"0x00007FF62A1B2100","value":"0x3E8","status":"ok","error":""},{"name":"bad_item","address":"0x0000000000000000","value":"","status":"error","error":"NotFound(bad_item)"}]
```

### 1.6 能力边界声明

- 支持:table/csv/json 三格式;--out 落盘;read/write 两模式导出;
  status/error 字段;CSV/JSON 转义。
- 不支持:其它格式(yaml/xml 等);--format 与 --out 之外的新 flag。
- 帮助文本:mem 组 batch 两行更新,说明 --format/--out。
