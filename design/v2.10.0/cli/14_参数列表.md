# CLI - 参数列表(修改模式,功能,v2.10.0)

> 引用:v2.9.0/cli/14_参数列表.md。v2.10.0 为 mem batch 增加 --format/--out 参数。

## 1. mem batch 命令参数

| 命令 | # | 参数 | 必填 | 类型 | 校验 |
|------|---|------|------|------|------|
| mem batch read | 1 | file | 是 | string | 可读文件(存在性由接口层查) |
| mem batch read | 2 | --format | 否 | format-flag | 取值 table\|csv\|json;缺省 table |
| mem batch read | 3 | --out | 否 | out-flag | `--out <file>`;缺省 stdout |
| mem batch write | 1 | file | 是 | string | 同上 |
| mem batch write | 2 | --format | 否 | format-flag | 同上 |
| mem batch write | 3 | --out | 否 | out-flag | 同上 |

- `--format` 为 value-bearing flag(仿 convert `--out` 的 out-flag 机制):
  `--format <值>` 两个 token;缺省 table 时输出与 v2.9.0 一致。
- `--out` 复用既有 out-flag 解析:`--out <file>` 两个 token;缺省 stdout。
- 两个 flag 均可省略、可同时出现;解析器按 spec 顺序消费(先 --format 后
  --out,与 convert 的 flag 消费机制一致)。
- 交互示例:
  - `mem batch read paths.json`(表格,同 v2.9.0)
  - `mem batch read paths.json --format json`(JSON 到 stdout)
  - `mem batch read paths.json --format csv --out out.csv`(CSV 落盘)
