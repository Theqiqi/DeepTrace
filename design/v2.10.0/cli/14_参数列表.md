# CLI - 参数列表(新建模式,功能,v2.9.0)

> 引用:v2.8.0/cli/14_参数列表.md。v2.9.0 新增 mem batch read/write 的 file
> 参数;JSON 内部字段见下。

## 1. mem batch 命令参数

| 命令 | # | 参数 | 必填 | 类型 | 校验 |
|------|---|------|------|------|------|
| mem batch read | 1 | file | 是 | string | 可读文件(存在性由接口层查) |
| mem batch write | 1 | file | 是 | string | 同上 |

## 2. JSON 内部字段(batch 模块校验)

| 字段 | 位置 | 必填 | 取值/校验 |
|------|------|------|-----------|
| version | 顶层 | 是 | 数字 == 1 |
| process | 顶层 | 否 | 字符串;存在时 attach 后比对进程名 |
| values | 顶层 | 是 | 对象;name → 定位器定义;name 非空且唯一 |
| module | 定位器 | 否 | 字符串;与 symbol 互斥 |
| base | 定位器 | 条件 | hex/十进制地址;有 module 时为模块内偏移;无 module 且无 symbol 时必填(绝对地址) |
| symbol | 定位器 | 否 | 脚本符号名形状;与 module 互斥 |
| offsets | 定位器 | 否 | 字符串数组,每项 hex/十进制偏移 |
| type | 定位器 | 是 | byte/word/dword/qword/float/double/string/bytes |
| count | 定位器 | 条件 | 仅 type=bytes 必填,数字 > 0 |
| value | 定位器 | 条件 | 仅 write 模式必填;按 type 校验 |

## 3. 其余参数

命令组其余参数全部不变,引用既有文档。
