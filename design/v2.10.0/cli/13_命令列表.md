# CLI - 命令列表(修改模式,功能,v2.10.0)

> 引用:v2.9.0/cli/13_命令列表.md。v2.10.0 为 mem batch 增加导出参数。

## 1. mem 组命令改动

```text
mem batch read <file.json> [--format table|csv|json] [--out <file>]
    批量执行 JSON 定位器:逐项解析最终地址并按 type 读值
    --format csv|json:结构化导出(供工具/AI 消费);缺省 table 表格
    --out <file>:导出结果写文件;缺省 stdout

mem batch write <file.json> [--format table|csv|json] [--out <file>]
    批量执行 JSON 定位器:逐项解析最终地址并按 type 写 value
    --format csv|json:导出每项 name/address/status/error(value 空)
    --out <file>:导出结果写文件;缺省 stdout
```

- JSON 文件格式、定位器三态、offsets/type/count/value 语义与 v2.9.0 完全
  一致(引用 v2.9.0 文档),本次不改。
- 导出字段(read):`name,address,value,status,error`;
  导出字段(write):`name,address,status,error`(value 列空)。
  - CSV 固定列 `name,address,value,status,error`,header 一行。
  - JSON 为对象数组,键名同上。
  - 失败项 status=`error`、value 空、error 为错误消息;成功项 status=`ok`。
- 帮助文本:mem 组 batch 两行更新,说明 --format/--out。

## 2. 其余命令

mem 其余动作、module/thread/disasm/watch/script/shellcode 等全部不变。
