# 想法收集 — v2.10.0: mem batch 输出导出 CSV/JSON

## 输入想法

> 给 mem batch 输出加 CSV/JSON 导出选项,方便喂给其他工具或 AI。

## 现状分析

- `mem batch read <file.json>` 目前只输出固定表格(NAME/ADDRESS/VALUE,`print_batch_read`),无法直接被脚本/jq/AI 消费。
- `mem batch write` 逐条打印 `OK <name>`,同样无结构化导出。
- CLI 已有 `--out` out-flag 先例(`asm file --out <path.bin>`),解析器支持 value-bearing flag。
- `BatchRow { name, address, value }` 无状态字段,失败项 value 显示 `"error"` 字符串,机器解析不友好。

## 期望行为(与用户确认后的定稿)

1. `mem batch <read|write> <file.json> [--format table|csv|json] [--out <file>]`
   - `--format` 缺省 `table`(现状不变);`csv`/`json` 输出结构化数据。
   - `--out <file>`:把导出结果写到文件(否则 stdout)。
2. read/write 都支持导出:
   - read:每行 `{name, address, value, status, error}`。
   - write:每行 `{name, address, status, error}`(value 空,只报结果)。
3. 失败项:status=error,value 空,error 消息独立字段;成功项 status=ok。
4. CSV 列固定 `name,address,value,status,error`;JSON 为对象数组。
5. 供其他工具/AI 消费:格式必须是标准 CSV/JSON(纯 ASCII,可被 json.loads / csv 解析)。

## 约束

- 纯 ASCII 输出;一次调用一个操作;退出码语义不变(0 成功/1 业务错误/2 用法错误)。
- 打印层只做格式化(可单测纯函数),落盘在接口层。
- 无静态库改动(纯 CLI 组合既有 API 的格式化能力)。

v2.10.0(功能位 +1)。
