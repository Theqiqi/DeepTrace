## 1. 改动点 → 层 / 文件映射

| 改动点 | 层 | 文件 | 说明 |
|--------|----|------|------|
| BatchRow 加 status/error 字段 | 打印层 | src/printing/printer.h | 行语义扩展 |
| 格式化纯函数 | 打印层 | src/printing/printer.cpp | batch_rows_text(rows, format):table/csv/json 序列化(可单测) |
| CSV/JSON 转义 | 打印层 | 同上 | RFC4180 引号 / JSON 字符串转义 |
| mem batch 参数 | 命令解析层 | src/command/commands.cpp | batch 条目加 --format/--out 参数 + 帮助文本 |

| 输出路由/落盘 | 接口调用层 | src/interface/cmd_memory.cpp | 收集 rows → printer 格式化 → stdout 或 write_text_file |

## 2. 职责边界(与既有约定一致)

- **打印层**:batch_rows_text 为纯格式化函数(不写文件、不调 deeptrace);
  CSV/JSON 转义在此层完成;输出纯 ASCII。
- **接口调用层**:cmd_memory 收集 BatchRow(status/error) → 调 printer
  格式化 → 有 --out 时调 internal::write_text_file 落盘;所有 deeptrace
  调用仍对应公共 API,零新增。
- **命令解析层**:format-flag 仿 out-flag 机制(两个 token 消费);非法值
  报用法错误退出 2。
- **静态库**:零改动。
