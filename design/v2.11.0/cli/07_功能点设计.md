# CLI - 功能点设计(修改模式,功能,v2.11.0)

> 引用:v2.10.0/cli/07_功能点设计.md。v2.11.0 改动点:attach 权限透出。

## 1. 新增功能点:attach 权限透出(ps attach)

### 1.1 命令形态

```text
ps attach <pid>
```

行为不变(附加到进程),输出增强:成功时附加权限摘要。

### 1.2 正常路径

```text
ps attach 1234
  → deeptrace::attach(1234) → Ok
  → deeptrace::session_permissions(&mask) → Ok
  → printer 语义化 mask → "read|write|vm_operate|create_thread|..."
  → 输出 "OK (permissions: read|write|...)"
  → 退出 0
```

### 1.3 错误路径

| 场景 | 层 | 退出码 |
|------|----|--------|
| attach 失败(AccessDenied/NoSuchProcess) | 执行层 | 1(既有) |
| session_permissions 异常(防御性) | 执行层 | 输出既有 OK(不掩盖 attach 结果) |

### 1.4 输出示例

```text
$ deeptrace_cli ps attach 1234
OK (permissions: read|write|vm_operate|create_thread|suspend_resume|query)

# 只读权限场景(降权成功)
$ deeptrace_cli ps attach 4321
OK (permissions: read|query)
```

### 1.5 能力边界声明

- 支持:attach 成功后权限名列表(read/write/vm_operate/create_thread/
  suspend_resume/terminate/query/query_limited/dup_handle/create_process/
  set_quota/set_info);缺失位不显示。
- 不支持:权限掩码的原始十六进制展示;独立探测 API。
- 帮助文本:ps attach 简介更新为「Attach to a process (shows permissions)」。

## 2. 其余功能点

ps 其余动作、mem batch 导出(v2.10.0)、脚本引擎等全部不变。
