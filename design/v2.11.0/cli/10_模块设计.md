# CLI - 模块设计(修改模式,功能,v2.11.0)

> 引用:v2.10.0/cli/10_模块设计.md。v2.11.0 改动落点:

## 1. 改动点 → 层 / 文件映射

| 改动点 | 层 | 文件 | 说明 |
|--------|----|------|------|
| 权限名语义化 | 打印层 | src/printing/printer.h/cpp | format_permissions(mask) 纯函数 |
| ps attach 输出摘要 | 接口调用层 | src/interface/cmd_process.cpp | attach 成功后查掩码并打印 |
| 版本号 2.11.0 | 打印/命令层 | printer.cpp、commands.cpp | help/version 字符串 |
| 单测 | 测试 | test/unit/printer_test.cpp | format_permissions 位映射 |
| 集成 | 测试 | test/integration/cli_integration_test.cpp | ps attach 输出含 permissions |
| e2e | 测试 | test/e2e/test_cli_e2e.py | ps attach 权限断言 |

## 2. 职责边界(与既有约定一致)

- **打印层**:format_permissions(uint32_t mask) 返回语义化名列表(纯函数,
  `|` 连接,缺失位不显示);不调 deeptrace、不写文件。
- **接口调用层**:cmd_process attach 分支 attach 成功后调
  `deeptrace::session_permissions` 取掩码 → printer 格式化 → print_message;
  对应真实公共 API(deeptrace.h)。
- **命令解析层**:ps attach 参数不变(pid),无需改动 parser。
- **静态库**:v2.11.0 契约(见 design/v2.11.0/deeptrace/)。
