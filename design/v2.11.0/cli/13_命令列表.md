# CLI - 命令列表(修改模式,功能,v2.11.0)

> 引用:v2.10.0/cli/13_命令列表.md。v2.11.0 ps attach 输出增强。

## 1. ps 组命令改动

```text
ps attach <pid>
    附加到进程;成功时输出实际权限摘要
    输出: OK (permissions: read|write|vm_operate|create_thread|...)
```

- 权限名语义化映射(缺失位不显示):
  terminate / create_thread / vm_operate / read / write / dup_handle /
  create_process / set_quota / set_info / query / suspend_resume /
  query_limited。
- 帮助文本:ps attach 简介更新为
  「Attach to a process (shows permissions)」。

## 2. 其余命令

ps 其余动作、mem/module/thread/disasm/watch/script/shellcode 等全部不变。
