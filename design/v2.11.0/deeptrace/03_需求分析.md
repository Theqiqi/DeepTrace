# deeptrace - 需求分析(修改模式,v2.11.0)

> 引用:v2.2.0/deeptrace/03_需求分析.md 及后续版本。v2.11.0 为「attach
> 权限透出」改动:Session 记录 attach 实际权限,新增 session_permissions 查询。

## 1. 领域对象

- **会话(Session)**:进程操作的状态容器(pid/handle/debug_mode)。
  新增 `permissions` 字段:attach 实际成功的 access 掩码。
- **操作**:
  - attach(pid):打开进程句柄并记录实际权限掩码;
  - session_permissions:查询当前会话权限掩码;
  - detach:关闭句柄并清零权限掩码。

## 2. 数据流

```
attach(pid)
  → OpenProcess(ALL_ACCESS) 成功 → permissions = PROCESS_ALL_ACCESS
  → 失败 → OpenProcess(有限集合) 成功 → permissions = 有限集合
  → 失败 → 返回 AccessDenied/NoSuchProcess(权限掩码不写入)
session_permissions(&mask)
  → 无会话 → NotAttached
  → 有会话 → *mask = Session.permissions
detach() → 关闭句柄,permissions = 0,pid = 0
```

## 3. 约束

- 零额外 OpenProcess 探测(权限直接来自 attach 的实际掩码,零副作用)。
- 不改变 attach/detach 既有语义;AccessDenied 失败透出保持。
- 公共头文件只暴露标准 C++ 类型(uint32_t 掩码)。
