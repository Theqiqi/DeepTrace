# deeptrace - 接口设计(修改模式,v2.11.0)

> 引用:既有接口文档。v2.11.0 新增:

## 1. 函数签名

```cpp
// deeptrace.h
Result session_permissions(uint32_t* out_mask);
```

## 2. 参数与返回

| 参数 | 类型 | 说明 |
|------|------|------|
| out_mask | uint32_t* | 输出:当前会话 attach 实际 access 掩码(PROCESS_* 位) |

| 返回 | 条件 |
|------|------|
| Ok | 有会话,out_mask 已写入 |
| NotAttached | 当前无会话(session.pid == 0) |
| InvalidArg | out_mask 为 nullptr |

## 3. 实现要点

- 直接读 `internal::session()`;不新增平台调用。
- attach 成功路径写入掩码:
  - 全权限成功:`s.permissions = PROCESS_ALL_ACCESS;`
  - 降级成功:`s.permissions = 降级集合掩码;`
- detach:`s.permissions = 0;`
