# deeptrace - 职责和边界设计(修改模式,v2.11.0)

> 引用:既有职责文档。v2.11.0 增量:

## 1. 各层职责

- **Service(process.cpp/session.h)**:负责 attach 的权限掩码记录与会话查询;
  是唯一接触权限掩码的层。
- **对外接口(deeptrace.h)**:session_permissions 返回 uint32_t 掩码,不暴露
  Windows 类型。

## 2. 禁止项

- 禁止在 attach 之外额外调用 OpenProcess 探测权限(零副作用约束)。
- 禁止把权限名映射(语义名)放进静态库 —— 那是 CLI 展示层的事。
- 禁止改变 attach/detach 的返回码与失败语义。
