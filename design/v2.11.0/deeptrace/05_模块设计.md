## 1. 改动点 → 层 / 文件映射

| 改动点 | 层 | 文件 | 说明 |
|--------|----|------|------|
| Session 加 permissions 字段 | Service | src/service/session.h | 会话状态扩展 |
| attach 记录实际掩码 / detach 清零 | Service | src/service/process.cpp | attach 成功分支写入;detach 清零 |
| session_permissions 公共 API | Service | src/service/process.cpp/.h | 查询会话掩码 |
| 公共头声明 | 对外 | include/deeptrace.h | 新增 API 声明 |
| 单测 | 测试 | test/unit/ | session_permissions 未 attach → NotAttached |
| 集成 | 测试 | test/integration/process_integration_test.cpp | 真实进程 attach 后查询掩码非 0 且含 read/write |

## 2. 职责边界

- Service 层 process.cpp:attach 是既有流程,只增加「把实际掩码写入 Session」;
  session_permissions 直接读 Session(无新平台调用)。
- Domain/Algorithm/Infrastructure 零改动(权限掩码是 Windows OpenProcess
  的返回值,attach 处已有)。
- 零额外探测:不新增 OpenProcess 调用。
