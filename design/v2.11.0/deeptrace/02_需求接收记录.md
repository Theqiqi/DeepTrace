# deeptrace - 跨流程需求接收记录(design/v2.11.0/deeptrace/02_需求接收记录.md)

> 关联交接记录:design/v2.11.0/cli/01_想法收集.md(CLI v2.11.0 发起)。
> 来源:CLI 需在 attach 成功后透出实际权限(独立小版本)。

## 1. 接收清单(逐项)

### M1:查询当前会话实际权限掩码(session_permissions)

| 项 | 内容 |
|----|------|
| 缺失能力 | attach 成功后查询实际获得的进程访问权限(access mask) |
| 期望公共 API | `Result session_permissions(uint32_t* out_mask)` |
| 输入 | 无(当前会话) |
| 输出 | *out_mask = attach 实际成功的 OpenProcess access 掩码 |
| 异常要求 | 未 attach → NotAttached;out_mask 为空 → InvalidArg |
| 验收标准 | ①attach(全权限成功)→ 掩码含 PROCESS_ALL_ACCESS 全部位;②attach(降权成功)→ 掩码 = 降级集合;③未 attach 查询 → NotAttached;④detach 后掩码清零(会话无 pid) |

### M2:Session 记录实际权限掩码(基础设施/服务层内部)

| 项 | 内容 |
|----|------|
| 缺失能力 | attach 成功时把实际 access 掩码存入 Session |
| 期望实现 | `Session` 增加 `uint32_t permissions = 0;`;attach 成功时写入 |
| 输入 | attach 实际成功的 access 值 |
| 输出 | Session.permissions |
| 异常要求 | 无(内部状态) |
| 验收标准 | ①attach 成功后 session.permissions == 实际掩码;②detach 后清零;③零额外 OpenProcess 探测(直接用 attach 的掩码) |

## 2. 边界声明

- 不新增独立探测 API(不逐个权限位 OpenProcess 探测):权限信息直接来自
  attach 的实际掩码,零副作用。
- 不改变 attach/detach 的既有行为与返回码;AccessDenied 失败透出保持。
