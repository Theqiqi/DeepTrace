## 2. 模块职责(沿用)

- 命令层:构造请求对象(参数校验);接口层:经公共 API 调库并执行命令流程;
  打印层:格式化输出。新增函数遵循既有风格。
- script check 属于**接口层**:读文件与结构校验为纯文本/静态逻辑(标准库),
  汇编预检经静态库公共 API `asm_assemble_labels`(纯本地汇编,无需 attach)。
- check 与 run/disable 共享 `aa_parse_text` 解析器,保证语法判定一致;
  不引入任何会话/attach/detach 逻辑。
