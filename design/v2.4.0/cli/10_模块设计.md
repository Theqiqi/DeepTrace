# CLI - 模块设计(修改模式,增量,v2.3.0)

> 引用:v2.2.0/cli/10_模块设计.md 既有模块结构。本版本改动落在三层既有模块:

## 1. 改动点 → 层/文件

| 改动点 | 层 | 文件 |
|--------|-----|------|
| 新命令组登记(script run/disable/status)与帮助文本 | 命令层 | src/command/commands.cpp |
| 新参数校验(script-path 沿用;无新参数类型) | 命令层 | src/command/parser.cpp(不变或微调) |
| 请求数据结构:不变(CommandRequest 通用) | 命令层 | src/command/request.h |
| 脚本解析器(AA 语法 → 步骤)+ 脚本执行器(alloc/汇编写入/hook/建线程/恢复/释放) | 接口层 | src/interface/cmd_script.cpp(新)、cmd.h(辅助) |
| 分派(executor):新命令复用既有 -p 自动 attach/detach 路径 | 接口层 | src/interface/executor.cpp(不变) |
| 输出:复用 print_inject/print_message;script status 新输出格式 | 打印层 | src/printing/printer.cpp(script status 行) |

## 2. 模块职责(沿用)

- 命令层:构造请求对象(参数校验);接口层:经公共 API 调库并执行命令流程;
  打印层:格式化输出。新增文件/函数遵循既有风格。
- 脚本解析器(AA 语法)属于**接口层**:纯文本解析(标准库),不涉及静态库;
  执行阶段经静态库公共 API(script_alloc/asm_assemble_labels/thread_create_at/
  hook_set/hook_clear/script_free/script_enable/script_disable)。

## 3. 未改动模块

ps/mem/module/thread/debug/disasm/resolve/watch/dll/convert/asm/shellcode/
hex2bin 命令与 executor 主路径均不变。
