# CLI - 异常设计

## 1. 退出码约定

| 退出码 | 含义 |
|--------|------|
| 0 | 成功 |
| 1 | 命令执行失败(进程不存在、无权限、读写失败等) |
| 2 | 参数/用法错误(缺参、非法值、未知命令) |

## 2. 错误输出约定

- 全部错误消息前缀 `Error: `,输出到 stderr,纯 ASCII
- 用法错误附带 `Usage: deeptrace_cli [options] <command> [args...]` 与 `Try 'deeptrace_cli -h' for help.`
- deeptrace 错误:`Error: <result_message>(<context>)`,如 `Error: ReadFault(0x140001000)`

## 3. 异常场景处理矩阵

| 场景 | 检测位置 | 处理 |
|------|---------|------|
| 无参数运行 | main | 输出 `Missing command. Use -h or --help for help.` 退出码 1 |
| -h/--help | 解析层 | 打印帮助,退出 0 |
| -v/--version | 解析层 | 打印 `deeptrace_cli v1.0.0`,退出 0 |
| 未知命令组 | 解析层 | `Error: unknown command group: 'xxx'`,退出 2 |
| 未知子命令 | 解析层 | `Error: unknown command: 'xxx'`,退出 2 |
| 缺参数 | 解析层 | `Error: missing argument: <name>`,退出 2 |
| 参数非法 | 解析层 | `Error: invalid <name>: '<value>'`,退出 2 |
| pid 非法 | 解析层 | `Error: invalid pid: '<value>'`,退出 2 |
| 进程不存在 | 接口层(deeptrace) | `Error: NoSuchProcess(<pid>)`,退出 1 |
| 无权限 | 接口层 | `Error: AccessDenied(<pid>)`,退出 1 |
| 未附加 | 接口层 | `Error: NotAttached`,退出 1 |
| 地址不可读 | 接口层 | `Error: ReadFault(0x...)`,退出 1 |
| 地址不可写 | 接口层 | `Error: WriteFault(0x...)`,退出 1 |
| 扫描无命中 | 接口层 | 输出 `No match found`(成功退出 0) |
| 模式非法 | 接口层 | `Error: BadFormat('<pattern>')`,退出 1 |
| C++ 异常兜底 | main | `Error: internal exception: <what>`,退出 1 |

## 4. 防崩溃约定

- 所有 deeptrace 指针输出参数判空
- 所有字符串转换捕获异常
- 禁止访问空指针/越界(打印层遍历前判空)
