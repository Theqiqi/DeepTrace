# CLI - 能力需求列表

> 只回答"CLI 需要做什么",不回答"用什么做"。

| 编号 | 能力 | 说明 |
|------|------|------|
| C1 | 列举全部进程及其属性 | pid/名称/线程数/父进程 |
| C2 | 附加/分离目标进程建立会话 | 后续操作针对该进程 |
| C3 | 查询进程信息 | 名称/线程数/父进程 |
| C4 | 挂起/恢复/终止进程 | 带退出码 |
| C5 | 读取任意地址内存 | 指定大小,多种输出格式 |
| C6 | 写入任意地址内存 | 值格式 hex/dec |
| C7 | 转储一段内存为 hex | 带地址与 ASCII 列 |
| C8 | 列举进程内存区域 | 基址/大小/保护 |
| C9 | 类型化读取 | byte/word/dword/qword/float/double |
| C10 | 列举/查找模块、取基址 | 名称匹配 |
| C11 | 解析模块导出表 | 符号名+地址 |
| C12 | 模块转储 | hex 或保存文件 |
| C13 | 列举/挂起/恢复/终止线程 | 按 tid |
| C14 | 软件/硬件/页保护断点 | 设置、清除 |
| C15 | 单步/步过调试 | 输出新 RIP |
| C16 | 调试状态 | 附加状态、断点数 |
| C17 | 读取寄存器 | 全部或单个 |
| C18 | 反汇编 | 指定地址/范围 |
| C19 | 特征码扫描 | AOB 模式含 ?? |
| C20 | 监视地址值 | watch 增删查刷 |
| C21 | DLL 注入/弹出/列表/状态 | 路径或地址 |
| C22 | x64 汇编 | 助记符→机器码,hex/C数组输出 |
| C23 | 壳码注入 | 自动分配/指定地址,状态 |
| C24 | 帮助与版本 | 分组命令帮助、版本号 |
