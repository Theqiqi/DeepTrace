# CLI - 参数列表(重新设计)

## 1. 参数类型定义

| 类型 | 语法 | 示例 | 校验规则 |
|------|------|------|---------|
| address | `0x` 前缀十六进制 或 十进制 | `0x140001000` / `5368709120` | 0 < 值 ≤ 0x7FFFFFFFFFFF |
| number | 十进制(可 0x 前缀) | `16` / `0x10` | ≥ 0 |
| pid | 十进制 | `1234` | 1 ≤ 值 ≤ 0xFFFFFFFF |
| tid | 十进制 | `5678` | 1 ≤ 值 ≤ 0xFFFFFFFF |
| string | 任意 ASCII | `kernel32.dll` | 非空 |
| format | hex/dec/bin/ascii | `hex` | 枚举校验 |
| value-type | byte/word/dword/qword/float/double | `dword` | 枚举校验 |
| hw-type | 0=execute/1=write/2=io | `0` | 0-2 |
| pattern | AOB 模式(空格分隔字节,`??` 通配) | `48 8B ?? ?? 00` | 偶数 hex 字符或 ??,字节数 1-64 |
| hex-bytes | 连续 hex 字符串 | `4831C0C3` | 偶数长度,仅 0-9a-fA-F |
| exit_code | 十进制 | `0` | 0-0xFFFFFFFF |

## 2. 各命令参数规格

### ps
| 命令 | 参数 | 默认 |
|------|------|------|
| ps list | 无 | - |
| ps attach | pid(必填) | - |
| ps detach | 无 | - |
| ps info | 无 | - |
| ps suspend | 无 | - |
| ps resume | 无 | - |
| ps kill | exit_code(可选) | 0 |

### mem
| 命令 | 参数 | 默认 |
|------|------|------|
| mem read | address(必填), size(可选), format(可选) | size=1, format=hex |
| mem write | address(必填), value(必填), format(可选) | format=hex |
| mem dump | address(必填), size(必填) | - |
| mem regions | 无 | - |
| mem readval | address(必填), type(必填) | - |

### module
| 命令 | 参数 | 默认 |
|------|------|------|
| module list | 无 | - |
| module find | name(必填) | - |
| module base | name(必填) | - |
| module exports | module(必填) | - |
| module dump | name(必填), output_file(可选) | 无文件→stdout hex |

### thread
| 命令 | 参数 | 默认 |
|------|------|------|
| thread list | 无 | - |
| thread suspend | tid(必填) | - |
| thread resume | tid(必填) | - |
| thread kill | tid(必填) | - |

### debug
| 命令 | 参数 | 默认 |
|------|------|------|
| debug attach/detach/pause/resume/status | 无 | - |
| debug step | tid(可选) | 第一个线程 |
| debug next | tid(可选) | 第一个线程 |
| debug break/clear | address(必填) | - |
| debug hbreak | address(必填), type(可选), len(可选) | type=0, len=1 |
| debug hclear | address(必填) | - |
| debug guard/unguard | address(必填), size(必填) | - |
| debug registers | tid(可选) | 第一个线程 |
| debug register | name(必填), tid(可选) | 第一个线程 |

### disasm
| 命令 | 参数 | 默认 |
|------|------|------|
| disasm at | address(必填), count(可选) | count=10 |
| disasm range | start(必填), end(必填) | - |

### resolve
| 命令 | 参数 | 默认 |
|------|------|------|
| resolve base | module(必填) | - |
| resolve scan | pattern(必填) | - |

### watch
| 命令 | 参数 | 默认 |
|------|------|------|
| watch list | 无 | - |
| watch add | description(必填), address(必填), type(必填) | - |
| watch remove | index(必填) | - |
| watch refresh | 无 | - |
| watch clear | 无 | - |

### dll
| 命令 | 参数 | 默认 |
|------|------|------|
| dll inject | path(必填) | - |
| dll eject | path-or-address(必填) | - |
| dll list | 无 | - |
| dll status | 无 | - |

### asm
| 命令 | 参数 | 默认 |
|------|------|------|
| asm assemble | code(必填,引号包裹), --hex(可选), --c-array(可选) | 默认输出 hex 字符串 |

### shellcode
| 命令 | 参数 | 默认 |
|------|------|------|
| shellcode inject | hex_bytes(必填) | - |
| shellcode injectat | address(必填), hex_bytes(必填) | - |
| shellcode status | 无 | - |

## 3. 参数错误处理

- 缺必填参数:输出 `Error: missing argument: <name>` + 用法,退出码 2
- 类型非法:输出 `Error: invalid <name>: '<value>'` + 用法,退出码 2
- 多余参数:忽略多余并提示(不中断),或按命令规格严格处理(数量校验)
