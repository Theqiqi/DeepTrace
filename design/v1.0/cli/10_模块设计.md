# CLI - 模块分析(三层架构)

## 1. 三层架构

```
src/main.cpp
  │
  ├─ src/command/     命令解析层:解析 argv → 命令请求结构体
  ├─ src/interface/   接口调用层:命令请求 → pmem API 调用 → 结果结构
  └─ src/printing/    命令打印层:结果结构 → ASCII 文本输出
```

## 2. 模块划分

| 模块 | 文件 | 职责 |
|------|------|------|
| 命令定义 | src/command/commands.h/cpp | 命令表(组/子命令/参数规格)、帮助文本 |
| 命令解析 | src/command/parser.h/cpp | getopt 全局选项 + 命令路由 + 参数校验 |
| 命令请求 | src/command/request.h | CommandRequest 结构体 |
| 接口调用 | src/interface/executor.h/cpp | 分发到各命令执行函数,调 pmem API |
| 各命令执行 | src/interface/cmd_process.h/cpp 等 | 按命令组拆分实现 |
| 打印 | src/printing/printer.h/cpp | 纯格式化(表/hex/错误/帮助) |
| 入口 | src/main.cpp | 初始化→解析→执行→打印→退出码 |

## 3. 调用方向

```
main → 命令解析层 → 接口调用层 → pmem 公共 API
                    ↓
              命令打印层(结果格式化)
                    ↓
                 stdout/stderr
```

单向调用:**命令打印层 ← 接口调用层 ← 命令解析层 ← main**;
接口调用层调用 pmem;命令打印层不依赖命令解析层与接口调用层。
