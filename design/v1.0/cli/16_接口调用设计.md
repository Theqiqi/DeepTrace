## 2. 会话管理(接口调用层)

- main 解析出 pid → Executor 启动时 `pmem::attach(pid)`(ps list 除外)
- 每条命令执行前后保持会话;命令结束后 `pmem::detach()`
- 单步/调试类命令内部自行管理 DebugActiveProcess 生命周期(pmem 内)

## 3. 禁止事项

- 接口调用层禁止使用 pmem 以外的 API 实现任何能力
- 禁止 mock/fake/硬编码结果
- 禁止包含 pmem 内部头文件
