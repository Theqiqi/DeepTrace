# CLI - 代码规范

## 1. 通用规范

- 语言标准:C++20
- 命名:类型 PascalCase,函数 camelCase,成员 m_ 前缀,常量 UPPER_SNAKE
- 头文件 `#pragma once`
- 嵌套 ≤ 3 层;错误后提前返回
- 单一职责:函数只做一件事;文件过大拆分

## 2. 分层规范

- **命令解析层**只解析与校验,不执行
- **接口调用层**只调 pmem 公共 API,不打印、不实现业务算法
- **命令打印层**只格式化,不调 pmem、不依赖其他两层
- main 只初始化+调度
- CLI 源码禁止 include:windows.h、tlhelp32.h 等平台头文件;禁止第三方库

## 3. 输出规范

- 所有输出字符串(帮助/错误/状态)必须纯 ASCII 可打印字符
- 宽字符转 ASCII:不可打印字符替换为 '?'
- 地址格式:`0x%016llX`(64 位);字节:`%02X` 大写
- 表格对齐:固定列宽,便于解析

## 4. 无交互规范

- 禁止 getchar()/scanf()/cin/while(cin) 等阻塞式输入等待
- 无参运行直接输出提示后退出
- 不进入 REPL 循环

## 5. 错误处理

- 退出码:0 成功 / 1 执行失败 / 2 用法错误
- 错误消息 `Error: ...` 到 stderr
- 捕获 std::exception 兜底

## 6. 测试规范

- 单元测试:命令解析层(参数边界/非法值/默认值/命令映射)
- 集成测试:完整三层链路 parse → execute → pmem API(真实 target)
- e2e:Python 启动真实 pmem_cli.exe + pmem_target.exe 断言命令行行为
- target 程序:不链接 pmem、关闭 ASLR、已知地址放已知值、输出 `PID: <number>` 行
