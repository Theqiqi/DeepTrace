# CLI - 业务流程分析

## 1. 用户操作流程(主流程)

```
用户输入命令行
  ↓
全局选项解析(-p/-h/-v)
  ↓
命令路由:命令组 + 子命令 + 参数
  ↓
参数校验(数量/格式)
  ↓
目标进程可用性检查(需要 pid 的命令)
  ↓
调用 deeptrace 公共 API(经接口调用层)
  ↓
命令打印层格式化输出(纯 ASCII)
  ↓
退出(0 / 非0)
```

## 2. 业务流程清单

### BF1 附加与查看进程
```
deeptrace_cli ps list                      → 输出进程表
deeptrace_cli -p <pid> ps info             → 输出进程信息
deeptrace_cli ps attach <pid>              → 建立会话,输出 OK
deeptrace_cli ps detach                    → 关闭会话,输出 OK
```

### BF2 内存读写
```
deeptrace_cli -p <pid> mem read <addr> [size] [format]     → 输出字节序列
deeptrace_cli -p <pid> mem write <addr> <value> [format]   → 输出写入结果
deeptrace_cli -p <pid> mem dump <addr> <size>              → 输出 hex dump
deeptrace_cli -p <pid> mem regions                        → 输出区域表
deeptrace_cli -p <pid> mem readval <addr> <type>          → 输出类型化值
```

### BF3 模块与解析
```
deeptrace_cli -p <pid> module list          → 输出模块表
deeptrace_cli -p <pid> module base <name>   → 输出基址
deeptrace_cli -p <pid> module exports <name>→ 输出导出符号表
deeptrace_cli -p <pid> module dump <name> [file] → 输出 hex/保存文件
deeptrace_cli -p <pid> resolve scan <pattern> → 输出命中地址
```

### BF4 调试
```
deeptrace_cli -p <pid> debug break <addr>      → 设置软件断点
deeptrace_cli -p <pid> debug clear <addr>      → 清除
deeptrace_cli -p <pid> debug step [tid]        → 单步
deeptrace_cli -p <pid> debug registers [tid]   → 寄存器表
deeptrace_cli -p <pid> debug status            → 断点/状态
```

### BF5 监视/注入/壳码
```
deeptrace_cli -p <pid> watch add <desc> <addr> <type>
deeptrace_cli -p <pid> watch refresh
deeptrace_cli -p <pid> dll inject <path>
deeptrace_cli -p <pid> shellcode inject <hex>
deeptrace_cli -p <pid> asm assemble "mov rax, 1" --hex
```

## 3. 业务流程图(文本)

```
       ┌─────────────┐
       │ 命令行输入   │
       └──────┬──────┘
              ▼
      ┌───────────────┐
      │ 命令解析层     │
      │ (参数校验)     │
      └──────┬──────┘
             ▼
      ┌───────────────┐
      │ 接口调用层     │
      │ (deeptrace API)    │
      └──────┬──────┘
             ▼
      ┌───────────────┐
      │ 命令打印层     │
      │ (ASCII 输出)  │
      └──────┬──────┘
             ▼
           退出码
```

## 4. 异常路径

| 场景 | 处理 |
|------|------|
| 缺命令 | 输出错误 + -h 提示,退出非 0 |
| 未知命令 | 输出错误 + 用法,退出非 0 |
| 参数非法 | 输出具体错误,退出非 0 |
| 进程不存在/无权限 | 输出 deeptrace 错误消息,退出非 0 |
| 地址不可读 | 输出 ReadFault,退出非 0 |
| 未附加进程 | 输出 NotAttached 提示,退出非 0 |
