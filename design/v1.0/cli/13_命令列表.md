# CLI - 命令列表(重新设计)

> 依据流程步骤重新设计的命令交互。设计原则:
> 1. 全局选项统一前置:getopt 解析 `-p/--pid/-h/--help/-v/--version`
> 2. 命令格式统一:`<group> <action> [args...]`
> 3. 地址统一支持 `0x` 前缀十六进制与十进制
> 4. 每个子命令用法在帮助中给出完整参数
> 5. 无交互:一次调用执行一个操作,无参运行输出提示后退出

## 用法总览

```
Usage: deeptrace_cli [options] <command> [args...]

Options:
  -p, --pid <pid>    Target process ID
  -h, --help         Show help
  -v, --version      Show version
```

## 命令组清单

### ps — 进程
```
ps list                          List all processes
ps attach <pid>                  Attach to a process
ps detach                        Detach from current process
ps info                          Show current process info
ps suspend                       Suspend the attached process
ps resume                        Resume the attached process
ps kill [exit_code]              Terminate the attached process (default exit code 0)
```

### mem — 内存
```
mem read <address> [size] [format]     Read memory (format: hex|dec|bin|ascii, default hex, size default 1)
mem write <address> <value> [format]   Write memory (format: hex|dec, default hex)
mem dump <address> <size>              Dump memory region in hex
mem regions                            List memory regions
mem readval <address> <type>           Read a typed value (byte|word|dword|qword|float|double)
```

### module — 模块
```
module list                            List all loaded modules
module find <name>                     Find module by name
module base <name>                     Get module base address
module exports <module>                List module exports
module dump <name> [output_file]       Dump module: hex to stdout or to file
```

### thread — 线程
```
thread list                            List all threads in current process
thread suspend <tid>                   Suspend a thread
thread resume <tid>                    Resume a thread
thread kill <tid>                      Terminate a thread
```

### debug — 调试
```
debug attach                           Enter debug mode (requires attached process)
debug detach                           Exit debug mode, remain attached to process
debug pause                            Pause the debugged process
debug resume                           Resume the debugged process
debug step [tid]                       Step into (single step)
debug next [tid]                       Step over
debug break <address>                  Set a software breakpoint at address
debug clear <address>                  Clear a software breakpoint at address
debug hbreak <address> [type] [len]    Set a hardware breakpoint (type: 0=execute,1=write,2=io, default 0; len default 1)
debug hclear <address>                 Clear a hardware breakpoint
debug guard <address> <size>           Set a page guard breakpoint
debug unguard <address> <size>         Remove a page guard breakpoint
debug status                           Show debug status
debug registers [tid]                  Display all registers
debug register <name> [tid]            Get a specific register value
```

### disasm — 反汇编
```
disasm at <address> [count]            Disassemble at address (default count 10)
disasm range <start> <end>             Disassemble memory range
```

### resolve — 解析
```
resolve base <module>                  Get base address of module
resolve scan <pattern>                 Pattern scan (AOB, e.g. "48 8B ?? ?? 00")
```

### watch — 监视
```
watch list                             List all watch entries
watch add <description> <address> <type>    Add watch (type: byte|word|dword|qword|float|double)
watch remove <index>                   Remove watch by index
watch refresh                          Refresh all watch values
watch clear                            Clear all watches
```

### dll — 注入
```
dll inject <path>                      Inject a DLL into the target process
dll eject <path-or-address>            Eject an injected DLL
dll list                               List all injected DLLs
dll status                             Show DLL injection status
```

### asm — 汇编
```
asm assemble <code> [--hex] [--c-array]    Assemble x64 assembly to bytes
```

### shellcode — 壳码
```
shellcode inject <hex_bytes>           Inject shellcode (auto-alloc)
shellcode injectat <addr> <hex_bytes>  Inject shellcode at address
shellcode status                       Show shellcode inject status
```
