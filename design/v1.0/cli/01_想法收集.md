# CLI - 想法收集

## 1. 输入想法

参考软件:DeepTrace CLI(idea.txt),Windows 进程调试命令行工具。
要求:复刻全部功能,命令参数交互按流程步骤重新设计。

参考功能:
- 进程:list/attach/detach/info/suspend/resume/kill
- 内存:read/write/dump/regions/readval
- 模块:list/find/base/exports/dump
- 线程:list/suspend/resume/kill
- 调试:pause/resume/step/next/break/clear/hbreak/hclear/guard/unguard/status/registers/register/attach/detach
- 反汇编:at/range
- 解析:base/scan
- 监视:list/add/remove/refresh/clear
- DLL:inject/eject/list/status
- 汇编:assemble
- 壳码:inject/injectat/status
- 全局选项:-p/--pid、-h/--help

## 2. 期望

- 程序类型:命令行可执行文件(exe),无交互(非 REPL),一次执行一个操作
- 底层能力由 pmem 静态库提供,CLI 不直接调用 Windows API
- 全部输出纯 ASCII,禁止阻塞式输入等待
