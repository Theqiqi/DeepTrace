# CLI - 接口分析

## 1. 接口分析

### 命令请求结构体
```cpp
struct CommandRequest {
  std::string group;              // ps/mem/module/...
  std::string action;             // list/read/...
  std::vector<std::string> args;  // 原始参数
  uint32_t pid = 0;               // -p 指定
  bool pid_set = false;
  bool help = false;              // -h
  bool version = false;           // -v
};
```

### 命令解析接口
```cpp
// parser.h
CommandRequest parse_args(int argc, char* argv[]);
// 返回:help/version 标志、或 group/action/args、或解析错误(打印后退出)
```

### 接口调用接口
```cpp
// executor.h
int execute(const CommandRequest& req);   // 返回进程退出码
// 内部按 group 分发到各命令执行函数,结果经 Printer 输出
```

### 命令打印接口
```cpp
// printer.h
namespace printer {
void print_error(const std::string& msg);
void print_help();
void print_version();
void print_processes(const std::vector<deeptrace::ProcessInfo>& list);
void print_regions(const std::vector<deeptrace::MemoryRegion>& list);
void print_modules(const std::vector<deeptrace::ModuleInfo>& list);
void print_exports(const std::vector<deeptrace::ExportInfo>& list);
void print_threads(const std::vector<deeptrace::ThreadInfo>& list);
void print_registers(const std::vector<deeptrace::RegisterInfo>& list);
void print_instructions(const std::vector<deeptrace::Instruction>& list);
void print_watches(const std::vector<deeptrace::WatchEntry>& list);
void print_hex_dump(uintptr_t base, const std::vector<uint8_t>& bytes);
void print_bytes(const std::vector<uint8_t>& bytes);   // 单行 hex
void print_message(const std::string& msg);
std::string to_ascii(const std::wstring& s);  // 宽字符→ASCII 安全转换
}
```

## 2. 数据结构列表

| 结构 | 说明 |
|------|------|
| CommandRequest | 命令请求(见上) |
| deeptrace::* (全部) | 直接使用 deeptrace 公共类型,CLI 不重复定义 |

## 3. 异常设计

- CLI 不抛异常(捕获 std::exception 兜底,输出错误)
- deeptrace 返回 Result ≠ Ok → 接口层输出 result_message 并返回非 0 退出码
- 退出码约定:0=成功;1=命令执行失败;2=参数/用法错误
