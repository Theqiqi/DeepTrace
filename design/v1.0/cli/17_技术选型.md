# CLI - 技术选型

## 1. 技术选型

| 项 | 选择 |
|----|------|
| 程序类型 | 命令行可执行文件(exe) |
| 语言 | C++20 |
| 平台 | Windows x64 |
| 框架 | Console(标准输出/错误) |
| 构建 | CMake(CMakeLists.txt + CMakePresets.json) |
| 生成器 | Ninja(仅 Ninja) |
| 工具链 | MSVC(cl.exe,经 vcvars64) |
| 包管理 | vcpkg manifest(gtest 仅测试) |
| 参数解析 | getopt(C 标准库)/ argc/argv |
| 依赖 | deeptrace 静态库(../deeptrace/out/lib/<配置>/deeptrace.lib + ../deeptrace/include/deeptrace.h) |
| 命名 | deeptrace_cli(产物 cli/out/bin/<配置>/deeptrace_cli.exe) |
| 运行时链接 | Debug=/MDd(x64-windows)、Release=/MT(x64-windows-static) |

## 2. 目录约定

```
cli/
├── CMakeLists.txt
├── CMakePresets.json
├── vcpkg.json
├── src/{command,interface,printing}/ + main.cpp + CMakeLists.txt
├── test/{target,unit,integration,e2e}/ + 各 CMakeLists.txt(e2e 无 CMake)
├── script/{build_debug,build_release}.bat + {build_debug,build_release}_wsl.sh
└── out/
```

## 3. 跨项目引用

- find_library 查找 ../deeptrace/out/lib/<配置>/deeptrace.lib
- 公共头文件直接来自 ../deeptrace/include/deeptrace.h
- 无 install/ 中间层

## 4. 输出约束

- 全部输出纯 ASCII 可打印字符
- 禁止阻塞式输入等待(getchar/scanf/cin)
