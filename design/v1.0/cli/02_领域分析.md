# CLI - 领域分析

## 1. 业务对象

- 进程(Process):pid、名称、线程数、父进程 —— 附加目标
- 内存地址(Address):uintptr 地址,读写/转储目标
- 内存区域(MemoryRegion):列举对象
- 模块(Module):基址/导出表/转储对象
- 线程(Thread):tid,挂起/恢复/结束/单步对象
- 断点(Breakpoint):软件/硬件/页保护
- 寄存器(Register):名称与值
- 指令(Instruction):反汇编输出
- 监视条目(Watch):描述/地址/类型/值
- 注入记录(Inject):DLL 路径、壳码字节
- 模式串(Pattern):AOB 扫描输入

## 2. 参与者

- 用户:通过命令行输入命令与参数,查看文本输出
- 目标进程:被操作对象(由 -p/--pid 或 ps attach 指定)

## 3. 操作流程(概要)

1. 用户输入命令行(如 `pmem_cli -p 1234 mem read 0x140001000 16 hex`)
2. CLI 解析全局选项与命令/参数
3. 校验参数;校验目标进程可用
4. 调用 pmem 公共 API 执行
5. 纯 ASCII 格式化输出结果
6. 退出(成功 0,失败非 0),无任何等待

## 4. 数据集合与元素操作

| 集合 | 元素操作 |
|------|---------|
| 进程列表 | 查看(list) |
| 内存区域列表 | 查看(regions) |
| 模块列表 | 查看、查找、导出、转储 |
| 线程列表 | 查看、挂起、恢复、结束 |
| 断点集合 | 添加、清除、查看(status) |
| watch 集合 | 添加、移除、查看、刷新、清空 |
| 注入集合 | 注入、弹出、查看、状态 |
| 壳码集合 | 注入、状态 |
