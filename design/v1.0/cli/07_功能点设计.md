# CLI - 功能点设计

## 1. 功能点列表(与命令一一对应)

### 命令组 ps
- F1 ps list:列举进程表
- F2 ps attach:附加目标进程
- F3 ps detach:分离
- F4 ps info:进程信息
- F5 ps suspend:挂起
- F6 ps resume:恢复
- F7 ps kill:终止

### 命令组 mem
- F8 mem read:读内存
- F9 mem write:写内存
- F10 mem dump:hex 转储
- F11 mem regions:区域表
- F12 mem readval:类型化读取

### 命令组 module
- F13 module list / F14 module find / F15 module base
- F16 module exports / F17 module dump

### 命令组 thread
- F18 thread list / F19 thread suspend / F20 thread resume / F21 thread kill

### 命令组 debug(15 个子命令)
- F22 attach / F23 detach / F24 pause / F25 resume
- F26 step / F27 next
- F28 break / F29 clear / F30 hbreak / F31 hclear
- F32 guard / F33 unguard
- F34 status / F35 registers / F36 register

### 命令组 disasm
- F37 disasm at / F38 disasm range

### 命令组 resolve
- F39 resolve base / F40 resolve scan

### 命令组 watch
- F41 list / F42 add / F43 remove / F44 refresh / F45 clear

### 命令组 dll
- F46 inject / F47 eject / F48 list / F49 status

### 命令组 asm
- F50 asm assemble

### 命令组 shellcode
- F51 inject / F52 injectat / F53 status

### 全局
- F54 帮助(-h/--help)
- F55 版本(-v/--version)
- F56 无参运行提示

## 2. 功能分析(执行过程)

每个功能 = `参数校验 → 接口调用层调用 pmem API → 打印层格式化`。

示例 F8 mem read:
1. 校验:addr 必须可解析为地址;size 默认 1;format ∈ {hex,dec,bin,ascii}
2. pmem::memory_read(addr, size)
3. 打印:地址 + hex 字节行(或按 format)

示例 F28 debug break:
1. 校验:addr 可解析
2. pmem::breakpoint_set(addr) → 返回原字节
3. 打印:`breakpoint set at 0x... (orig 0xXX)`
