# CLI - 程序类型判断

## 1. 判断依据

| 判据 | 结论 |
|------|------|
| 操作可抽象为命令+参数? | 是:每个功能均为"命令 子命令 [参数...]" |
| 输出可文本化? | 是:全部结果为文本行 |
| 一次执行一个操作? | 是:无 REPL、无交互循环 |
| 需要图形交互? | 否 |
| 需要实时可视化反馈? | 否 |
| 需要多线程并行? | 否 |

## 2. 结论

- 适合 **CLI 无交互程序**形式(参考 .flow/cli_无交互_development_process.md)
- 程序类型:命令行可执行文件(exe)
- 无参运行直接输出提示后退出;禁止 getchar/scanf/cin 等阻塞等待
- 输出字符串必须纯 ASCII(防止 cmd.exe 乱码)
