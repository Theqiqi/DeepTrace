# deeptrace 静态库 - 技术选型

## 1. 技术选型

| 项 | 选择 |
|----|------|
| 程序类型 | 静态库(非 exe) |
| 语言 | C++20 |
| 平台 | Windows x64 |
| 构建 | CMake(CMakeLists.txt + CMakePresets.json) |
| 生成器 | Ninja(仅 Ninja) |
| 工具链 | MSVC(cl.exe,经 vcvars64 提供) |
| 包管理 | vcpkg manifest(已检测到 VS 自带 vcpkg.exe 与 VCPKG_ROOT) |
| 三方依赖 | gtest(仅测试;经 vcpkg manifest 管理) |
| 运行时链接 | Debug=/MDd(MultiThreadedDebugDLL,x64-windows);Release=/MT(MultiThreaded,x64-windows-static) |
| 输出目录 | out/bin/<配置>、out/lib/<配置>(由 CMakePresets cacheVariables 声明) |
| 命名 | deeptrace(进程内存操作类) |

## 2. 目录约定

```
deeptrace/
├── CMakeLists.txt
├── CMakePresets.json
├── vcpkg.json
├── include/deeptrace.h
├── src/{data,algorithm,atomic,api}/ + CMakeLists.txt
├── test/{target,unit,integration}/ + 各 CMakeLists.txt
├── script/{build_debug,build_release}.bat + {build_debug,build_release}_wsl.sh
└── out/
```

## 3. 编译环境检测结论

- vcpkg.exe:`C:\Program Files\Microsoft Visual Studio\2022\Community\VC\vcpkg\vcpkg.exe`(VCPKG_ROOT 已设置)
- cmake.exe:VS2022 自带(Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin)
- ninja.exe:VS2022 自带(Common7\IDE\CommonExtensions\Microsoft\CMake\Ninja)
- cl.exe:经 vcvars64.bat 提供
- 编译方式:WSL → cmd.exe → .bat → MSVC(cl.exe)

## 4. 静态库交付约定

- 产物:deeptrace/out/lib/<配置>/deeptrace.lib + deeptrace/include/deeptrace.h
- 无 install/ 目录、无安装脚本(无其他依赖)
- CLI 经 find_library 直接引用 ../deeptrace/out/lib/<配置>/deeptrace.lib
