# pmem 静态库 - 想法整理

## 1. 输入想法

参考软件:DeepTrace CLI(idea.txt 中展示),一个 Windows 进程调试命令行工具,功能包括:

- 进程操作:列举、附加、分离、信息、挂起、恢复、结束
- 内存操作:读、写、转储、区域列举、类型化读取
- 模块操作:列举、查找、基址、导出表、模块转储
- 线程操作:列举、挂起、恢复、结束
- 调试操作:暂停/恢复、单步、步过、软件断点、硬件断点、页保护断点、状态、寄存器
- 反汇编:指定地址、指定范围
- 解析:模块基址、特征码扫描
- 监视:watch 条目增删查刷
- DLL 注入:注入、弹出、列举、状态
- 汇编:助记符 → 机器码
- 壳码:注入、指定地址注入、状态

## 2. 程序类型判断(初步)

- 程序类型:**静态库**(供 CLI 调用)
- 静态库命名:进程内存操作类 → **pmem**
- 语言:C++20
- 平台:Windows
- 跨平台:否

## 3. 目标

将上述全部能力以真实 Windows 底层能力实现为 pmem 静态库公共 API,
禁止模拟数据、硬编码结果或伪造 API。供 CLI(无交互命令行程序)调用。
