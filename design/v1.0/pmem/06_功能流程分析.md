# pmem 静态库 - 功能流程分析

## 1. 功能执行过程

### 附加会话流程
```
session_attach(pid):
  校验 pid > 0
  OpenProcess(PROCESS_ALL_ACCESS) → 失败返回 NoSuchProcess/AccessDenied
  会话记录 pid + 句柄
```

### 内存读取流程
```
memory_read(addr, size):
  校验附加 + addr != 0 + size > 0
  ReadProcessMemory(hProcess, addr, buf, size) → 失败返回 ReadFault(部分读取判定)
  返回实际读取字节数
```

### 软件断点流程
```
breakpoint_set(addr):
  校验附加 + 地址可执行
  读取原字节(1B)
  写入 0xCC
  持久化(pid,addr,原字节) → 状态文件
breakpoint_clear(addr):
  从状态文件取原字节 → 写回
  删除状态记录
```

### 单步流程
```
debug_step():
  DebugActiveProcess(pid)
  等待初始调试事件(超时)
  选目标线程(默认第一个) → GetThreadContext → 置 TF
  SetThreadContext → ContinueDebugEvent
  WaitForDebugEvent(EXCEPTION_SINGLE_STEP, 超时)
  读新 RIP → 返回
  DebugActiveProcessStop
```

### AOB 扫描流程
```
pattern_scan(pattern, hits):
  遍历 memory_regions(可读)
  对每区域字节流执行纯算法匹配(通配 ??)
  收集命中地址
```

## 2. 流程中错误路径

| 流程 | 错误路径 |
|------|---------|
| 附加 | 无权限 → AccessDenied;进程不存在 → NoSuchProcess |
| 读取 | 地址不可读 → ReadFault |
| 写入 | 地址不可写 → WriteFault |
| 扫描 | 无命中 → NotFound(由上层决定输出) |
| 单步 | 超时 → Timeout |
| DLL 注入 | 路径无效/远端失败 → Error |

## 3. 流程依赖

- 所有跨进程操作依赖 session_attach 成功(除列举类:进程列举、区域列举可临时打开)
- 单步/寄存器依赖调试附加或至少 OpenThread 权限
