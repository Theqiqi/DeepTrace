# CLI - 异常设计(修改模式,增量,v2.8.0)

> 引用:v2.7.0/cli/15_异常设计.md。v2.8.0 无新错误路径;mem write <symbol>
> 复用 v2.6.0 符号寻址错误语义,补用例锁定。

## 1. mem write <symbol> 错误路径(确认,无新增)

| 场景 | 层 | 退出码 | 输出 |
|------|----|--------|------|
| 符号未注册(未 run / 已 disable) | 接口层(script_symbol→NotFound) | 1 | `Error: NotFound(<symbol>)` |
| 无 session(-p 缺失/失败) | 接口层(script_symbol→NotAttached) | 1 | `Error: NotAttached` / attach 错误 |
| 值格式非法(奇数 hex / 非 hex) | 接口层(hex_bytes→空) | 2 | `Error: invalid value`(既有) |
| dec 值解析失败 | 接口层(to_u64) | 2 | 用法错误(既有) |

## 2. 错误语义关键点

- 与 mem write 数字地址路径完全一致,仅地址解析来源不同(符号记录)。
- 符号生命周期:disable/dealloc 后 NotFound(与 v2.6.0 符号寻址一致)。

## 3. 既有错误路径

near 就近分配(v2.7.0)、符号寻址其余命令、数字地址读写等全部不变。
