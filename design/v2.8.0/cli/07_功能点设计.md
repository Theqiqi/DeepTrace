## 1. 确认功能点:mem write 符号寻址(能力已存在,v2.6.0)

### 1.1 描述

`mem write <symbol> <value> [format]` 中 address 参数接受脚本符号名,经
`resolve_addr` → `script_symbol` 解析为记录地址后写入。用于脚本外动态改
人造指针目标:槽位(8 字节)内存放目标指针,一行命令改写即切换目标。

### 1.2 解析链路(已实现,无改动)

```
mem write slotA 8877665544332211 hex
  → parser: address 参数 "slotA" 符号形状合法(v2.6.0)
  → attach(pid)
  → resolve_addr("slotA") → script_symbol → Ok(槽位地址)
  → hex_bytes("8877665544332211") → memory_write(槽位, 8 字节) → OK
```

### 1.3 测试设计(v2.8.0 新增)

| 层 | 用例 | 断言 |
|----|------|------|
| 单测 | `parse({cli, mem, write, slotA, DEADBEEF, hex})` | r.ok, args[0]=="slotA" |
| 集成 | script run(aptr)→ `mem write slotA 8877665544332211 hex` → `mem read slotA 8` | 读出 88 77 66 55 44 33 22 11 |
| 集成 | `mem write slotA 1122334455667788 dec` → read | 读出 4C 9C 8C DA C1 FC 03 00(小端) |
| 集成 | `mem write nosuch ...` | 退出 1,Error 含 NotFound |
| 集成 | disable 后 `mem write slotA ...` | 退出 1 NotFound |
| e2e | aptr run → mem write slotA hex → read 读回新值 | 新值字节 |

### 1.4 能力边界声明

- 支持:任意脚本符号指向的内存写入(槽位 / 代码缓冲区)。
- 不支持:未注册符号(NotFound)、非法值格式(用法错误)、无 attach(NotAttached)。
- dec 固定 8 字节小端(既有语义)。
