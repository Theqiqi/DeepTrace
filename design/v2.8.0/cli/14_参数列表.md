# CLI - 参数列表(修改模式,增量,v2.8.0)

> 引用:v2.7.0/cli/14_参数列表.md。v2.8.0 无参数语义变更;声明 mem write
> 的 address 参数符号寻址(已在 v2.6.0 生效,本版本补测试)。

## 1. mem write address 参数(符号寻址确认)

| 命令 | # | 参数 | 位置 | 必填 | 类型 | 取值/校验(v2.8.0) |
|------|---|------|------|------|------|-----------|
| mem write | 1 | address | 第 1 个 | 是 | address | 数字地址 或 符号名形状 `[A-Za-z_][A-Za-z0-9_]*`(v2.6.0) |
| mem write | 2 | value | 第 2 个 | 是 | hex-bytes / u64 | hex:偶数十六进制;dec:u64(固定 8 字节小端) |
| mem write | 3 | format | 第 3 个 | 否 | format-rw | hex(默认)/ dec |

- 符号名形状通过解析;符号是否存在由接口层 attach 后查记录决定。
- 未知符号 → NotFound 退出 1;值非法 → 用法错误退出 2(既有语义不变)。
