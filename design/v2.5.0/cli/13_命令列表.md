# CLI - 命令列表(修改模式,增量,v2.4.0)

> 引用:v2.3.0/cli/13_命令列表.md。v2.4.0 script 组新增 check 如下,其余命令不变。

## 1. script 组(v2.4.0 新增 check)

```text
script check <file>
    Check AA script syntax and assembly only (no attach, no execute)
script run <file>
    Run an AA-style script [ENABLE] block (idempotent)
script disable <file>
    Run an AA-style script [DISABLE] block (idempotent)
script status
    Show enabled scripts and their hooks/allocs
```

- `script check`:只检查不执行——读文件 + AA 语法解析 + hook 块结构校验 + 汇编
  预检(占位地址调用 asm_assemble_labels)。**无需 -p**、不 attach、无目标副作用。
  通过 → `OK (N steps: ...)` 退出 0;失败 → `Error: ...` 退出 2(输入/脚本问题)。
  模块加载等动态问题不在 check 范围(需 attach,由 run 校验)。
- `script run/disable/status` 行为与 v2.3.0 相同(幂等语义、`already enabled/disabled`)。
- `<file>` = AA 脚本文件路径(纯 ASCII);脚本语法见 v2.3.0 12_接口设计 §3。
