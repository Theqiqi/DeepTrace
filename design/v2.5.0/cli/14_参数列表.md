# CLI - 参数列表(修改模式,增量,v2.5.0)

> 引用:v2.4.0/cli/14_参数列表.md。v2.5.0 **无新增参数/命令**;
> 本版本为 script 汇编能力增强(符号引用,人造指针),参数面不变。

## 1. script 命令参数

| 命令 | # | 参数 | 位置 | 必填 | 类型 | 取值/校验 |
|------|---|------|------|------|------|-----------|
| script check | 1 | file | 第 1 个 | 是 | script-path(非空) | 文件存在/可读由接口层校验 |
| script run | 1 | file | 第 1 个 | 是 | script-path(非空) | 文件存在/可读由接口层校验 |
| script disable | 1 | file | 第 1 个 | 是 | script-path(非空) | 文件存在/可读由接口层校验 |
| script status | - | (无参数) | - | - | - | - |

> v2.5.0 无参数变更;脚本内符号引用的「参数」是汇编行里的符号名(alloc'd 符号或标签),
> 由静态库 asm_assemble_labels 解析,不属于命令行参数。
