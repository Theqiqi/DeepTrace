# CLI - 模块设计(修改模式,增量,v2.5.0)

> 引用:v2.4.0/cli/10_模块设计.md 既有模块结构。本版本核心改动在**静态库汇编层**,
> CLI 三层仅同步版本号与文档,无结构性改动。

## 1. 改动点 → 层/文件

| 改动点 | 层 | 文件 |
|--------|-----|------|
| 符号引用编码扩展(内存操作数 RIP 重写 + 立即数 + Capstone 校验防截断) | 静态库 | DeepTrace/src/service/asm.cpp、asm.h(核心) |
| Capstone detail 校验助手(编码地址 == 符号地址) | 静态库 | DeepTrace/src/infrastructure/disassembly/(disasm 扩展) |
| exec_enable / aa_precheck_asm 同步(编码层自动受益,无逻辑改动) | 接口层 | cli/src/interface/cmd_script.cpp(不变) |
| 版本号 2.5.0 | 命令/打印层 | src/command/commands.cpp、src/printing/printer.cpp |

## 2. 模块职责(沿用)

- 命令层:构造请求对象(参数校验);接口层:经公共 API 调库并执行命令流程;
  打印层:格式化输出。新增函数遵循既有风格。
- 符号编码属**静态库服务层**(asm.cpp),CLI 不经手编码细节;
  exec_enable 已传真实符号表、check 已传占位符号表,编码扩展自动生效。
- Capstone 校验仅用于「发现 Keystone 静默截断」,属于静态库内部实现,
  不暴露新公共 API;`asm_assemble_labels` 签名不变。

## 3. 未改动模块

ps/mem/module/thread/debug/disasm/resolve/watch/dll/convert/asm/shellcode/
hex2bin 命令与 executor 主路径均不变;script run/disable/status/check 行为不变
(仅编码能力增强)。
