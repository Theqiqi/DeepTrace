# CLI - 功能点设计(修改模式,增量,v2.5.0)

> 引用:v2.4.0/cli/07_功能点设计.md 既有功能点。本版本新增「汇编行符号引用(人造指针)」功能点。

## 1. 功能点:汇编行符号引用(人造指针)

### 1.1 功能分析

- 输入:脚本 ENABLE 块内的裸汇编行,引用 alloc'd 符号或脚本内标签(任意指令)。
- 语义:符号在汇编行中按「已解析的地址」参与编码;解析顺序
  流内标签 > 外部符号(alloc'd 符号 / hook 块外标签)。
- 编码规则(静态库 `asm_assemble_labels`,两遍布局):
  1. **jmp/call 引用**(不变):自编码 rel32(E9/E8 + disp32)。
  2. **内存操作数 `[sym]`**:重写为 `[rip+disp32]` —— 先以 `[rip+0]` 占位汇编定长,
     再算 disp = sym - (指令地址 + 长度),回填重汇编;位移超 int32 → BadFormat。
  3. **立即数 `sym`**:替换为地址字面量后交 Keystone 编码(64 位目标 → movabs imm64);
     **Capstone 校验**实际编码引用的地址 == 符号地址,发现静默截断 → BadFormat。
  4. **复杂内存表达式**(`[reg+sym]` 等)→ 明确报错。
- 效果:用户示例 `alloc(sunObjPtr,8)` + `mov [sunObjPtr],rax` 可运行;脚本外经
  `script status` 拿槽位地址 + `mem read <addr>` 读回指针值(完整链路)。
- 输出:无新命令/无新输出格式;汇编成功写入与既有 asm 行一致。

### 1.2 功能流程(编码层)

```
asm_assemble_labels(code, base, symbols):
  parse lines; 收集流内标签
  for line:
    if jmp/call 引用:  → 自编码 rel32(既有)
    if 内存操作数 [sym]: → [rip+0] 占位汇编 → 定长 → disp=sym-(addr+len)
                           → 校验 |disp|<=int32 → 回填重汇编
    if 立即数 sym:      → 替换 0x<addr> → Keystone 汇编 → Capstone 校验地址
                           → 截断(地址不匹配)→ BadFormat
    else:              → Keystone 直接汇编(既有)
  emit bytes
```

## 2. 与既有功能点的关系

- **check 预检同步受益**:`aa_precheck_asm` 以占位地址(0x1000 起,低位)调用同一
  `asm_assemble_labels`,自动校验含符号引用的指令合法性(编码路径一致);
  run 以真实地址编码,距离/位数限制在此判定。
- run/disable/status 行为不变;解析器 `aa_parse_text` 复用同一实现。
- 释放链路不变:`[DISABLE] dealloc(name)` 经 per-PID 落盘记录按名释放。
