# CLI - 能力需求列表(修改模式)

> 引用:v1.0.0/cli/08_能力需求列表.md 既有能力。本版本聚焦改动点新增能力需求,
> 只回答"CLI 需要做什么",不回答"用什么做"。

## 1. 改动点所需能力

| # | 能力需求 | 复用/缺失 |
|---|----------|-----------|
| 1 | 按类型枚举校验 type 参数(byte/word/dword/qword/float/double/string/hex/pattern) | 复用 parser 既有枚举校验模式,新增枚举集合 |
| 2 | 按类型校验 value(整数范围、浮点有限性、ASCII 字符集、hex 偶数长度、pattern 规则) | 复用 parser 既有校验框架,新增按类型校验函数 |
| 3 | 整数(无符号十进制/0x 十六进制)→ 小端字节(1/2/4/8 宽度) | **缺失** → CLI 标准库自实现 |
| 4 | float/double → IEEE754 小端字节(4/8) | **缺失** → CLI 标准库自实现 |
| 5 | ASCII 字符串 → 逐字节转换 | **缺失** → CLI 标准库自实现 |
| 6 | 连续 hex 字节串 → 空格分隔模式串 | **缺失** → CLI 标准库自实现 |
| 7 | 按字节模式扫描目标进程全部可读已提交内存区域,返回命中地址 | 复用静态库 `pattern_scan` 公共 API |
| 8 | 单次调用内自动 attach/detach 会话 | 复用 executor 既有逻辑 |

## 2. 缺失能力说明

能力 3/4/5/6 均为纯数值/字符编码转换,属于输入格式处理,使用 C/C++ 标准库
(strtoull/strtof/strtod/memcpy 等)即可实现,不涉及 OS API、不需要静态库新增能力。
扫描能力(能力 7)由静态库公共 API 覆盖,CLI 不重复实现。
