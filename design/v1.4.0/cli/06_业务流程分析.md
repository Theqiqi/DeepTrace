# CLI - 业务流程分析(修改模式)

> 引用:v1.0.0/cli/06_业务流程分析.md 既有流程。本版本只重画受影响命令
> `resolve scan` 的业务流程,其余命令引用既有文档。

## 1. resolve scan 业务流程图(类型值输入)

```
用户(脚本/AI/用户)
  │
  ▼
输入: deeptrace_cli -p <pid> resolve scan <value> [type]
  │
  ▼
[1] 解析命令与参数
    ├─ type 缺省 → pattern(向后兼容)
    ├─ type 非法 → Error: invalid type / 退出码 2(结束)
    └─ value 不符合 type 语义 → Error: invalid value for type / 退出码 2(结束)
  │
  ▼
[2] 单次调用内自动 attach(-p pid)
    ├─ attach 失败 → Error / 退出码 1(结束)
    └─ 成功 → 进入扫描
  │
  ▼
[3] 值 → 字节模式转换(value_to_pattern,标准库实现)
  │
  ▼
[4] pattern_scan(模式串) 扫描全部可读已提交内存区域
  │
  ▼
[5] 打印结果
    ├─ 有命中 → 每行一个 0x%016llX 地址,退出码 0
    └─ 无命中 → No match found,退出码 0
  │
  ▼
[6] 自动 detach 释放会话 → 退出
```

## 2. 边界说明

- 业务以单条命令为边界,`-p <pid>` 在本次调用内完成 attach → 操作 → detach
- 转换失败在解析阶段(退出码 2)即拦截,不会发起 attach 与扫描
- 无命中不属于错误:扫描成功但无结果,退出码 0 并输出 `No match found`
