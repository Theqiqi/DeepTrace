# CLI - 接口设计(修改模式)

> 引用:v1.0.0/cli/12_接口设计.md 既有接口。本版本标注改动数据结构与新增接口。

## 1. 接口分析

- command 层对外接口:parse_args(argc, argv) → ParseResult,不变
- interface 层对外接口:execute(req) → 退出码,不变
- 本版本新增 interface 层内部辅助函数(见下)

## 2. 数据结构列表(增量)

| 数据结构 | 变化 |
|----------|------|
| CommandRequest | 不变(args 通用容器已足够承载 value+type) |
| ParamSpec.type | 新增取值:`scan-type`、`scan-value`(parser 校验类型名) |
| 其余(ParseResult/CommandSpec 等) | 不变 |

## 3. 新增接口声明

```cpp
// interface/cmd.h (internal 命名空间)
// 把已通过校验的类型化值转换为 pattern_scan 可用的空格分隔大写 hex 模式串。
// value 已由 parser 按 type 校验,此处只做编码,不做校验。
// type ∈ byte|word|dword|qword|float|double|string|hex|pattern
std::string value_to_pattern(const std::string& value, const std::string& type);
```

- 声明位置:`cli/src/interface/cmd.h` 的 `internal` 命名空间(与 hex_bytes 等并列)
- 实现位置:`cli/src/interface/executor.cpp`(与 hex_bytes 等转换辅助函数一致)
- 调用位置:`cli/src/interface/cmd_resolve.cpp` scan 分支
