# CLI - 技术选型(修改模式)

## 结论:沿用既有技术选型

本版本为修改既有 CLI,沿用 v1.0.0/cli/17_技术选型.md 选型,不重复分析:

| 项 | 选型 |
|----|------|
| 程序类型 | 命令行可执行文件(exe) |
| 语言 | C++20 |
| 平台 | Windows |
| 框架 | Console |
| 构建 | CMake(CMakeLists.txt + CMakePresets.json) |
| 包管理 | vcpkg(仅测试依赖 gtest) |
| 依赖 | 静态库 deeptrace(公共头 deeptrace.h + out/lib/<配置>),keystone/capstone 显式链接 |
| 参数解析 | argc/argv + 自研 parser |

新增代码(value_to_pattern)仅用 C++ 标准库,无需新增依赖;测试框架沿用 gtest。
