# CLI - 职责和边界设计(修改模式)

> 引用:v1.0.0/cli/11_职责和边界设计.md 既有职责边界。本版本无结构性变化,
> 仅确认新增代码仍满足各层禁止项。

## 1. 既有职责(引用)

- command 层:解析参数、构造请求对象;禁止直接调用静态库 API
- interface 层:调用静态库公共 API(deeptrace.h),执行命令流程;禁止包含静态库内部头文件
- printing 层:纯格式化输出;禁止直接调库
- 各层单向调用:printing ← interface ← command ← main

## 2. 改动确认

- `value_to_pattern` 位于 interface 层(internal 命名空间),只使用 C/C++ 标准库
  (strtoull/strtof/strtod/memcpy/字符串处理),不包含 deeptrace 内部头文件 ✓
- cmd_resolve.cpp 只通过 `deeptrace::pattern_scan` 公共 API 触发扫描,
  不触碰 OS API(ReadProcessMemory 等)✓
- parser 校验逻辑纯标准库,不调库 ✓
- 打印层仅更新版本字符串,不新增职责 ✓

## 3. 禁止项复查(新增代码)

| 禁止项 | 状态 |
|--------|------|
| command/printing 直接调静态库 | 无新增违反 |
| interface 包含静态库内部头文件 | 无 |
| 生产代码使用平台相关 API / 第三方库 | 无(value_to_pattern 纯标准库) |
| 跨层反向调用 | 无 |
