# CLI - 功能点设计(修改模式)

> 引用:v1.0.0/cli/07_功能点设计.md 既有功能点。本版本只对改动点新增/更新功能点。

## 1. 受影响功能点增量

### F1(更新):resolve scan 类型化扫描

- 输入:`resolve scan <value> [type]`
- 功能:把用户输入的不同类型数据值转换为十六进制字节模式,扫描目标进程内存,
  输出命中地址列表
- 依赖:
  - 参数校验(parser):type 枚举校验 + 按类型的 value 校验
  - 值转换(executor 内部 `value_to_pattern`):标准库实现
  - 静态库公共 API `deeptrace::pattern_scan`
- 输出:命中地址(每行 `0x%016llX`)或 `No match found`;退出码 0 成功

### F2(新增):类型值字节转换

- 输入:已校验的 (value, type)
- 功能:value → 空格分隔大写 hex 模式串
  - 整数类型:无符号十进制/0x 十六进制 → 小端字节(宽度 1/2/4/8)
  - float/double:strtof/strtod 数值 → IEEE754 位模式 → 小端字节(4/8)
  - string:ASCII 可打印字符逐字节(不追加结尾 NUL)
  - hex:连续字节串 → 空格分隔模式
  - pattern:透传(已是最简 AOB 形式)
- 输出:模式串(如 `64 00 00 00`)

### F3(新增):按类型的参数校验

- 功能:type 枚举合法性;value 按 type 语义校验(范围/格式/字符集)
- 输出:非法 → `Error: ...`,退出码 2

## 2. 未受影响功能点

进程/内存/模块/线程/调试/反汇编/监视/注入/汇编/壳码等功能点不变,引用既有文档。
