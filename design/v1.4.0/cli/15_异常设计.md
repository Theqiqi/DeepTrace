# CLI - 异常设计(修改模式)

> 引用:v1.0.0/cli/15_异常设计.md 既有异常体系。本版本补充 scan 新增路径的错误处理。

## 1. 退出码语义(沿用)

- 0:成功(含扫描成功但无命中)
- 1:业务错误(attach 失败、静态库 API 失败、NotAttached 等)
- 2:用法错误(参数缺失/非法)

## 2. 新增错误路径(scan 类型值输入)

| 场景 | 输出(stderr) | 退出码 |
|------|--------------|--------|
| type 缺省 | (不报错,默认 pattern) | - |
| type 非法枚举 | `Error: invalid type: '<t>'` | 2 |
| value 不符合 type 语义 | `Error: invalid value for type '<t>': '<v>'` | 2 |
| 缺 value 参数 | `Error: missing argument: value` | 2 |
| 多余参数 | `Error: too many arguments: '<arg>'` | 2 |
| attach 失败(-p 目标不存在) | `Error: <result_message>(attach <pid>)` | 1 |
| pattern_scan 返回 NotAttached/其他错误 | `Error: <result_message>(<pattern>)` | 1 |
| 扫描成功但无命中 | stdout `No match found` | 0 |

## 3. 消息格式约束(沿用)

- 错误消息统一 `Error: <消息>` 前缀,输出到 stderr,纯 ASCII
- 命中输出到 stdout,每行一个 `0x%016llX`
