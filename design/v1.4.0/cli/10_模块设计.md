# CLI - 模块设计(修改模式)

> 引用:v1.0.0/cli/10_模块设计.md 既有三层架构。本版本标注新增/修改命令落在哪些层与文件。

## 1. 三层架构

```
main.cpp → command(解析) → interface(执行) → printing(输出)
              │                    │
              │              deeptrace 公共 API
```

## 2. 改动落点

| 层 | 文件 | 改动 |
|----|------|------|
| command | commands.cpp | `resolve scan` 命令表(usage/brief/params)+ 帮助文本版本号 |
| command | parser.cpp | 新增参数类型 `scan-type`(枚举校验)与 `scan-value`(按类型校验) |
| interface | cmd.h | 新增 `internal::value_to_pattern` 声明 |
| interface | executor.cpp | 实现 `internal::value_to_pattern`(标准库) |
| interface | cmd_resolve.cpp | scan 分支:value_to_pattern → pattern_scan 调用链 |
| printing | printer.cpp | version 输出 v1.4.0(无新增输出格式) |
| 构建 | CMakeLists.txt | 工程版本 1.4.0 |

## 3. 未涉及模块

mem/module/thread/debug/disasm/watch/dll/asm/shellcode 各组处理器、executor 自动会话
逻辑、其余 printer 输出格式均不涉及,引用既有文档与代码。
