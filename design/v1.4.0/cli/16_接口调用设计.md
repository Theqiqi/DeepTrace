# CLI - 接口调用设计(修改模式)

> 引用:v1.0.0/cli/16_接口调用设计.md 既有映射。本版本列出改动点新增的 API 映射。

## 1. 新增 API 映射

| CLI 动作 | 静态库公共 API | 说明 |
|----------|----------------|------|
| resolve scan(类型值) | `deeptrace::pattern_scan(pattern, hits)` | value_to_pattern 转换后的模式串直接传入 |
| resolve scan(-p 自动会话) | `deeptrace::attach(pid)` / `detach()` | 复用 executor 既有自动 attach/detach 路径,无需新增 |

- cmd_resolve.cpp scan 分支调用链:

```cpp
std::string pattern = internal::value_to_pattern(req.args[0], req.args[1]);
deeptrace::Result r = deeptrace::pattern_scan(pattern, hits);
```

- req.args 布局:`args[0]`=value,`args[1]`=type(parser 已填充默认值 `pattern`)

## 2. 资源生命周期核对

- scan 命令的 attach/detach 走 executor 既有 `needs_session_attach` 路径
  (group != ps 且 pid_set → 自动 attach,命令结束自动 detach)
- 本改动不新增成对资源;attach/detach 配对完整性由测试阶段「副作用检查」
  (attach 后目标进程仍存活、detach 后无残留)验证
- 转换失败在 parser 阶段拦截(退出码 2),不进入 attach,无资源占用

## 3. 匹配完成确认

- 能力匹配(09)已完成:扫描/会话能力由 deeptrace 公共 API 覆盖
- 静态库流程未触发,无完成契约等待;可直接实现接口调用层
