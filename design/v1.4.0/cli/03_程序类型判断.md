# CLI - 程序类型判断(修改模式)

## 结论:沿用既有 CLI 无交互类型

本版本为修改既有 CLI(添加 `resolve scan` 类型值输入形式),程序类型不变,不做重复判断。

- 操作可抽象为命令+参数:`resolve scan <value> [type]`,仍是一次执行一个操作
- 输入可抽象为参数:value/type 均为位置参数,无交互输入
- 输出可文本化:命中地址列表(纯 ASCII 十六进制地址),退出码 0/1/2 语义不变
- 无实时可视化/多线程并行需求,不跳转 GUI 或服务流程

沿用 v1.0.0/cli/03_程序类型判断.md 判定结果。
