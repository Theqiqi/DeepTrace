## 2. 功能方向

CLI 需要完成的功能方向:让用户能以"自然数据类型"输入扫描目标值,由 CLI 负责
把值编码成内存中的字节形态(与目标进程 x64 小端存储一致),再复用既有扫描能力定位地址。
需求覆盖:

1. 类型化输入:支持常见标量类型(整数/浮点)与字符串、hex、既有 AOB pattern
2. 转换正确性:整数小端、浮点 IEEE754 小端、ASCII 逐字节,转换纯标准库实现
3. 向后兼容:不传 type 时与 v1.3.0 完全一致
4. 错误处理:非法类型/非法值/超范围/非 ASCII 字符串 → `Error: ...` + 退出码 2
5. 约束保持:无交互、一次调用一个操作、纯 ASCII 输出、-p 自动 attach/detach

## 3. 非目标(本版本不做)

- 不做有符号负数支持(整数按无符号解析,负数返回用法错误)
- 不做大小端切换选项
- 不做通配符与类型值混用(类型值扫描不支持 ??;通配仅限 pattern 模式)
- 不修改静态库 deeptrace(能力完全复用 pattern_scan)
