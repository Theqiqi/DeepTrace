## 1. resolve 命令组(更新)

```
resolve base <module>                  Get base address of module
resolve scan <value> [type]            Scan for a value or AOB pattern
                                       (type: byte|word|dword|qword|float|double|string|hex|pattern)
```

- `type` 可选,默认 `pattern`(既有 AOB 行为,向后兼容)
- `value` 语义随 type 变化:
  - 整数类型:无符号十进制或 0x 前缀十六进制,小端字节
  - float/double:IEEE754 小端字节
  - string:ASCII 可打印字符逐字节
  - hex:连续 hex 字节串(偶数长度)
  - pattern:空格分隔 hex 字节 + ?? 通配(AOB)

### 使用示例

```
deeptrace_cli -p 1234 resolve scan 100 dword
deeptrace_cli -p 1234 resolve scan 0x11223344 dword
deeptrace_cli -p 1234 resolve scan 3.14 float
deeptrace_cli -p 1234 resolve scan "hello" string
deeptrace_cli -p 1234 resolve scan DEADBEEF hex
deeptrace_cli -p 1234 resolve scan "48 8B ?? ?? 00"        # 默认 pattern
```
