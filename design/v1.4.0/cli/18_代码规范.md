# CLI - 代码规范(修改模式)

## 结论:沿用既有代码规范

本版本沿用 v1.0.0/cli/18_代码规范.md 全部规范,新增代码强制满足以下条目:

1. CLI 源码不允许包含静态库内部头文件(只允许 `deeptrace.h`)
2. CLI 只能通过公共 API 与静态库交互(`value_to_pattern` 不调库,扫描只经 `pattern_scan`)
3. CLI 生产代码禁止使用平台相关 API 或第三方库,只允许静态库公共 API 与 C/C++ 标准库
   (`value_to_pattern` 仅用 strtoull/strtof/strtod/memcpy/字符串标准库)
4. CLI 所有输出字符串使用纯 ASCII 可打印字符(帮助文本、错误消息、命中地址)
5. 无交互:禁止 getchar/scanf/cin 等待;命令执行完立即退出
6. 一次调用一个操作;会话生命周期 = 本次 CLI 进程(-p 单次调用内 attach/detach)

## 风格约定(沿用)

- namespace deeptrace_cli;internal 命名空间放转换辅助函数(与 hex_bytes 并列)
- 错误消息 `Error: <msg>` 前缀;退出码 0/1/2
- 头文件 #pragma once;实现文件按既有拆分习惯落位
