# CLI - 参数列表(修改模式)

> 引用:v1.0.0/cli/14_参数列表.md 既有参数类型。本版本新增两个参数类型并更新
> resolve scan 的参数规格;commands.cpp 的 ParamSpec 与 parser.cpp 校验逻辑同步。

## 1. 新增参数类型定义

| 类型 | 语法 | 示例 | 校验规则 |
|------|------|------|---------|
| scan-type | 枚举:byte/word/dword/qword/float/double/string/hex/pattern | `dword` | 枚举校验 |
| scan-value | 随 type 变化(见下表) | `100` / `3.14` / `hello` | 按 type 联动校验 |

### scan-value 按 type 校验规则

| type | 接受语法 | 校验规则 |
|------|----------|---------|
| byte | 十进制 或 0x 十六进制,无符号 | 0 ≤ 值 ≤ 0xFF |
| word | 同上 | 0 ≤ 值 ≤ 0xFFFF |
| dword | 同上 | 0 ≤ 值 ≤ 0xFFFFFFFF |
| qword | 同上 | 0 ≤ 值 ≤ 0xFFFFFFFFFFFFFFFF |
| float | 十进制浮点(含科学计数法) | strtof 全串解析且有限(非 inf/nan) |
| double | 同上 | strtod 全串解析且有限 |
| string | ASCII 可打印字符序列 | 非空;每个字符 ∈ [0x20, 0x7E] |
| hex | 连续 hex 字节串(可选 0x 前缀) | 非空;偶数长度;仅 0-9a-fA-F |
| pattern | AOB(空格分隔,?? 通配) | 沿用 valid_pattern:1-64 字节,?? 或双 hex 字符 |

### 不支持(返回用法错误,退出码 2)

- 整数负数(如 `-1`)→ invalid value
- 非 ASCII 字符串(含中文/控制字符)
- 类型值扫描混用通配符(?? 仅 pattern 模式)
- 奇数长度 hex、非 hex 字符 hex

## 2. resolve scan 参数规格(更新)

| 命令 | 参数 | 默认 |
|------|------|------|
| resolve scan | value(必填,scan-value), type(可选,scan-type) | type=pattern |

## 3. 参数错误处理(沿用)

- 缺必填参数:输出 `Error: missing argument: <name>`,退出码 2
- 类型非法:输出 `Error: invalid type: '<value>'`,退出码 2
- 值非法:输出 `Error: invalid value for type '<type>': '<value>'`,退出码 2
- 多余参数:输出 `Error: too many arguments: '<arg>'`,退出码 2
