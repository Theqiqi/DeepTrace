## 2. 需求说明

### 2.1 disasm file(新增功能点)

**动机**:从样本/exploit 提取的 .bin shellcode 需要离线分析看懂。
现有 `disasm at/range` 只反汇编目标进程内存,不碰本地文件。

**输入**:`disasm file <path.bin> [count]`;count 可选,默认 100,>0。

**处理**:读 .bin → 静态库 `disasm_buffer`(纯 buffer 解码,Capstone,
基址从 0 开始)→ `print_instructions` 输出(与进程内 disasm 同款)。

**输出示例**:
```
$ deeptrace_cli disasm file payload.bin
0x0000000000000000  48 8B 05 00 00 00 00  mov rax, [rip+0]
0x0000000000000007  FF 25 00 00 00 00     jmp [rip+0]
0x000000000000000D  C3                    ret
```

### 2.2 bin2hex(新增功能点)

**输入**:`bin2hex <path.bin> [format]`;format 可选
hex(默认,空格分隔)/dec/bin/ascii/c-array,复用 `print_bytes_formatted`。

**处理**:读 .bin → 按 format 打印;输出可喂回 `shellcode inject` / `hex2bin`。

**输出示例**:
```
$ deeptrace_cli bin2hex payload.bin
48 8B 05 00 00 00 00 FF 25 00 00 00 00 C3
```

## 3. 能力边界

- 支持:本地 .bin 反汇编/转 hex;多格式输出;纯数据无进程。
- 不支持/错误:
  - 文件不存在/不可读 → 用法错误退出 2。
  - 空文件 → 反汇编无输出退出 0;bin2hex 报错退出 2。
  - 反汇编遇不可解码字节 → 截断(与进程内 disasm 语义一致),退出 0。
  - 无需 attach(-p 不影响;命令本身无会话依赖)。
