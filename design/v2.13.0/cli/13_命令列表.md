# CLI - 命令列表(修改模式,功能,v2.13.0)

> 引用:v2.12.0/cli/13_命令列表.md。v2.13.0 新增:

## 1. disasm 组新增命令

```text
disasm file <path.bin> [count]
    本地 .bin 文件反汇编(离线分析 shellcode/载荷)
    输出: print_instructions 同款(基址从 0 开始)
    无会话依赖(不需 attach)
```

- 帮助文本:disasm 组新增 file 条目;count 默认 100。

## 2. 新命令组 bin2hex

```text
bin2hex <path.bin> [format]
    .bin → hex 字节(hex2bin 逆操作),format: hex|dec|bin|ascii|c-array
    输出可直接喂回 shellcode inject / hex2bin
```

- 帮助文本:新命令组 bin2hex。

## 3. 其余命令

disasm at/range、hex2bin、asm、shellcode、convert、script 等全部不变。
