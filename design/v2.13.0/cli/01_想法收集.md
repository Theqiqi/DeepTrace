## 现状盘点(结论)

| 转换 | 现状 |
|------|------|
| asm → bin | ✅ `asm file <path.asm> --out <path.bin>`(Keystone) |
| asm → hex | ✅ `asm assemble <code> [--hex]` |
| hex → bin | ✅ `hex2bin <hex> <output.bin>` |
| bin → hex | ❌ 缺(仅 shellcode injectfile 间接消费) |
| bin → asm | ❌ 缺(disasm 只对进程内存) |

## 职责分层定稿

- **转换层**:格式互转,纯数据无进程。补 bin→hex / bin→asm 后环闭合。
- **脚本层**:程序化注入(指令+db 字节混编、符号/hook/生命周期)。
- **shellcode 层**:独立载荷生命周期(alloc/run/free/status)。
- db 与 shellcode 入口不重复:db 是脚本内小片段,shellcode 是独立大载荷。

## 本期范围

- `disasm file <path.bin> [count]`:本地文件反汇编(Capstone,离线分析)。
- `bin2hex <path.bin> [format]`:hex2bin 逆操作。
- 静态库 `disasm_buffer` 公共 API(纯 buffer 解码,零会话依赖)。
