# CLI - 功能点设计(修改模式,功能,v2.13.0)

> 引用:v2.12.0/cli/07_功能点设计.md。v2.13.0 新增两个转换层功能点。

## 1. disasm file

### 1.1 命令形态

```text
disasm file <path.bin> [count]
```

- count 可选,默认 100,>0(上限 10000,同 disasm at)。
- 文件读取用 `internal::read_binary_file`(executor 已有,shellcode injectfile 同款)。

### 1.2 正常路径

```
disasm file payload.bin
  → read_binary_file → disasm_buffer(bytes, count) → print_instructions → 0
```

### 1.3 错误路径

| 场景 | 层 | 退出码 |
|------|----|--------|
| 文件不存在/不可读 | 执行层 | 2 |
| count 非法(0/超限) | 解析层 | 2 |
| 空文件 | 执行层 | 无输出,0 |

## 2. bin2hex

### 2.1 命令形态

```text
bin2hex <path.bin> [format]
```

- format 可选 hex(默认)/dec/bin/ascii/c-array,复用 `print_bytes_formatted`。

### 2.2 正常路径

```
bin2hex payload.bin --hex
  → read_binary_file → print_bytes_formatted(bytes, format) → 0
```

### 2.3 错误路径

| 场景 | 层 | 退出码 |
|------|----|--------|
| 文件不存在/不可读 | 执行层 | 2 |
| format 非法 | 解析层 | 2 |
| 空文件 | 执行层 | 报错,2 |

## 3. 静态库 disasm_buffer

- `disasm_buffer(const uint8_t* data, size_t size, uint32_t count,
  std::vector<Instruction>& out)`:纯 buffer 解码,无会话/无进程读取。
- `disasm_at` 重构为:读内存 → `disasm_buffer`,行为不变(回归锁定)。

## 4. 能力边界

- 转换层纯数据操作,不依赖 attach;`-p` 不影响。
- 反汇编输出与进程内 disasm 完全同款(print_instructions)。
- bin2hex 输出与 `mem read hex` / hex2bin 输入格式一致(空格分隔 hex)。
