# CLI - 异常设计(修改模式,功能,v2.13.0)

> 引用:v2.12.0/cli/15_异常设计.md。v2.13.0 新增:

## 1. disasm file

| 场景 | 层 | 退出码 | 消息 |
|------|----|--------|------|
| 文件不存在/不可读 | 执行层 | 2 | cannot read file: <path> |
| count 非法(0/非数字/超限) | 解析层 | 2 | 解析错误 |
| 空文件 | 执行层 | 0 | 打印表头,0 条指令(print_instructions 空列表行为) |
| 字节不可解码 | 执行层 | 0 | 截断(同 disasm at 语义) |

## 2. bin2hex

| 场景 | 层 | 退出码 | 消息 |
|------|----|--------|------|
| 文件不存在/不可读 | 执行层 | 2 | cannot read file: <path> |
| format 非法 | 解析层 | 2 | invalid format: <f> |
| 空文件 | 执行层 | 2 | empty file: <path> |

## 3. 共性

- 无会话依赖,不存在 NotAttached 场景。
- 错误消息统一走 stderr(print_error),与既有转换类命令一致。
