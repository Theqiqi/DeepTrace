# CLI - 参数列表(修改模式,功能,v2.13.0)

> 引用:v2.12.0/cli/14_参数列表.md。v2.13.0 新增:

## 1. disasm file 命令参数

| 命令 | # | 参数 | 必填 | 类型 | 校验 |
|------|---|------|------|------|------|
| disasm file | 1 | file | 是 | path | 可读文件(接口层查) |
| disasm file | 2 | count | 否 | number | 1..10000,默认 100 |

## 2. bin2hex 命令参数

| 命令 | # | 参数 | 必填 | 类型 | 校验 |
|------|---|------|------|------|------|
| bin2hex | 1 | file | 是 | path | 可读文件(接口层查) |
| bin2hex | 2 | format | 否 | format-arg | hex/dec/bin/ascii/c-array,默认 hex |

## 3. 其余参数

命令组其余参数全部不变,引用既有文档。
