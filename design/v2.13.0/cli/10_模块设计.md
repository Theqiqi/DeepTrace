# CLI - 模块设计(修改模式,功能,v2.13.0)

> 引用:v2.12.0/cli/10_模块设计.md。v2.13.0 改动点:

## 1. 模块职责调整

| 模块 | 变更 |
|------|------|
| command/commands.cpp | 新增 bin2hex 命令组 + disasm file 条目;版本 2.13.0 |
| command/parser.cpp | 新增 format-arg 解析(bin2hex 的 format,仿 convert type 校验);disasm file 的 count opt |
| interface/cmd_disasm.cpp | 新增 `file` 动作(read_binary_file → disasm_buffer → print_instructions) |
| interface/cmd_hex2bin.cpp | 新增 `bin2hex` 命令处理器(或独立 cmd_bin2hex.cpp) |
| 静态库 service/disasm | 抽公共 `disasm_buffer`(纯 buffer 解码);disasm_at 复用 |

## 2. 依赖关系

- cmd_disasm / bin2hex 依赖 `internal::read_binary_file`(executor)。
- 静态库 disasm_buffer 依赖 infrastructure/disassembly(已有 Capstone 封装)。
- 无新增第三方依赖。
