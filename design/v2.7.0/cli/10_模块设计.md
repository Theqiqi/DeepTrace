# CLI - 模块设计(修改模式,增量,v2.7.0)

> 引用:v2.6.0/cli/10_模块设计.md。v2.7.0 改动落点:脚本执行链路
> (cmd_script.cpp)的 near 锚点产出与传递 + 版本号,解析层与打印层无结构改动。

## 1. 改动点 → 层 / 文件映射

| 改动点 | 层 | 文件 | 说明 |
|--------|----|------|------|
| near 表达式解析为锚点(新增输出) | 脚本执行层 | src/interface/cmd_script.cpp | `resolve_enable` 增参 `near_anchors`(alloc 符号名 → 锚点地址);模块形式 anchor=base+offset,裸地址直接解析 |
| 分配时传入锚点(修改) | 脚本执行层 | src/interface/cmd_script.cpp | `exec_enable` 增参 `near_anchors`;Phase 1 有锚点调 `script_alloc_near`,无锚点调 `script_alloc` |
| 调用链贯通 | 脚本执行层 | src/interface/cmd_script.cpp | `script_run` 构造并传递 `near_anchors` |
| 静态库新 API | 静态库(见 deeptrace 流程) | DeepTrace/... | `script_alloc_near(name,size,anchor,owner,&addr)`、`RemoteAllocNear(...)` |
| 版本号 2.7.0 | 打印/命令层 | printer.cpp、commands.cpp | help/version 字符串 |

## 2. 职责边界(与既有约定一致)

- 命令解析层(classify):只做 near 表达式**语法**校验(模块形式结构、偏移
  hex),不解析地址——地址解析需 attach 后 resolve_base,属执行层。
- 脚本执行层(resolve_enable):near 表达式 → 锚点地址(模块加载校验 + 偏移
  合成),产出 near_anchors 表;exec_enable 消费并决定走
  script_alloc_near / script_alloc。
- 静态库:就近分配算法(VirtualQueryEx 窗口扫描)完全封装在静态库内部,
  CLI 只传锚点地址,不感知窗口实现。
- 命令打印层:alloc 输出格式不变;错误输出沿用 report_error。
