# CLI - 命令列表(修改模式,增量,v2.7.0)

> 引用:v2.6.0/cli/13_命令列表.md。v2.7.0 **不新增命令**;脚本 `alloc` 关键字的
> near 第三参数语义升级为真实就近分配。

## 1. alloc 关键字(script 脚本内,语义增强)

```text
alloc <name>, <size> [, <near_expr>]
```

- `<near_expr>`(第三参数,可选)v2.7.0 起为**真实就近分配锚点**:
  1. `"module.dll"+0x<offset>` —— 模块基址 + 十六进制偏移,如
     `alloc(newmem,2048,"GameAssembly.dll"+7D5778)`;模块需已加载(未加载 →
     `Error: NotFound(<module>)` 退出 1);
  2. 裸地址(十进制 / 0x 十六进制)。
  分配落点保证在锚点 ±2GB(RIP 相对 rel32 上限)窗口内、优先贴近锚点;
  窗口内无足够空闲区 → 分配失败退出 1(不静默退化为任意分配)。
- 不带第三参数:行为不变(OS 任意选址,与 v2.5.0 一致)。
- `script check` 语法校验规则不变(非法 near 表达式照旧拒绝)。
