# CLI - 参数列表(修改模式,增量,v2.7.0)

> 引用:v2.6.0/cli/14_参数列表.md。v2.7.0 修改脚本 alloc 关键字第三参数的
> 语义(放置提示 → 就近分配),无新增命令参数。

## 1. alloc 第三参数(near_expr,语义升级)

| 关键字 | # | 参数 | 必填 | 类型 | 取值/校验(v2.7.0) |
|--------|---|------|------|------|-----------|
| alloc | 1 | name | 是 | 符号名 | `[A-Za-z_][A-Za-z0-9_]*`(v2.6.0 形状,不变) |
| alloc | 2 | size | 是 | u64 | 十进制 / 0x 十六进制,> 0 |
| alloc | 3 | near_expr | 否 | near 表达式 | 见下 |

### near_expr 取值(v2.7.0)

| 形式 | 语法 | 解析 | 校验 |
|------|------|------|------|
| 模块 + 偏移 | `"module.dll"+0x<hex>` | resolve_base(module) + 偏移 | 模块已加载(未加载 → NotFound,退出 1) |
| 裸地址 | 十进制 / 0x 十六进制 | parse_u64 | 值 > 0 |

- 解析结果 = **锚点地址**,传给静态库 `script_alloc_near` 做 ±2GB 就近分配。
- 语法非法(缺 `+offset`、偏移非 hex、空)→ 解析期报错,check/run 均拒绝
  (既有行为,不变)。
- 不带第三参数 → `script_alloc`(OS 任意选址,行为不变)。
