# CLI - 需求分析(修改模式,增量,v2.7.0)

> 引用:v2.6.0/cli/04_需求分析.md。v2.7.0 为「alloc near 真实就近分配」功能增量:
> `alloc(name,size,"module.dll"+0x1234)` 的第三参数从「放置提示,不保证就近」
> 升级为**真实就近分配(锚点 ±2GB 内)**,消除 RIP 相对位移超界概率。

## 1. 需求变更清单

| # | 改动点 | 新增/修改/删除 | 影响命令组 |
|---|--------|----------------|------------|
| 1 | alloc 第三参数(near)真实就近分配:锚点 ±2GB 窗口内找空闲区 | 修改(alloc 语义) | script run / check |
| 2 | 静态库新公共 API `script_alloc_near(name,size,anchor,owner,&addr)` 就近分配 + 符号记录 | 新增(静态库能力) | - |
| 3 | CLI resolve_enable 解析出的 near 锚点传给 exec_enable(原来被丢弃) | 修改(脚本执行链路) | script run |
| 4 | 就近失败(窗口内无空闲)报错,不静默退化为任意分配 | 修改(错误语义) | script run |
| 5 | 无 near 第三参数行为完全不变(OS 任意选址) | 不变 | script run |

## 2. 需求说明

### 2.1 near 真实就近分配(修改功能点)

**动机**:`alloc(newmem, 2048, "GameAssembly.dll"+0x7D5778)` 的场景下,脚本会
在锚点附近生成 RIP 相对跳转(`"m.dll"+0x7D5778: jmp newmem`)。RIP 相对 rel32
位移上限为 ±2GB。v2.5.0 起的实现是裸 `VirtualAllocEx(nullptr,...)`(OS 任意
选址),newmem 可能落在锚点 2GB 之外 → 运行时非法指令/访问违例。本版本把第三
参数变为**真实就近分配**:分配地址保证落在锚点 ±2GB 窗口内,且优先贴近锚点,
从根上消除超界概率。

**输入**:`alloc(name, size, near_expr)` 的第三参数,语法沿用 v2.5.0:
- `"module.dll"+0x1234`(模块基址 + 十六进制偏移)
- 裸地址(十进制 / 0x 十六进制)

**处理**:脚本执行前 `resolve_enable` 解析 near 表达式为**锚点地址**
(模块形式:resolve_base + 偏移;裸地址:直接解析),并保留既有模块加载校验。
执行时 `exec_enable` 对带锚点的 alloc 调 `script_alloc_near`,无锚点调
`script_alloc`(行为不变)。

**输出**:与无 near 的 alloc 一致(`alloc <name> = 0x... (N bytes)`),无新
输出格式;就近失败 → `Error: ...` 退出 1,不静默回退。

**无交互约束**:与 script run 既有约束一致(attach 后执行、一次调用一操作)。

### 2.2 受影响既有功能点(修改)

- `script run`:alloc 步骤的第三参数从「仅校验模块加载」变为「校验 + 就近
  分配」。`script check`:语法校验不变(parse 层已拒绝非法 near 表达式);
  模块加载校验属运行时,check 不 attach 不涉及。
- 不带 near 的 alloc:`script_alloc` 路径原样保留。

## 3. 能力边界(声明支持 / 不支持)

- 支持:`alloc` 第三参数(`"module"+offset` 或裸地址)真实就近分配,落点在
  锚点 ±2GB 内,优先贴近锚点。
- 不支持/错误:
  - near 表达式语法非法(如 `"module"` 无 `+offset`、偏移非 hex)→ 解析期
    报错,`script check` / `script run` 均拒绝(既有行为)。
  - 模块未加载(`"module"+offset` 的 module 不存在)→ NotFound 退出 1(既有)。
  - 锚点 ±2GB 窗口内无足够空闲区 → 分配失败退出 1(**不静默回退**)。
  - 32 位进程:地址空间 < 2GB,窗口退化为全地址空间(就近语义自然成立)。

## 4. 需求点设计

| 需求点 | 说明 |
|--------|------|
| R1 near 真实就近 | alloc 第三参数解析为锚点,分配落点在锚点 ±2GB 内、贴近锚点 |
| R2 向后兼容 | 无第三参数 → script_alloc(OS 任意选址),行为完全不变 |
| R3 错误语义 | 语法非法(2)/ 模块未加载 NotFound(1)/ 窗口无空闲 Error(1) |
| R4 不静默回退 | 声明 near 就真的 near;就近失败宁可报错也不远配 |
