# CLI - 异常设计(修改模式,增量,v2.7.0)

> 引用:v2.6.0/cli/15_异常设计.md。v2.7.0 新增「near 就近分配失败」错误路径,
> 其余错误路径不变。

## 1. 新增错误路径(near 就近分配)

| 场景 | 层 | 退出码 | 输出 |
|------|----|--------|------|
| near 表达式语法非法(缺 +offset / 偏移非 hex) | 解析器(classify) | 2 | `script parse error at line N: invalid alloc near ...` |
| near 模块未加载 | 脚本执行层(resolve_enable) | 1 | `Error: NotFound(<module>)`(既有语义) |
| 锚点 ±2GB 窗口内无足够空闲区 | 静态库 script_alloc_near → Error | 1 | `Error: ...`(report_error,含 alloc 名) |
| 就近分配成功但记录落盘失败 | 静态库(回滚释放后) → Error | 1 | `Error: ...` |

## 2. 错误语义关键点

- **不静默回退**:near 就近失败绝不退化为「任意位置分配」——用户声明 near
  即要求近;失败报错,用户可换锚点或去掉 near。
- **与 script_alloc 对齐**:script_alloc_near 错误码复用既有 Result
  (NotAttached/InvalidArg/Error),CLI 侧 report_error 沿用,无需新错误格式。
- 既有脚本错误(汇编 BadFormat、写失败、hook 失败等)与退出码语义
  (0 成功 / 1 业务错误 / 2 用法错误)不变。

## 3. 既有错误路径

符号寻址(v2.6.0)、数字地址读写/监视/注入的既有错误路径全部不变。
