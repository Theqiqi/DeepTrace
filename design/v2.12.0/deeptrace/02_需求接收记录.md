# deeptrace - 跨流程需求接收记录(design/v2.12.0/deeptrace/02_需求接收记录.md)

> 关联交接记录:design/v2.12.0/cli/01_想法收集.md(CLI v2.12.0 发起)。
> 来源:CLI 需「从目标值反推指针链」能力(pointer map 两段式)。

## 1. 接收清单(逐项)

### M1:线程池(Infrastructure/threadpool)

| 项 | 内容 |
|----|------|
| 缺失能力 | 并行扫描所需线程池(纯标准库) |
| 期望实现 | `internal::ThreadPool` 类:固定 worker 线程 + 任务队列 |
| 输入 | 线程数(>0)、任务函数 |
| 输出 | 任务并行执行、join 后全部完成 |
| 异常要求 | 线程数 0 → InvalidArg;析构 join 所有线程 |
| 验收标准 | ①N 个任务在 M 线程上并行执行;②析构不泄漏;③hardware_concurrency 默认值 |

### M2:pointer map 快照(反向反推指针链)

| 项 | 内容 |
|----|------|
| 缺失能力 | 从目标地址反推多层指针链(全内存反向扫描) |
| 期望公共 API | `Result pointer_map_snapshot(const PointerScanConfig& cfg, std::vector<PointerChain>& out)` |
| 输入 | target 地址、max_offset、max_level、max_results、模块锚定(可选)、线程数 |
| 输出 | 指针链列表(每条 = 根地址 + 偏移序列) |
| 异常要求 | 未 attach → NotAttached;cfg 非法(max_offset=0 等)→ InvalidArg;无结果 → Ok+空 |
| 验收标准 | ①能反推出测试目标预埋的已知链;②链起点默认锚定模块基址(可关闭);③max_level 限制深度;④max_offset 限制每层指针指向范围 |

### M3:pointer map 重扫(交集过滤)

| 项 | 内容 |
|----|------|
| 缺失能力 | 用新快照过滤旧链列表,保留真实结构链 |
| 期望公共 API | `Result pointer_map_rescan(const std::vector<PointerChain>& base, uintptr_t new_target, const PointerScanConfig& cfg, std::vector<PointerChain>& out)` |
| 输入 | 旧链列表、新目标地址、配置 |
| 输出 | 过滤后链列表(仅仍解析到新目标的链) |
| 异常要求 | 未 attach → NotAttached;空输入 → Ok+空 |
| 验收标准 | ①每条链在新目标下重新求值,命中才保留;②假阳性链被丢弃;③顺序稳定 |

### M4:模块锚定

| 项 | 内容 |
|----|------|
| 缺失能力 | 限制链起点落在指定模块基址内 |
| 期望实现 | PointerScanConfig.module 非空时,根地址必须在 module_base..+size 内 |
| 输入 | 模块名(可选) |
| 输出 | 过滤链起点 |
| 异常要求 | 模块未加载 → NotFound(配置错误) |
| 验收标准 | ①锚定默认开启;②配置 module 为空 = 不锚定;③锚定链起点 ∈ 模块范围 |
