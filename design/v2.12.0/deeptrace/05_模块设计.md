# deeptrace - 模块设计(修改模式,v2.12.0)

> 引用:既有模块设计。v2.12.0 新增指针链搜索能力。

## 1. 改动点 → 层 / 文件映射

| 改动点 | 层 | 文件 | 说明 |
|--------|----|------|------|
| 指针链数据结构 | Domain | src/domain/types.h | PointerScanConfig / PointerChain |
| 反向反推算法 | Algorithm | src/algorithm/pointer_scan.h/cpp | scan_pointers_to(data,len,target,max_offset):纯 buffer 扫描,返回候选地址+偏移 |
| 线程池 | Infrastructure | src/infrastructure/threadpool/threadpool.h/cpp | 纯标准库固定 worker 池 |
| 快照/重扫组装 | Service | src/service/resolve.h/cpp | 区域枚举→分块读→并行算法→锚定/截断 |
| 公共头 | 对外 | include/deeptrace.h | pointer_map_snapshot / pointer_map_rescan |
| 单测 | 测试 | test/unit/pointer_scan_test.cpp | 算法纯 buffer 用例(已知链/偏移/层级) |
| 集成 | 测试 | test/integration/process_integration_test.cpp | 真实进程预埋链反推 + rescan 过滤 |

## 2. 职责边界

- **Domain**:纯数据结构(与既有类型一致)。
- **Algorithm**:纯内存计算(不读进程),输入 buffer 输出候选;可完全单测。
- **Infrastructure threadpool**:并行执行原语(任务队列 + worker),复用
  标准库;不感知业务。
- **Service resolve**:组装流程(枚举区域→分块读→喂算法→锚定→截断),
  线程池调用方;所有 deeptrace 调用对应公共/内部 API。
- 零副作用:快照/重扫只读目标进程。
