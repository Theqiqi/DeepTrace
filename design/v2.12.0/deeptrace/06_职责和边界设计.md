# deeptrace - 职责和边界设计(修改模式,v2.12.0)

> 引用:既有职责文档。v2.12.0 增量:

## 1. 各层职责

- **Domain**:PointerScanConfig/PointerChain 纯数据结构。
- **Algorithm**:反向反推核心算法(纯 buffer,可单测,无 I/O)。
- **Infrastructure/threadpool**:并行原语(纯标准库);memory 复用既有。
- **Service/resolve**:流程组装(枚举/读/算/锚定/截断),对外 API。

## 2. 禁止项

- 禁止 Algorithm 层直接读进程内存(保持纯计算可测)。
- 禁止线程池用第三方库/平台 API(仅 std::thread + hardware_concurrency)。
- 禁止在快照/重扫中写目标进程(只读,零副作用)。
- 禁止 CLI 重复实现扫描算法(必须走静态库公共 API)。
