# deeptrace - 需求分析(修改模式,v2.12.0)

> 引用:既有需求文档。v2.12.0 为「指针链搜索」新功能(pointer map 两段式)。

## 1. 领域对象

- **PointerChain**:一条指针链 = 根地址(root,模块基址内)+ 偏移序列
  `offsets[0..n-1]`。求值:addr = root;for off: addr = *(addr) + off。
- **PointerScanConfig**:target 地址 / max_offset / max_level / max_results /
  模块锚定(module,可空)/ 线程数(thread_count)。
- **快照(snapshot)**:一次全内存反向反推产生的链列表。
- **重扫(rescan)**:用新目标地址对旧链列表求值过滤(交集)。

## 2. 数据流

```
pointer_map_snapshot(cfg)
  → 枚举内存区域(复用 EnumMemoryRegions 过滤)
  → 分块读入内存(复用 pattern_scan 的分块框架)
  → 反向反推(线程池并行):
      层 0: 全内存找 qword ∈ [target-max_offset, target+max_offset]
            的地址 A0,链 = {A0} + 偏移(A0+off==target 的 off)
      层 n: 对每层候选地址再找「指向它的指针」,直到模块锚定或 max_level
  → 模块锚定过滤 → max_results 截断 → 输出链列表

pointer_map_rescan(base, new_target, cfg)
  → 逐条求值 base 链(读目标内存,线程池并行)
  → 仅保留最终地址 == new_target ± max_offset 的链
  → 输出过滤后链列表
```

## 3. 算法要点(反向反推)

- **层 0(直接指针)**:扫描所有可读内存,找存着「target 地址附近」的 qword
  指针的地址。地址 A 命中当 |*(qword)A - target| <= max_offset;链 =
  {A} + (target - *(qword)A)。即 `A + off` 直达 target。
- **层 n+1**:上一层的候选地址集合成为新目标集合;再扫内存找指向它们的
  指针,递归。每层都要全内存扫描 → 必须线程池并行。
- **假阳性**:巧合指针大量存在;两段式(快照 A + 重扫 B)交集过滤是抗
  假阳性的核心(CE 同款策略)。
- **max_results** 防爆炸:单次快照输出上限(默认 10000),避免几十万条。

## 4. 约束

- 线程池纯标准库(std::thread + hardware_concurrency);无第三方依赖。
- 复用既有 EnumMemoryRegions / memory_read 的分块读框架,不重复实现。
- 快照/重扫均为只读操作,不修改目标进程(零副作用)。
- 公共头只暴露标准 C++ 类型(struct PointerScanConfig/PointerChain)。
