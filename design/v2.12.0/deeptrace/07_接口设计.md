# deeptrace - 接口设计(修改模式,v2.12.0)

> 引用:既有接口文档。v2.12.0 新增:

## 1. 函数签名

```cpp
Result pointer_map_snapshot(const PointerScanConfig& cfg,
                            std::vector<PointerChain>& out);
Result pointer_map_rescan(const std::vector<PointerChain>& base,
                          uintptr_t new_target,
                          const PointerScanConfig& cfg,
                          std::vector<PointerChain>& out);
```

## 2. 参数与返回

### pointer_map_snapshot

| 参数 | 类型 | 说明 |
|------|------|------|
| cfg | PointerScanConfig& | target/max_offset/max_level/max_results/module/thread_count |
| out | vector<PointerChain>& | 输出链列表(按根地址升序) |

| 返回 | 条件 |
|------|------|
| Ok | 完成(可能空) |
| NotAttached | 无会话 |
| InvalidArg | target==0 / max_offset==0 / max_level==0 |
| NotFound | 锚定模块未加载 |

### pointer_map_rescan

| 参数 | 类型 | 说明 |
|------|------|------|
| base | vector<PointerChain>& | 旧快照链列表 |
| new_target | uintptr_t | 新目标地址 |
| cfg | PointerScanConfig& | 复用 max_offset/thread_count(忽略 module/level) |
| out | vector<PointerChain>& | 过滤后链列表(保持 base 顺序) |

| 返回 | 条件 |
|------|------|
| Ok | 完成(可能空) |
| NotAttached | 无会话 |
| InvalidArg | new_target==0 / max_offset==0 |

## 3. 实现要点

- 快照:EnumMemoryRegions 过滤可读区域 → 每区域分块读(复用 pattern_scan
  的 CHUNK=1MB 框架)→ 线程池并行对每块做 scan_pointers_to → 汇总候选
  (候选 = 地址 + 命中偏移)→ 递归找上层指针 → 锚定过滤 → max_results 截断。
- 重扫:对 base 每条链在线程池并行求值(逐层 memory_read)→ 最终地址
  与 new_target 差 ≤ max_offset 则保留。
- 线程池:ThreadPool(thread_count ?: hardware_concurrency),任务队列 +
  固定 worker,析构 join。
