# CLI - 模块设计(修改模式,功能,v2.12.0)

> 引用:v2.11.0/cli/10_模块设计.md。v2.12.0 改动落点:

## 1. 改动点 → 层 / 文件映射

| 改动点 | 层 | 文件 | 说明 |
|--------|----|------|------|
| ptrscan JSON 解析 | 接口层 | src/interface/batch.cpp 或新 ptrscan 模块 | 仿 batch JsonReader 极简解析(顶层对象 + 数字/字符串) |
| resolve ptrscan 命令 | 命令解析层 | src/command/commands.cpp | resolve 组新增动作(file 参数) |
| 执行 | 接口调用层 | src/interface/cmd_resolve.cpp | 解析 → 快照/重扫 → 打印 |
| 链格式化 | 打印层 | src/printing/printer.cpp | format_chain(module+root_off + off...) |
| 版本号 2.12.0 | 打印/命令层 | printer.cpp、commands.cpp | help/version 字符串 |
| 单测 | 测试 | test/unit/ | JSON 解析 + 链格式化 |
| 集成 | 测试 | test/integration/cli_integration_test.cpp | 真实进程预埋链反推 |
| e2e | 测试 | test/e2e/test_cli_e2e.py | ptrscan 真实用例 |

## 2. 职责边界(与既有约定一致)

- **接口层**:ptrscan JSON 解析(纯文本校验,仿 batch 模块,不调 deeptrace)。
- **接口调用层**:cmd_resolve ptrscan 分支调公共 API
  (pointer_map_snapshot/rescan),链输出走 printer。
- **打印层**:format_chain 纯格式化(module+hex 偏移,`+` 连接)。
- **命令解析层**:resolve ptrscan 参数 = file(script-path 类型复用)。
- **静态库**:v2.12.0 契约(见 design/v2.12.0/deeptrace/)。
