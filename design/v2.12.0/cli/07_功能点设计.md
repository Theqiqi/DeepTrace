# CLI - 功能点设计(修改模式,功能,v2.12.0)

> 引用:v2.11.0/cli/07_功能点设计.md。v2.12.0 新增「指针链搜索」功能点。

## 1. 新增功能点:指针链搜索(resolve ptrscan)

### 1.1 命令形态

```text
resolve ptrscan <file.json>
```

### 1.2 JSON 格式(定稿)

```json
{ "version": 1,
  "target": "0x7FF62A1B2100",
  "module": "Game.exe",
  "max_offset": 2048,
  "max_level": 5,
  "max_results": 10000,
  "threads": 0,
  "rescan": { "target": "0x..." }
}
```

- version 必须 1;target 必填(hex/十进制);其余可选。
- rescan 缺省 = 仅快照;提供 target = 快照 + 重扫过滤。

### 1.3 正常路径

```text
resolve ptrscan scan.json
  → attach(pid) → 解析 JSON(校验 version/target)
  → pointer_map_snapshot(cfg) → 链列表
  → (有 rescan) pointer_map_rescan(base, new_target, cfg) → 过滤
  → 打印: Game.exe+01AF89C0 +38 +104 +8 每行一条
  → detach → 退出 0(无结果也 0,打印 No chains found)
```

### 1.4 错误路径

| 场景 | 层 | 退出码 |
|------|----|--------|
| JSON 语法/version≠1/target 缺失或非法 | JSON 解析 | 2 |
| 未 attach | 执行层 | 1 |
| 锚定模块未加载 | 执行层 | 1 |
| 扫描 API 其它错误 | 执行层 | 1 |

### 1.5 输出示例

```text
$ deeptrace_cli -p 1234 resolve ptrscan scan.json
Game.exe+01AF89C0 +38 +104 +8
Game.exe+01AF89C0 +38 +10C +8
(2 chains)

# 重扫过滤后
$ deeptrace_cli -p 1234 resolve ptrscan rescan.json
Game.exe+01AF89C0 +38 +104 +8
(1 chain)
```

### 1.6 能力边界声明

- 支持:快照/重扫、模块锚定、全参数、链格式兼容 batch。
- 不支持:链保存/管理命令(文件即存储);pointer map 落盘持久化;
  单层地址扫描(mem scan 之外的能力)。
- 帮助文本:resolve 组新增 ptrscan 条目。

## 2. 其余功能点

resolve base/scan、mem batch(链消费闭环)、ps attach 权限(v2.11.0)等全部不变。
