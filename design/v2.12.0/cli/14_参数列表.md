# CLI - 参数列表(修改模式,功能,v2.12.0)

> 引用:v2.11.0/cli/14_参数列表.md。v2.12.0 新增 resolve ptrscan 的 file 参数。

## 1. resolve ptrscan 命令参数

| 命令 | # | 参数 | 必填 | 类型 | 校验 |
|------|---|------|------|------|------|
| resolve ptrscan | 1 | file | 是 | script-path | 可读文件(存在性由接口层查) |

## 2. JSON 内部字段(ptrscan 模块校验)

| 字段 | 必填 | 取值/校验 |
|------|------|-----------|
| version | 是 | 数字 == 1 |
| target | 是 | hex/十进制地址,> 0 |
| module | 否 | 字符串;锚定模块名(空/缺省 = 不锚定) |
| max_offset | 否 | 数字 > 0,默认 2048 |
| max_level | 否 | 数字 > 0,默认 5 |
| max_results | 否 | 数字 > 0,默认 10000 |
| threads | 否 | 数字 >= 0,0 = 自动(hardware_concurrency),默认 0 |
| rescan | 否 | 对象 { target: 地址 } 或 null |

## 3. 其余参数

命令组其余参数全部不变,引用既有文档。
