# CLI - 命令列表(修改模式,功能,v2.12.0)

> 引用:v2.11.0/cli/13_命令列表.md。v2.12.0 resolve 组新增 ptrscan。

## 1. resolve 组新增命令

```text
resolve ptrscan <file.json>
    指针链搜索(从目标值反推):JSON 配置 → 快照/重扫 → 打印链列表
    输出: 每行一条链,格式兼容 mem batch 定位器:
          Game.exe+01AF89C0 +38 +104 +8
    末尾: (N chains) / (M chains, K after rescan)
```

- JSON 字段:version(1)/target(必填)/module(锚定,可选)/max_offset(2048)/
  max_level(5)/max_results(10000)/threads(0=自动)/rescan(可选重扫段)。
- 帮助文本:resolve 组新增 ptrscan 条目。

## 2. 其余命令

resolve base/scan、mem batch 等全部不变(搜索→batch 验证闭环)。
