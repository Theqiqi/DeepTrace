# 想法收集 — v2.12.0: 指针链搜索(pointer map 两段式)

## 输入想法

> 指针链搜索(从目标值反推指针链)设计调研 → 定稿实现方案。

## 调研结论(Cheat Engine Pointer Scan)

- CE 指针扫描**反向进行**:从目标值地址往上反推,每层全内存找「存着指向
  [目标±max_offset] 的指针」的地址,递归直到落在模块基址内或达 max_level。
- max_offset 默认 2048(结构体成员偏移一般 <2KB);max_level 默认 5。
- **假阳性爆炸**是核心难点:单次扫描产生几十万条巧合路径。CE 用
  **pointer map + rescan**:快照 A → 重启地址变化 → 快照 B → 交集过滤。
- 输出格式:`game.exe+01AF89C0 + 38 + 104 + 8` = 模块基址 + 偏移链,
  与 v2.9.0 `mem batch` JSON 定位器输入形态一致(搜索→验证闭环)。

## 定稿方案(用户确认)

1. **两段式**(B):静态库新增 pointer map 快照 + 重扫交集过滤。
2. **参数全开放**:max_offset/max_level 可调,默认 2048/5(同 CE)。
3. **默认模块锚定**:链起点须落在指定模块基址内(如 game.exe),可配置关闭。
4. **线程池自实现**(纯标准库,无三方依赖);线程数经 API 参数传入
   (默认 hardware_concurrency,可显式指定)。
5. **CLI 入口**:`resolve ptrscan <file.json>` JSON 配置驱动,打印链列表;
   输出兼容 `mem batch` 定位器输入,实现搜索→验证闭环。

## 约束

- 静态库仅标准库(线程池用 std::thread + hardware_concurrency)。
- CLI 输出纯 ASCII;一次调用一操作;退出码语义不变。
- 快照是静态库能力(全内存遍历+递归需高效底层),非 CLI 组合。
