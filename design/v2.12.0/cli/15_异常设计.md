# CLI - 异常设计(修改模式,功能,v2.12.0)

> 引用:v2.11.0/cli/15_异常设计.md。v2.12.0 新增 ptrscan 错误路径。

## 1. 新增错误路径(resolve ptrscan)

| 场景 | 层 | 退出码 | 输出 |
|------|----|--------|------|
| JSON 语法错误(行/列定位) | ptrscan 解析 | 2 | `ptrscan parse error at line N col M: ...` |
| version ≠ 1 | ptrscan 解析 | 2 | `invalid version 'N' (expected 1)` |
| target 缺失/非法 | ptrscan 解析 | 2 | `missing/invalid target` |
| 参数非法(max_offset=0 等) | ptrscan 解析 | 2 | `invalid <field>: <v>` |
| 文件不可读 | ptrscan 解析 | 2 | `cannot read file: <path>` |
| 未 attach | 执行层 | 1 | `Error: NotAttached(...)` |
| 锚定模块未加载 | 执行层 | 1 | `Error: NotFound(<module>)` |
| 扫描 API 其它错误 | 执行层 | 1 | `Error: <msg>` |

## 2. 错误语义关键点

- **配置错误(2) vs 业务失败(1)**:JSON 结构/取值问题 → 2;运行期失败 → 1。
- **无结果非错误**:快照/重扫无命中 → `No chains found` 退出 0。
- 退出码与既有语义一致(0 成功 / 1 业务错误 / 2 用法错误)。

## 3. 既有错误路径

v2.11.0 及之前各命令错误路径全部不变,引用既有文档。
