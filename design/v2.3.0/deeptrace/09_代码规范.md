# deeptrace - 代码规范(修改模式,v2.3.0)

> 引用:v2.2.0/deeptrace/09_代码规范.md 既有规范。本版本沿用既有代码规范,
> 新增约束:

- 新增 Service 模块(script/hook)遵循既有命名与分层规范(namespace deeptrace,
  内部函数 namespace deeptrace::internal)。
- asm_assemble_labels 复用 Algorithm/Infrastructure 的 asm_one,不绕过分层。
- 公共类型(HookInfo/ScriptInfo)定义于 include/domain/types.h,公共 API 声明于
  include/deeptrace.h。
- 记录持久化复用 store(load/save 行式 ASCII,'|' 分隔),禁止在 Service 中直接做文件 I/O。
