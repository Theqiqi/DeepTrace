# deeptrace - 模块设计(修改模式,v2.3.0)

> 引用:v2.2.0/deeptrace/05_模块设计.md 既有模块划分。本版本新增/扩展模块:

## 1. 模块划分(增量)

| 模块 | 变化 | 文件 | 职责 |
|------|------|------|------|
| Service: script | 新增 | src/service/script.h/cpp | 脚本符号表 + 脚本记录持久化(script_alloc/enable/disable/status) |
| Service: hook | 新增 | src/service/hook.h/cpp | hook 改写与恢复(hook_set/hook_clear) |
| Service: asm | 扩展 | src/service/asm.h/cpp | 新增 asm_assemble_labels(带 label 汇编) |
| Service: thread | 扩展 | src/service/thread.h/cpp | 新增 thread_create_at(任意地址建线程) |
| Domain: types | 扩展 | include/domain/types.h | HookInfo / ScriptInfo 数据结构 |
| Infrastructure: store | 扩展 | src/service/store.h/cpp | 脚本符号表 / hook 记录 / 脚本记录持久化(新记录类型) |

## 2. 既有模块

进程/内存/模块/线程/调试/反汇编/解析/监视/注入等模块不变,引用既有文档。
