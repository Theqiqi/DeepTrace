# CLI - 接口设计(修改模式,增量,v2.3.0)

> 引用:v2.2.0/cli/12_接口设计.md 既有接口。本版本新增 script 命令组:

## 1. 数据结构(沿用,无新增)

- `CommandRequest{group, action, args, pid, pid_set, help, version}` 不变。
- 脚本解析产物(接口层内部):`ScriptStep{type, name, value}` + `ScriptBlock{enable, disable}`。

## 2. 新增命令的接口层行为

### 2.1 script run

- 输入:`<file>`(AA 脚本路径)。
- 处理:
  1. 解析脚本(语法错误 → 退出 2);
  2. 校验含 [ENABLE] 块(无 → 退出 2);
  3. 幂等检查:`script_status` 中该脚本已 enabled → 输出 `already enabled` 退出 0;
  4. 执行 ENABLE 步骤(见 §3);
  5. 全部成功 → `script_enable(path)`(幂等记录)→ 输出摘要。
- 输出:每步摘要(alloc 地址 / createThread TID / hook 目标)。

### 2.2 script disable

- 输入:`<file>`。
- 处理:
  1. 解析脚本(语法错误 → 退出 2);
  2. 校验含 [DISABLE] 块(无 → 退出 2);
  3. 幂等检查:未 enabled → 输出 `already disabled` 退出 0;
  4. 执行 DISABLE 步骤(逆序:hook 恢复 → 释放);
  5. `script_disable(path)` → 输出 `OK` + 摘要。

### 2.3 script status

- 输入:无。
- 处理:`script_status(list)` → 输出状态表(脚本路径、hook 目标、分配符号)。
- 输出:纯 ASCII 表;无记录输出空表头。

## 3. ENABLE/DISABLE 步骤执行器

```
exec_enable(steps, path, ctx):
  for step:
    alloc(name,size)      -> script_alloc(name,size,path,&addr); ctx.symbols[name]=addr; print
    asm 块(裸汇编行)      -> 收集汇编文本;目标=当前块(alloc 的 name 或 hook 目标)
                             asm_assemble_labels(text, base, ctx.symbols, bytes)
                             memory_write(base, bytes)
    db <hex>              -> 按 hex 解析 → memory_write 到当前目标
    hook 目标("module"+offset:) -> 解析模块基址+偏移 → hook_set(addr, jmp 目标, path, info)
    createThread(name)    -> thread_create_at(ctx.symbols[name], &tid); print
    registersymbol / label -> no-op(符号由 alloc 登记;label 由 asm_assemble_labels 解析)

exec_disable(steps, path, ctx):
  for step (逆序):
    unregistersymbol(name) -> no-op
    hook 恢复              -> hook_clear(addr)
    dealloc(name)          -> script_free(name)
```

- hook 目标行 `"module"+offset:` 后跟 `jmp <label>` → 跳转目标 = label 符号地址;
  该行也作为 hook 目标传给 hook_set。
- 汇编块目标:脚本内 alloc 后的裸汇编行写入该 alloc 地址;hook 目标后的裸汇编行
  写入目标地址(由 hook_set 改写 jmp,`db` 行写原始字节供恢复)。

## 4. 模块地址表达式解析(接口层辅助)

- `"module"+offset`:`resolve_base(module)` + offset 计算(标准库文本解析)。
- 模块未加载 → 错误退出 1。

## 5. 与既有命令的关系

- asm file / hex2bin / shellcode alloc/run/free/exec 继续作为独立工具与字节转换来源。
- script 组不修改任何既有命令行为。
- 所有新命令经 executor 既有 `-p <pid>` 自动 attach/detach 路径。
