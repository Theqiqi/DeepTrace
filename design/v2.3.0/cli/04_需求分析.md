# CLI - 需求分析(修改模式:需求变更文档,v2.3.0)

> 引用:v2.2.0/cli/04_需求分析.md 既有需求。本版本输出需求变更,逐条列出改动点。
> 输入:01_想法收集(想法)+ 用户设计决策确认(完整版 AA / 幂等开关 / 三态数据源)。

## 1. 已确认的设计决策(想法收集阶段的开放问题)

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 语法范围 | **完整版 AA**:精简关键字(alloc/dealloc/createThread/db)之上增加 label/registersymbol/unregistersymbol/模块偏移地址表达式(hook 目标)/jmp 改写与原始字节恢复 |
| 2 | 数据源 | **三态全支持**:.asm/.s 汇编文件、.bin 文件、16 进制字节;保留既有互转命令(asm file / hex2bin / shellcode exec) |
| 3 | 执行语义 | **幂等开关**:enable/disable 重复执行结果一致,天然无状态——执行开启命令任意次数,状态必为「开」;执行关闭任意次数,状态必为「关」。call 型脚本一次调用跑完 enable+disable 完整流程;hook 型脚本 enable 持续存在、disable 单独触发 |
| 4 | 状态持久化 | hook 状态与原始字节按 PID 持久化(沿用 store 机制,仿 breaks.dat/injects.dat),跨调用可判定「已启用/已禁用」并支持幂等 |
| 5 | 命令入口 | 新命令组 `script`:`script run <file>`(执行 ENABLE,幂等)、`script disable <file>`(执行 DISABLE,幂等)、`script status`(可选,列 hook 状态) |

## 2. 脚本语法(参考 CE AA,能力边界内)

```
[ENABLE] / [DISABLE]           块标记(脚本可含双块;至少一块)
alloc(name, size[, near_expr]) 分配 size 字节远程内存(可选 near 地址表达式),绑定符号 name,成为后续裸汇编行的写入目标
label(name)                    声明标签(与 name: 等价;标签指向当前写入流位置)
registersymbol(name)           注册符号(name 可被脚本内 jmp/call 引用)
unregistersymbol(name)         注销符号(DISABLE 块用)
createThread(name)             在符号 name 处创建远程线程执行一次
dealloc(name)                  释放符号 name 指向的内存(DISABLE 块用)
db <hex bytes>                 原始字节直接写入当前输出流(目标地址恢复用)
<name>:                        标签定义 = 指向当前输出流位置
<asm 行>                       汇编指令(Intel x64,Keystone);裸汇编行连续拼接进「当前写入目标」
"module"+offset:               目标地址标签(模块基址 + 偏移),后续裸汇编行写入目标地址(hook 改写)
```

## 4. 无交互与纯 ASCII 约束复核

- 新命令无阻塞输入等待(getchar/scanf/cin 不出现);脚本读取为文件 I/O;执行完立即退出。
- 所有输出纯 ASCII;错误消息统一 `Error:` 前缀。
- 一次调用一个操作:`script run` 执行一个脚本的 ENABLE 块;`script disable` 执行一个脚本的 DISABLE 块。
- 资源成对:alloc↔dealloc、hook set↔hook clear、createThread↔(线程自然结束),脚本执行失败路径必须回滚已分配资源(见 15_异常设计)。
- 新增/修改需求点均满足无交互与纯 ASCII 约束。

## 5. 能力边界声明(声明支持 / 不支持)

- **支持**:脚本文件(.aa 建议扩展名,亦可 .txt);关键字 alloc/label/registersymbol/unregistersymbol/createThread/dealloc/db;`[ENABLE]`/`[DISABLE]` 双块;目标地址表达式 `"module"+offset`(模块必须已加载);裸汇编行(Intel x64);`db` 原始字节。
- **不支持**(报明确错误,文档不暗示支持):无 `[ENABLE]` 块的 run、无 `[DISABLE]` 块的 disable、未知关键字、语法错误、模块未加载的地址表达式、跨进程符号(符号仅作用于本次脚本)、条件分支/循环等高级汇编伪指令、对非 hook 语义的任意地址改写。
- **幂等边界**:enable 后未执行 disable 又 enable → 跳过(已启用);disable 后未 enable 又 disable → 跳过(已禁用);进程重启后 hook 记录失效(记录随进程句柄校验)。
- hook 只改写入的 jmp + nop 填充区,不修改其余代码;DISABLE 用保存的原始字节恢复,恢复失败报错退出 1。
