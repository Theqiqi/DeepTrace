# CLI - 需求点设计(修改模式,增量,v2.3.0)

> 引用:v2.2.0/cli/05_需求点设计.md 既有需求点。本版本新增脚本相关需求点,既有需求点不变。

## 1. 新增需求点

### R-SCRIPT-RUN:执行脚本 ENABLE 块(幂等)

- 命令:`script run <file>`
- 输入:AA 风格脚本文件路径
- 输出:执行摘要(alloc 地址、createThread TID、hook 目标与写入字节)
- 语义:
  - 解析脚本(语法错误 → 用法错误退出 2)
  - 校验 [ENABLE] 块存在,不存在 → 错误退出 2
  - 顺序执行 ENABLE 块步骤:label 声明收集符号 → alloc(按大小分配+符号绑定)→ 裸汇编行经带 label 汇编写入当前目标 → db 写入 → hook 目标改写 → createThread → registersymbol
  - **幂等**:脚本已启用(按 PID+脚本路径记录存在)且目标仍有效 → 跳过执行,输出「already enabled」,退出 0
  - 失败回滚:任一步失败 → 回滚本脚本已分配内存/已改写 hook(恢复原始字节),退出 1
- 边界:文件不存在 → 用法错误退出 2;目标未 attach → 错误退出 1;模块未加载 → 错误退出 1

### R-SCRIPT-DISABLE:执行脚本 DISABLE 块(幂等)

- 命令:`script disable <file>`
- 输入:AA 风格脚本文件路径
- 输出:`OK` + 摘要(已恢复 hook 目标、已释放内存)
- 语义:
  - 解析脚本(语法错误 → 用法错误退出 2)
  - 校验 [DISABLE] 块存在,不存在 → 错误退出 2
  - **幂等**:脚本未启用(记录不存在)→ 跳过执行,输出「already disabled」,退出 0
  - 顺序执行 DISABLE 块:unregistersymbol → 目标地址 `db` 恢复原始字节(hook clear)→ dealloc(释放)
  - 失败:hook 恢复失败 → 错误退出 1(记录保留,可重试)
- 边界:同 run

### R-SCRIPT-STATUS:脚本/hook 状态

- 命令:`script status`
- 输入:无
- 输出:目标进程已启用 hook/脚本列表(脚本路径、hook 目标地址、原始字节摘要)
- 语义:读取按 PID 持久化的脚本记录,输出纯 ASCII 表格
- 边界:未 attach → 错误退出 1

### R-AA-ALLOC:按大小分配+符号绑定

- 关键字:`alloc(name, size[, near_expr])`
- 语义:分配 size 字节远程内存(PAGE_EXECUTE_READWRITE),绑定符号 name;near_expr 可选(仿 CE 就近分配,本版本可仅接受省略形式或显式报「不支持」——见能力边界)
- 输出:符号 name → 分配地址;记录进脚本状态(供 DISABLE dealloc)
- 边界:size=0/过大 → 错误;分配失败 → 回滚

### R-AA-ASM-LABEL:带 label 的汇编

- 关键字:裸汇编行 + `<name>:` 标签 + `label(name)`
- 语义:脚本内汇编块整体汇编,label 引用(jmp/call name)解析为「符号地址 - 当前指令地址」的 PC-relative 位移
- 实现:静态库新增「带符号汇编」API(走能力匹配);CLI 侧不自行汇编
- 边界:未定义 label 引用 → 汇编失败退出 1

### R-AA-HOOK:目标地址改写与恢复

- 关键字:`"module"+offset:` 后接裸汇编行(jmp 到新内存)+ db 原始字节
- 语义:
  - ENABLE:读目标地址原始字节 → 计算 jmp 写入(改写为 jmp 到新内存)→ nop 填充剩余 → 保存原始字节到记录
  - DISABLE:用保存的原始字节恢复目标地址 → 删除记录
- 边界:目标地址不可读/不可写 → 错误退出 1;hook 长度不足(目标指令区 < jmp 长度)→ 错误

### R-AA-CREATETHREAD:远程线程创建

- 关键字:`createThread(name)`
- 语义:在符号 name 指向的地址创建远程线程执行一次(与 shellcode_run 底层一致,新增对任意地址的线程创建)
- 边界:地址非法/未分配 → 错误退出 1

## 2. 受影响既有需求点

- `shellcode alloc/run/free/exec`、`asm file`、`hex2bin`(不变):继续作为脚本的字节转换与手工分阶段工具。
- 其余命令组(ps/mem/module/thread/debug/disasm/resolve/watch/dll/convert)不变。
- 无交互/纯 ASCII/一次调用一个操作/资源配对约束:全部新需求点满足(复核见 04_需求分析 §4)。
