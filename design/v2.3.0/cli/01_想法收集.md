# CLI - 想法收集(v2.3.0,修改/添加功能模式)

## 1. 输入想法(原始)

> 想到了,其实这种 shellcode 的 alloc,run,free,createthread 等可以写成**脚本的关键字**,然后 shellcode 只需要配合 asm 或者 bin 或者 16 进制字节就能执行。也就是分为按照 .flow 的新建与修改流程工作。

附参考示例(Cheat Engine AA 脚本语法,来自用户提供链接):

```text
[ENABLE]
alloc(newmem,2048,"GameAssembly.dll"+7D5778)
label(returnhere)
label(originalcode)
label(exit)
alloc(addsunrcx, 8)
registersymbol(addsunrcx)

newmem: //this is allocated memory, you have read,write,execute access
//place your code here
mov [addsunrcx],rcx

originalcode:
xor r9d,r9d
cvttss2si r8d,[rsp+44]

exit:
jmp returnhere

"GameAssembly.dll"+7D5778:
jmp newmem
nop 5
returnhere:

[DISABLE]
dealloc(newmem)
unregistersymbol(addsunrcx)
dealloc(addsunrcx)

"GameAssembly.dll"+7D5778:
db 45 33 C9 F3 44 0F 2C 44 24 44
```

```text
[ENABLE]
alloc(newmem,1024)
createThread(newmem)

newmem:
    sub rsp,28
    mov rax,addsunrcx
    mov rcx,[rax]
    mov rdx,0000000000000019
    mov r12,"GameAssembly.dll"+63B9C0
    call r12
    add rsp,28
    ret

[DISABLE]
dealloc(newmem)
```

## 2. 想法解读

- 用户希望把 v2.2.0 已实现的 shellcode 分阶段能力(alloc/run/free)以及线程创建(createThread)等操作,包装成**脚本关键字**,用户写脚本文件描述"要做什么",CLI 解析并执行。
- shellcode 数据来源三种:asm 汇编代码、bin 文件、16 进制字节——v2.2.0 已分别有 asm assemble/file、hex2bin、shellcode exec 支撑。
- 参考示例来自 Cheat Engine 的 AA(Auto Assembler)脚本:结构化关键字 + 标签(label) + 汇编行 + `[ENABLE]`/`[DISABLE]` 双块。

## 3. 现状差距分析

| 能力 | 现状 | 差距 |
|------|------|------|
| 分配内存并写入 | `shellcode alloc <source>`(v2.2.0) | 无 |
| 触发执行 | `shellcode run <address>` / `shellcode exec`(v2.2.0) | 无 |
| 释放清理 | `shellcode free <address>`(v2.2.0) | 无 |
| 汇编→字节 | `asm assemble` / `asm file`(v2.2.0) | 无 |
| hex→bin | `hex2bin`(v2.2.0) | 无 |
| 脚本文件解析/执行 | `debug run <script.json>` 已有 JSON 步骤脚本,但面向调试会话,非 AA 风格 | 需新增 |
| 线程创建 | 无独立 createThread 命令(仅注入时自动创建) | 需新增 |
| 目标地址代码改写(hook,jmp 到新内存) | 无 | 需新增(待确认范围) |
| 符号表(registersymbol) | 无 | 需新增(待确认范围) |
| [ENABLE]/[DISABLE] 双块 | 无 | 需确认执行语义 |

## 4. 流程可行性

- 类型:修改/添加功能(对现有 CLI 添加新命令组与脚本能力)。
- 程序类型沿用:CLI 无交互,一次调用一个操作(`script run <file>` 即一次调用执行一个脚本)。
- 涉及静态库能力补充(脚本执行 / hook / 线程创建):需走 `.flow/cpp_static_flow.md` 跨流程交接(第 3 步能力匹配后确定)。
- 版本号:v2.3.0(功能位 +1)。
