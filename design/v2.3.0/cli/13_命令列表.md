# CLI - 命令列表(修改模式,增量,v2.3.0)

> 引用:v2.2.0/cli/13_命令列表.md。v2.3.0 新增 script 组如下,其余命令不变。

## 1. script 组(新)

```text
script run <file>
    Run an AA-style script [ENABLE] block (idempotent)
script disable <file>
    Run an AA-style script [DISABLE] block (idempotent)
script status
    Show enabled scripts and their hooks/allocs
```

- `<file>` = AA 脚本文件路径(纯 ASCII)。
- 幂等:重复 run 已启用脚本 → `already enabled` 退出 0;重复 disable 未启用脚本
  → `already disabled` 退出 0。
- 脚本语法见 12_接口设计 §3(关键字:alloc/label/registersymbol/unregistersymbol/
  createThread/dealloc/db + `[ENABLE]`/`[DISABLE]` 块 + 裸汇编行 + `"module"+offset:`)。
