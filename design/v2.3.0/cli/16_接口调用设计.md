# CLI - 接口调用设计(修改模式,增量,v2.3.0)

> 引用:v2.2.0/cli/16_接口调用设计.md。本版本新增 script 命令组的静态库 API 映射。

## 1. 新增 API 映射(逐条)

| CLI 步骤 | 静态库公共 API(真实) | 说明 |
|----------|----------------------|------|
| alloc(name,size) | `script_alloc(name, size, path, &addr)` | 分配+符号绑定+owner=脚本路径 |
| dealloc(name) | `script_free(name)` | 释放+删符号 |
| 汇编块写入 | `asm_assemble_labels(text, base, symbols, bytes)` + `memory_write(base, bytes)` | 内部 label 解析;PC-relative 正确 |
| db <hex> | `memory_write(addr, bytes)` | 原始字节写入当前目标 |
| hook 目标改写 | `hook_set(addr, jmp_target, path, info)` | 保存原始字节+owner |
| hook 恢复 | `hook_clear(addr)` | 恢复原始字节+删记录 |
| createThread(name) | `thread_create_at(addr, &tid)` | 任意地址建线程 |
| 模块基址 | `resolve_base(module, &base)` | 解析 `"module"+offset` |
| 幂等检查/记录 | `script_status(list)` / `script_enable(path)` / `script_disable(path)` | 按 PID+路径持久化,幂等 |

## 2. -p 自动 attach/detach 路径覆盖

- script run/disable/status 全部经 executor 既有 `-p <pid>` 路径:本次调用内
  attach → 执行 → detach,会话生命周期 = 本次 CLI 进程。
- 新命令均需 -p(操作目标进程);script status 也需 -p(读取按 PID 的记录)。

## 3. 资源生命周期规则

- 成对:alloc ↔ dealloc、hook_set ↔ hook_clear、enable ↔ disable。
- ENABLE 失败回滚(见 15_异常设计 §3):已 alloc → script_free;已 hook → hook_clear。
- DISABLE 失败保留记录可重试(不半恢复)。
- 配对正确性由测试阶段「副作用检查」验证(enable 后 status 可见、disable 后目标
  字节恢复、进程存活)。

## 4. 调用顺序(script run)

```
parse(path) -> ENABLE steps
script_status() 已启用? -> already enabled (exit 0)
attach(-p)
for step: 执行(见 12_接口设计 §3)
  失败 -> rollback_all() -> exit 1
script_enable(path) -> 摘要 -> detach -> exit 0
```
