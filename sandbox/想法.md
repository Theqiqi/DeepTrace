# 想法

## 想法记录(原样)

- 项目自研的反汇编引擎只覆盖常见整数指令子集,不完整(无 SSE/AVX、REP 字符串指令等)
- 想验证:引入开源反汇编库(Capstone/Zydis)替换自研引擎是否可行——能否在 Windows+MSVC+vcpkg 环境接入、基础调用能否工作、能否覆盖自研引擎不支持的指令

## 可验证性预判

- 可验证:vcpkg 提供 capstone port,MSVC+vcpkg 环境已在 pmem/cli 项目中验证过(gtest 接入成功)
- 缺条件:无(vcpkg 网络需 GIT_SSL_NO_VERIFY=1,与既有项目一致)

## 情形判定

- 情形二:不对接 独立探索——先验证库本身的基础调用与 vcpkg 接入;对接 pmem 的集成方案留待本验证通过后另行验证

## 验证目标与观测标准(验证清单)

1. vcpkg 能解析并安装 capstone → cmake configure 成功,出现 capstone 包
2. 链接成功并运行 → sandbox_disasm.exe 输出反汇编结果
3. 基础指令解码文本与预期一致(断言)
4. 自研引擎不支持的 SSE/SSE2/REP 指令能正确解码(断言)

## 技术路线

- 语言:C++20;编译器:MSVC(cl.exe 经 vcvars64);构建:CMake + Ninja + CMakePresets;包管理:vcpkg manifest(capstone)
- 平台:Windows x64;运行:cmd.exe(经 WSL)
