# deeptrace_cli User Documentation

> deeptrace_cli is a Windows command-line tool for viewing processes, reading and writing process memory, debugging programs, disassembling code, running AA-style scripts, scanning pointer chains, and converting asm/bin/hex — suited to game modding, reverse engineering, and similar scenarios.

- [Quick Start (GETTING_STARTED)](GETTING_STARTED.md) — install, view processes for the first time, read memory for the first time
- [User Manual (USER_MANUAL)](USER_MANUAL.md) — how to use every command (incl. script engine, batch, pointer-chain scan, conversion layer)
- [FAQ](FAQ.md) — answers to frequently asked questions
- [Troubleshooting (TROUBLESHOOTING)](TROUBLESHOOTING.md) — error message reference
